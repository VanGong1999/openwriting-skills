# 分场 · 台词 · 潜台词

> 本包自包含：分场定义与格式、单场四步法、台词原则与七注意、金句类型、案例结构。与 [playbook.md](playbook.md) 节拍链、[genre-beats.md](genre-beats.md) 信息节拍（35–45）配合。优先级是**故事/节拍/可视听**，非短剧解压节奏。

---

## 使用说明

1. 分场链条：**一句话 → 1500 字梗概 → 信息节拍（约 35–45）→ 万字纲 → 分场**；勿跳过草稿直接怼戏。
2. 影视剧 = **闭合结构**，观众付整段注意力；连载小说开放写法不适用。
3. 台词服务场面与潜台词；**忌用台词推剧情**（与短剧高密度台词并存，边界见 SKILL.md）。

---

## 一、为什么分场在最后

**分场 = 落实的最后一步**：之前的设计必须变成可看可听的具体画面（「丑媳妇见公婆」）。

| 对比 | 连载小说 | 影视剧 |
|------|----------|--------|
| 结构 | 开放 | **闭合** |
| 逻辑 | 可随性 | 必须严谨 |
| 创作 | 可边写边想 | **先有图纸** |

编剧是理性与感性共存：**第一步永远是图纸与结构**，不能无梗概无大纲直接写场。

## 二、分场：定义与三层理解

### 2.1 时空定义

> **分场 = 统一空间和连续时间内的故事场面。**

满足其一即可：

- **统一空间**（同一场景）；
- **连续时间**（追逐跨多场景仍算一场）。

### 2.2 三层理解

| 层 | 含义 |
|----|------|
| **呈现** | 抽象信息 → 可看可听的视听语言 |
| **小故事** | 单场有头有尾、起承转合，单独可看 |
| **合成** | 呈现 + 可看性 = 合格分场 |

### 2.3 三个作用（缺一则不合格）

| 作用 | 说明 |
|------|------|
| **交代信息** | 信息节拍的最终实现 |
| **推进剧情** | 「拉着小车参观」——行动的艺术 |
| **带来变化** | 状态改变才是有效行动 |

> **无变化就不能要**——即使含信息与推进，也应删场或把内容挪到别处。

## 三、编剧分场 ≠ 导演分场

- 编剧场号、内外景**常被导演改掉**（反打当两场、跳拍等）。
- 好莱坞倾向按**幕**写，细分交给分镜；国内制片人常数场号。
- 中国剧本**一页 ≠ 一分钟**（中英文节奏差异）；场号方便制片心里有数。

### 编剧不必写

| 元素 | 说明 |
|------|------|
| 角色/道具统筹表 | 导演二度创作后由统筹做 |
| BGM | 原则上不是编剧活 |
| 机位走位 | 剧情强相关例外（如「满屏是屁股」） |
| 过细表情 | 习惯动作/撒谎习惯等有深意时可点一笔 |

### 首次出场规则

角色未被故事里「叫出名」前，写**可视特征**（如「四十岁光头男人走来」），勿替观众开天眼。叫出名后才用角色名。

**核心尺度：** 不是你的工作可不动；怕漏意图可点一点，勿过度干涉表演与导演。

## 四、单场元素与标准格式

**一场 = 基本信息 + 环境 + 动作 + 对白**

### 4.1 第一行四项

| 项 | 说明 | 示例 |
|----|------|------|
| 场号 | 电影约百场，常三位 | `028` |
| 场景 | 空间 | 办公室 |
| 时间 | **日 / 夜 / 晨 / 昏** | 日 |
| 内外 | 内景 / 外景 | 内 |

### 4.2 示例结构（后院谈判戏）

```text
028  外景  平房后院  夜

【环境】一片黑暗之中。远处街区偶有犬吠。

【动作】小粉慌乱用防水布盖住 muscle 车车牌；闻脚步声，抓撬棒蹲到车后。脚步慢，停住。

【对白】
                    老白（画外音）
          我知道你在那儿。

                    小粉
          谁？

                    老白
          ……（停顿、耸肩）我很好奇。

（老白从暗处现身。二人对峙。）

                    老白
          你不是一直想挣钱吗？跟我干。

                    小粉
          你他妈是个老师。

                    老白
          你不干，我就举报你。

（小粉僵住——由拒到被迫同意。切。）
```

说明：**画外音**标「先声后人」；**停顿、耸肩**标关键决心时刻；在**变化发生时收场**，勿再写「好吧我同意」重复一遍。

### 4.3 环境描写

宜**引人入胜**，调动：

- 视、听（基础）；
- 嗅、味、触觉、温度；
- 气质感（一进屋就知主人品味）。

### 4.4 复杂单场：连续时间换景

同一事件、连续时间可标**一个场号**，文内用「换景：车内 / 街景 / 房内」。拍摄九成会拆景拍，编剧按时空理解即可。

## 五、分场四步法（组装单场）

```text
锁定任务 → 找对抗 → 用事件包裹 → 带来转变
```

### 5.1 锁定任务

来自**信息节拍**：本场要办什么事（例：双男主结盟）。

### 5.2 找对抗

「冲突/对抗」同义；**有对抗的力量**即可，不必全是武打。

反向验证：一方愿一方不愿才有戏；双方都愿则跳过。

### 5.3 用事件包裹

给任务+对抗找具体「事儿」：谈判、抓捕、宴会、拜访……

### 5.4 带来转变

事件须有**结果性变化**（反转）。

### 5.5 三项补充

| 项 | 要求 |
|----|------|
| **烈度** | 架构好后一般**加强**（酌情分配：配角戏不必拉满） |
| **指向性** | 场末让观众知「接下来会怎样」（小钩子） |
| **掐头去尾** | **状态一变场就该结束**；动作 = 状态改变，非必肢体大动 |

### 5.6 简单戏模型（老白劝小粉）

| 步 | 内容 |
|----|------|
| 任务 | 招募伙伴 |
| 对抗 | 小粉不愿意 |
| 事件 | 对白谈判 |
| 转变 | 威胁举报 → 小粉同意 |
| 进/出 | 进场：藏车；出场：威胁后沉默收 |

### 5.7 复杂戏模型（参观缉毒现场）

**多任务一锅炖：** 伙伴登场 + 坚定贩毒决心 + 强化连襟人设 → 选**抓捕大事**作容器。

**四组对抗各自转变：** 抓与逃（光着屁股跑掉）/ 老白试探 vs 连襟逞狂同意 / 相认放走 / 打赌打平。

**烈度：** 包围→等校车→破门→追逐；主角相关戏拉满。

**万字纲转分场陷阱：** 信息常大量丢失且**不自知**——四步法价值在**查遗漏**。

熟练后四步内化；先想事件再理信息亦可。

## 六、长剧场级工作流

```text
节拍表定点 → 本场任务（来自节拍）→ 对抗 → 事件包裹
→ 烈度加强 → 环境/动作可视听化 → 对白短、有潜台词
→ 场末变化+指向下一场 → 自检：无变化则删
```

## 七、台词：原则与七注意

### 7.1 四条总原则

1. **台词没有事件重要**——补充、辅助，非主力。
2. 全片**坐下纯说话**最好不超过**三场**（水片爱咖啡厅/车里）。
3. **不能用台词推进剧情（大忌）**——原谅、解谜、恋爱全靠嘴 = 相声剧本。
4. 最重要是**说人话**，非华丽；才华用在剧情与对抗设计。

### 7.2 七注意（全文）

| # | 要点 | 展开 |
|---|------|------|
| 1 | 简洁、直接 | 不绕弯凑字数；台词最凑不了篇幅 |
| 2 | 避 **Q&A 陷阱** | 勿「你知道那谁吗」连环解释；制片可能整段删解释台词；事件表达不了就别硬说 |
| 3 | **潜台词** | 表面问抓坏蛋热闹，实则学制毒步骤；「直接」与潜台词不矛盾 |
| 4 | 少用代词、关联词 | 面对面少用「你」；少用因为所以；极端练习可禁代词 |
| 5 | 少用省略号、感叹号 | 停顿写停顿，别用漫画式堆标点 |
| 6 | 必须大量对白时增能 | **争论** / **信息错位**（打碎花瓶不知丈人知）/ **炸弹理论**（观众知桌下炸弹角色不知） |
| 7 | **个性化** | 记生活素材；给主角写日记；依次代入 A/B/C **表演**改各自台词（编剧是书房里的影帝） |

### 7.3 与剧本四大要求合用

可视听化 · 按放映顺序 · **禁大段闪回旁白独白** —— 信息表达不过来时改**事件设计**，勿加长解释台词。

## 八、金句三类型

| 类型 | 方向 | 例 |
|------|------|-----|
| **人设型** | 只有这种人才说的话 | 「我不要你觉得，我要我觉得」 |
| **情境型** | 对抗精妙 + 简练一句 | 「对不起，我是警察」；「这个可以有，这个真没有」 |
| **哲理型** | 生活/人生/生命开头 | **不推荐刻意追求**——须作品与人「够硬」才有资格 |

推荐追求人设型与情境型；哲理型易镜花水月。
