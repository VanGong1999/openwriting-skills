# Comedy Writing Playbook

---

## 本质三角

```
距离感（不共情）
    → 优越感（俯视）
    → 冒犯（须安全、可广泛、有度）
```

与爽/虐：**入戏共情** vs **戏外观摩**

---

## 人物行为幅

```
悲剧人物 < 正剧人物 < 喜剧真人 < 动画夸张
公式：最大行为 → 最小结果
```

## 三方向 × 三类型人物

### 小人物

| 子型 | 笑点源 | 慎用 |
|------|--------|------|
| 残缺外化 | 身体/言语缺陷 | 勿嘲真实残障无善意 |
| 傻 | 反应慢 | 智力冒犯审查 |
| low/没见识 | 进城错位 | 本山范式 |

### 典型人物（须有社会共识）

可踩：烂队、校长、势利亲家、老板、古装太监等  
不可乱踩：消防员、医护等共识神圣职业

### 荒诞人物

行为阈值极大：高技煮泡面、Tom 绕远路取小利

## 困境公式

| 类型 | 例 | 条件 |
|------|-----|------|
| 倒霉 | 摔倒、连倒霉 | 人设先可被俯视 |
| 反差 | 人进错环境（贼×警局） | **非生死** |
| 生死线 | 摔破头 | 笑停 |

结构性喜剧 = **人与环境不对配** + 困境最大化 + 安全

## 八呈现形式（孵化营 × 短剧）

| # | 形式 | 核心机制 | 短剧/电影例 |
|---|------|----------|-------------|
| 1 | 倒霉 | 链式升级 | 星爷耍帅必扑 |
| 2 | 误会 | 角色错观众对 | 门禁我爱你；马冬梅/秋雅；茴香汤 |
| 3 | 巧合 | 必然发生 | 重生遇傻春绿帽 |
| 4 | 隐私暴露 | 羞窘 | 裤子裂、走错澡堂 |
| 5 | 信息差 | **观众>角色** | 收保护费进黑帮屋；重生预知 |
| 6 | 反转 | 最差者得 | 如花；好嗓门 |
| 7 | 重复/callback | 默契共谋 | 赵四抽；跨世拔罐 |
| 8 | 反差 | 属性对立 | 女汉子×弱男 |

### 信息差铁律

- ✅ 观众与主角同是「先知」（穿越）  
- ❌ 观众比角色傻 → 笑点崩  

### 台词 vs 讲笑话

| 类型 | 判定 |
|------|------|
| 玩赖 | 角色专门讲独立段子 |
| 真喜剧台词 | 由人设+困境推出（不差钱真没有） |

### 动作

- 出洋相 / 张冠李戴  
- 同一困境：喜剧脸 vs 正剧脸效果迥异

## 短剧 14 元素（《夏洛特烦恼》式教材）

| # | 元素 | 要点 |
|---|------|------|
| 1 | 信息差开挂 | 重生/预知 |

| 5 | 冒犯 | 傻、特殊群体——**合规** |
| 6 | callback | 拔罐平行宇宙 |

## 短剧市场备忘

- 1.0 爽/虐先行；观众全覆盖后喜剧必会  
- 喜剧门槛：创作者的幽默 + 观众接受冒犯  
- 爱看喜剧者文化层次略高（相对纯爽）  
- 肢体笑点：**案头 + 表演**  
- 妄想悬疑+喜剧+科幻一桌 → 付费弱（吃席非买单商品）

## 场次设计单

```markdown
场次：
喜剧方向：[ ]人物 [ ]困境 [ ]黑色主题(少)
人物类型：[ ]小 [ ]典型 [ ]荒诞
情境：1–8 编号
信息差：观众知道___ 角色知道___
生死线：是否越界 [ ]否
合规：冒犯对象___ 风险___
能量：上一段情绪___ 本场释放方式___
```

## 能量平衡

- 长篇不宜从头笑到尾  
- 砸角色后宜有善意动作（穿衣、解围）  
- 脱口秀砸己 vs 剧砸角色——后者更要 **度**  

## 与合规交界（不强教擦边）

冒犯题材、两性恶搞、公职人员当笑靶 → 交 `compliance-content`  
劇内讽刺收礼等：用社会共识不正之风，勿变实名辟谣靶
