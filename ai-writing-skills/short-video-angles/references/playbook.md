# 短视频 3-2-4 与三角定位 Playbook

> 完整展开「3-2-4 创作法」、九类优势、需求三级、变现九种、案例库。

---

## 一、3-2-4 创作法全解

### 1.1 命名拆解

```
3  →  三角定位三个角：自身 | 用户 | 平台
2  →  双重叠加原则：
       · 自身：2–3 个局部优势叠加（可加反差）
       · 用户：爽点 + 价值叠加（且爽点分「激素级」「人性级」两层，勿先只做价值）
4  →  四步选题闭环（每做一个号走一遍）：
       ① 定 ≥2 种变现（平台角锚点）
       ② 勾优势（九类里选 2–3 稀缺）
       ③ 定主需求（爽点为主 + 价值为辅，且稳定）
       ④ 反验证：内容能否自然承载变现且不违背主需求
```

### 1.2 三角定位图

```
           ① 自身（局部优势）
                /\
               /  \
              /    \
    ③ 平台 ——      —— ② 用户（需求/爽点/价值）
    （变现方式）
```

**顺序铁律**：自身 → 用户 → 平台。**禁止**先问「哪个赛道最热/搞笑是否最赚钱」。

### 1.3 选题终极句

> **基于什么样的优势，提供给用户什么样的爽点/价值，落在什么变现方式上可持续。**

## 二、平台角：抖音变现九种（第 2 课）

| # | 方式 | 直播? | 要点 |
|---|------|-------|------|
| 1 | 直播带货 | 是 | 全品类头部难复制 / 赛道型 / 自有产品 |
| 2 | 打赏 | 是 | 存在感→上帝感；榜一贡献极高比例 |
| 3 | 付费直播 | 是 | 稀缺大事件 |
| 4 | 付费连麦 | 是 | 咨询类 |
| 5 | 短视频带货 | 否 | 品控+人设；爆款存留久 |
| 6 | 接广告 | 否 | 按条 |
| 7 | 流量分成 | 否 | 播放量奖励 |
| 8 | 平台任务 | 否 | 小游戏等 |
| 9 | 订阅/会员 | 否 | 短剧微剧 |

**结论**：前四依赖直播，后五不依赖；多数人可不做直播。带货案例：直播间卖牛肉坑位贵销量差 vs 牵牛出镜卖爆——**形式要匹配优势**。

**锚点**：先自选 **≥2** 变现再进三角，否则选题无验收标准。

## 三、自身角：局部优势

### 3.1 标准与方法

- **互联网只相信长板**。
- **百里挑一**：在 100 个普通人里突出即可；**不要**跟赛道王者比。
- **发掘**：外人夸过 **≥5 次** 的事。
- 每人 **多个** 优势，先全勾再筛。

### 3.2 九类优势表

| # | 类别 | 示例 |
|---|------|------|
| 1 | 产品/服务 | 养蜂、修车、地方特产（淄博烧烤：先放大不必最牛） |
| 2 | 身份/职业 | 警察、消防员、出差、行业内幕、全职/单亲妈妈 |
| 3 | 先天资源 | 草原、赶海、家乡、民族 |
| 4 | 技能/知识 | 琴棋书画、钓鱼、极限运动 |
| 5 | 天赋 | 白/好看/高/腿长+一字马 |
| 6 | 爱好 | 梅西集锦、八卦（注意变现限制） |
| 7 | 藏品/财富 | 老车、收藏（控人设别讨嫌） |
| 8 | 借力 | 家人、孩子、宠物、地域热点（淄博） |
| 9 | 缺陷 | 强迫症整理、脑瘫+写诗（勿单独卖惨，要叠加） |

### 3.3 运用六结论

1. 多优势 → 选 **稀缺度高** 的（唱歌易撞职业歌手）。
2. **2–3 个叠加**；8 个塞一账号会砸。
3. **反差**：牧民+清秀（丁真）；牧民+美式英语（野牦牛）。
4. **问他人**，擦掉自恋误勾。
5. 展现优势 = **个人 IP 画像**（别空喊「做达人」）。
6. 人人叠加 **创作能力**（对抗、节奏、拍剪写）——野牦牛再帅剪辑差也走不远。

## 四、用户角：需求三级（完整列表）

### 4.1 框架总图

```
一级 激素级/动物级（最广）
  ├─ 性（繁殖/魅力/爱情，非色情违法）
  ├─ 暴力（=征服：棍枪车钱版图装备）
  └─ 快乐（搞笑幽默；前两者易限流要技巧）

二级 人性级
  ├─ 优越感 ★最重要（姿态放低）
  ├─ 归属感（地域/国家/职业/咸甜之争）
  ├─ 认同/共鸣（吐槽老公/女生困境）
  ├─ 情感治愈（亲情鸡汤鼓励）
  └─ 秩序/逻辑（修蹄、洗牙、游戏、养成报恩）

三级 价值（最后考虑）
  ├─ 实用价值（真懂才能做）
  ├─ 效率价值（书单拆解省时间）
  └─ 欣赏价值（美景赏心悦目）
```

### 4.2 一级展开

**性**：好看、爱情、吸引力——与天赋优势衔接。

**暴力=征服**：《速激》限制级例；车评、豪宅、装备展示均属；**钱是最暴力的**。

**快乐**：搞笑市场巨大；性/暴力更广但易触碰价值观限流。

### 4.3 二级展开

**优越感**：傻号、脱口秀自黑、东北喜剧「土」、新农人观看感——观众在「评头论足」。

**归属感**：河南人看河南赞；一拉一踩（咸豆花）。

**认同**：处境相同（油腻老公、选择困难）。

**情感治愈**：母兄励。

**秩序**：显式（修驴蹄）+ 隐性（养花开花、收养报恩、逻辑自洽）。

### 4.4 三级展开

实用号粉丝天花板低于颜值舞号（**数量级**）。郭德纲：先让人爽/笑，别老上课。

### 4.5 需求三结论

1. **越靠前受众越广**（知识头部 vs 颜值前一万）。
2. **爽点+价值叠加**（变装+认同；女仆装+天津话+快乐）。
3. **主需求选定不改**（皮尤：汽车→时尚，用户需求仍是「美」）。

## 五、3-2-4 四步闭环实操表

| 步骤 | 动作 | 产出 |
|------|------|------|
| 1 平台 | 勾选 ≥2 变现 | 例：短视频带货 + 接广 |
| 2 自身 | 九类勾 2–3 + 稀缺/反差 | 例：消防身份 + 训练秩序爽点 |
| 3 用户 | 定主爽点 1–2 + 价值 0–1 | 例：优越感+秩序；叠加实用 tips |
| 4 验证 | 一条视频 30 秒承诺 + 能否自然挂车/商单 | 不成立则回步骤 2 换叠加 |

### 5.1 选题陈述模板

```markdown
## 账号选题卡
- 变现（≥2）：
- 优势叠加（2–3）：
- 稀缺/反差：
- 主爽点（一级/二级）：
- 叠加价值：
- 主需求稳定性（一年不换）：
- 单条 30s 观众获得：
- 反证失败信号（若出现则调整）：
```

### 5.2 优势 × 需求速配（启发，非穷举）

| 优势型 | 易配爽点 | 易配价值 |
|--------|----------|----------|
| 产品/服务 | 秩序（过程可见）、归属感 | 实用教程 |
| 身份/职业 | 优越感（内幕）、认同 | 效率科普 |
| 资源/家乡 | 归属感、欣赏 | 风物故事 |
| 天赋 | 性/欣赏 | 轻教程 |
| 缺陷+技能 | 情感治愈、秩序 | 励志经验 |

## 六、内容与短视频特性

- 短视频占互联网流量大头；**按需求推送**，非传统人口画像。
- **不消耗观众能量**（躺着刷） vs 长剧共情消耗——故钩子要快、甜头直接。
- **创作能力**要会构建对抗/人设/价值表达。

## 八、起号/改号检查表

```text
[ ] 是否先追热点赛道而未找长板
[ ] 变现 ≥2 且与内容不硬扭
[ ] 优势 2–3 叠加有反差
[ ] 主爽点在前两级而非纯干货
[ ] 爽点+价值在同一条可并存
[ ] 主需求写进选题卡且半年不改
[ ] 创作能力（节奏/文案/剪辑）有学习路径
[ ] 转型时核对：变的只是赛道还是需求也变
```
