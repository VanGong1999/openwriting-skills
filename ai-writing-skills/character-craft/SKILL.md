# Character Craft（人物塑造）

本 skill 自包含网文零基础人物课、热销文三维拆人设、团队人设套路、编剧孵化营人物三讲、十五步「缺陷/对手」、知乎短篇人物进阶与「延迟满足识人」的交叉共识。**人物推动情节**（主角）；情节可推着配角走（工具人）。**保人比保情节更重要**——人崩了，再跌宕也像拼接。

**公式、模板、20 问、对标表**：见 [references/playbook.md](references/playbook.md)。

---

## 适用场景

- 从 0 立主角/重要反派/CP，或修「脸谱化、工具人、人设崩」
- 开篇快速立体、热销向三维落笔、团队/群像关系设计
- 反派博弈、镜像线、催化剂型强主角
- 用「压力下选择」「延迟满足」写识人戏、CP 张力、感情线可信度
- 影视/提案向人物小传、对内草稿 → 对外小传

## 不适用场景

- 纯结构节拍、三幕十五步全流程 → 用 `story-fundamentals`
- 网文扫榜、品类节奏、日更卡点 → 用 `web-novel-craft`
- 短剧分集付费点 → 用 `short-drama-manhua`

## 先判角色档位，再投入笔墨

| 档位 | 塑造深度 | 逻辑 |
|------|----------|------|
| 主角 + 重要配角 + 重要反派 | 完整方法（内外维、四法、弧光/催化剂） | 人物推动情节 |
| 次要配角 | 功能 + 一两笔记忆点 | 情节需要再做 |
| 小 BOSS / 路人 | 可无脑坏，但勿抢戏盖主角 | 工具人 |

**新人建议**：先把 **3–4 人**塑牢再扩群像；慎用网上身高体重式填空模板。

## Agent 工作流（按序）

### Phase 0：一句话人物（30 秒）

- [ ] **人物 = 动作/选择的集合**；观众只见你主动呈现的约 **10%**，幕后仍要构思 **100%** 并精选露出部分。
- [ ] 主角能否用关键词 + 一个印象点说清？（例：桀骜冷 + 鞭打不叫）
- [ ] 主角**有主动力**，忌长期被动围观。

### Phase 1：立体骨架（外 + 内）

**外部**：家庭背景、成长环境（社会层）、外貌轮廓/气质、身体状况（影响选择）。

**内在**：性格（稳定态度 + 习惯行为）、**核心欲望**（可嵌套：表面欲 ≠ 真欲）、**心魔/弱点**（关键时刻挡行动）、**人物弧线**（障碍 → 改变或成长）。

深挖自问：习惯/怪癖？一次选择倒逼出什么经历？网文外貌宜**轮廓与氛围**，勿锁死五官以免改编掣肘。

### Phase 2：独特四法（主角/重要角色）

顺序可打乱，闭环即可：

1. **人物初定**（1–2 关键词）
2. **印象点**（外貌/动作/口头禅/技能）
3. **完善性格**（有小缺点，勿招人烦；高冷主角难写，宜配角）
4. **基本设定**（外貌言行——勿只从这里起步）
5. **争议点**（加深「按在心里」；正派可小，反派宜有理）
6. **合理行为理由**（尤其反派：为何害人、要得到什么）

**四技巧收束**：人设稳定 + 加强印象点 + 争议点平衡 + 行动有理且弧光完整。

人设大变时：**宁可改情节，勿让主角变工具人**。

### Phase 3：快速立体落笔（开篇/热销向）

同一段文字可同时立：

| 维 | 内容 |
|----|------|
| 一维 | 外貌身份、动作语言、脸谱化主性格 |
| 二维 | 身世、金手指/秘密、性格成因 |
| 三维 | 主动抉择推动剧情 |

**开篇**：主性格标签清晰，次性格勿前期堆满；缺陷勿快速抛光。技法：侧面外貌 → 行为升级标签 → 对话身份 → 极端行为夯实性格；外貌**分散、多视角**；对话/感官动词密集增烟火气。

写满**两维**已强于多数同品类基础人设。

### Phase 4：团队 / CP（关系套路）

团队本质模拟**亲密关系**（情/友/亲/师徒）：观众期待从张力 → 和解。

**四组合**：冲突 / **互补** / **镜像**（出身能力似，关键选择分道）/ **反差**。

- **双人**：父子父女、闺蜜、爱情、宠妹等。
- **三人经典**：领袖 + 逗逼 + 智囊（天然 CP 位；盗墓笔记式「全能第三人」易 CP 感）。
- **四人**：领袖 + 能者 + 福将 + 忠诚（西游记型）。
- **五人+**：用四组合叠加；可设**对照人设**（同结构不同境遇 → 人生分叉）。

CP / 感情：**逻辑自洽**（高不可攀 → 铺垫量决定能不能爱）；可开书即情侣规避暧昧台阶。**镜像反派**可对照主角之好；**更坏反派**可在主角灰度时抬受众容忍。

### Phase 5：反派与对手（不降智）

| 原则 | 要点 |
|------|------|
| 十五步 | **骑士对手** = 利益对冲，未必坏人；**确认对手**实力相当、有步骤；忌决战前对手失智 |
| 孵化营 | 对手要具体、强大（含智商）、有计划递进、促主角成长、**主角镜中另一选择** |
| 人设课 | 反派优点多加、坏得有理；无一坏人自觉是坏人 |
| 团队课 | 镜像反派：身世/经历/能力似，节点分道；不能太弱太蠢 |

**侮辱对手 = 侮辱主角**（神剧降智连带主角降智）。

### Phase 6：无成长弧光时 — 催化剂主角

主角强、坚持、目标正确而**自身不大变**时：令其所到之处**催他人成长**（送一辈子「活人回家」、一路治愈群像）。提案时可明说「催化剂主角」。

正剧可描绘**坚持**；喜剧更易拉满弧光。影视购片常筛「第一场到最后无成长」——概率门槛，理解即可。

### Phase 7：延迟满足 — 识人 / CP 金线

**定义**：非硬憋，而是 **A（眼前满足）与 B（更大收益）** 时选更合理项。

- **压力下见真人**：冷静系统易受抑 → 看冲突、利益、竞争中的选择。
- **分事儿看**：工作强 ≠ 感情强 ≠ 对弱者有耐心（克林顿式分裂）。
- **恋人人设**：舍得花**时间 + 情绪**；大五宜人性/尽责性/开放度/情绪控制——两项低危险，三项低勿深交。
- **写戏**：用对立选项、等待、克制、多想一步、第三方视角；CP 甜往往不是 instant gratification，而是**忍 A 求 B**（关系未来、信任、尊严）。

与人物**心魔、缺陷、两难选择**同源：压力下选什么 = 谁是谁。

### Phase 8：短篇 / 知乎进阶（可选）

- 三步：找原型 → 外在/社会/心理三要素 → 反差萌、表象/真相。
- 弧光：**目标贯穿、变化可能、结局关键选择**（《药神》式发光时刻）。
- 短篇：**全篇不宜超过三个核心角色**；场景内三人以内。
- 工具人解法：**不得不的理由** + **可共情弱点**。
- 信念不同 → 冲突（伏地魔 vs 哈利）；人物比情节重要时，情节可让位于人物。

## 输出格式（Agent）

对用户默认输出：

1. **结论**（人设问题或方案一句话）
2. **人物卡**（关键词、欲望/心魔、印象点、争议点）
3. **关系图**（若团队：组合类型 + 谁镜像谁）
4. **风险**（崩点、降智、缺铺垫）
5. **自查清单**（勾 playbook 末尾总表）

涉及「延迟满足识人」时单独标：**压力下行为 + 分事儿维度**。

## 文风与成长需求（速查）

| 文风 | 人物需求 |
|------|----------|
| 飞卢/新媒体/无限/部分快节奏言 | 性格稳定即可；记忆点 + 行为有据；弱弧光；少碰高冷主角 |
| 起点/晋江等长线 | 读者愿跟主角成长 → 弧光、缺陷弥补更重要 |

---

## 与故事 skill 的接口

- 主角**必须有缺陷**（十五步锁定主角）；对抗链 **环境 → 对手 → 自身**，缺陷在拐点与第十步目标升华联动。
- 配角四类：对手、伙伴、导师、爱情；其余工具人；分身 = 从主角**拆缺点（群像弧光）**或**拆优点（互补情感）**。
