# 小红书运营与爆款

## 适用边界

| 适用 | 不适用 |
|------|--------|
| 图文/Plog/口播笔记、薯店、蒲公英商单、搜索卡位 | 纯网文连载、短剧分场剧本 |
| 定位、选题、封面标题、发布后数据复盘 | 代替法律/平台最新细则（遇禁售品类以官方为准） |

**与知乎带货文的差异（并行时记一句）**：知乎重 **长文说服 + FABE + 解决方案/对比/经历模板 + 好物卡片**；小红书重 **封面标题秒停、CES 互动、搜索关键词、用户垂直多赛道、种草氛围、笔记可改标题封面**。同一产品：知乎写清决策链与证据；小红书写「对我有用/令我好奇」+ 场景图 + 人设植入。

## 底层公式

1. **变现**：`流量 × 变现模式`（乘积，非相加）；缺一即弱。变现实战课口径：`产品 × 流量 × 人设`，任一项为 0 则结果为 0。
2. **种草**：卖家秀 ≠ 买家秀——对用户**有用、真实、接地气**的内容才有流量；硬广/纯参数难起量。
3. **定位心法**：**以终为始**——先想清楚要链接谁、赚什么，再倒推内容与账号。
4. **爆款权重**：选题约占 **80 分**；算法看点击率、完播率、互动率，阶梯放大流量池。

## 标准工作流（从 0 到复盘）

```
认知平台 → 定终局变现 → 定位模型 → IP 五件套 → 选题五维度 → 写文案+结构 → 封面标题关键词 → 发布复盘 → 搜索长尾沉淀
```

**冷启动加料（两天实战课合并）**：商业定位（兼容两种变现）→ 内容定位（用户垂直 + Y 字选题）→ 人设（朋友/老师 + 好物分享）→ 三步法选题 → 两步法封面 → 三件套主页。

## 工作流 A：新账号搭建

1. **变现路径**（按粉丝量）：0 粉 → 笔记带货 / 直播带货 / 私域引流 / 知识付费；≥1000 粉 → **笔记带货 + 蒲公英商单**（两条腿，避免只挂橱窗被当硬广限流）。
2. **定位**：有产品/店铺 → **洋葱模型**（商业→内容→人设）；无商业 → **SPRM**（能力∩热情∩资源→检验市场）→ 填价值定位句。
3. **内容**：优先 **用户垂直**（同一目标用户的多赛道需求），非单赛道死磕；用 **Y 字选题法**列需求叉。
4. **人设**：零基础首选 **好物分享**（朋友激动推荐 + 老师经验）；昵称/简介/头像按模板落地。
5. **呈现**：IP 五件套 + 主标签 + 1–2 副标签一致。

## 工作流 B：单篇笔记生产

1. 选题用 **五维度**自检：与我相关 / 对我有用 / 令我好奇 / 让我动情 / 理想自我——**至少命中 1–2 条**，否则自嗨不做。
2. 文案保证 **四种价值**之一：情绪 / 实用 / 决策 / 资讯。
3. 结构四选一：痛点+方案 / 故事+干货 / 聚合清单（须植入自己）/ 走心共情。
4. 封面 3:4、亮点前置；标题含热词；正文/话题多植入搜索词。
5. 发布后看数据；不火 **改标题/封面**（图文可改）；薯条 **只投已跑出的爆款**，不投冷启动。

## 工作流 C：诊断表

对已有账号/笔记输出：

| 环节 | 症状 | 改法 |
|------|------|------|
| 变现 | 粉丝多不变现 | 用户垂直？两条腿变现？简介价值清晰？ |
| 定位 | 跟抄赛道无法接单 | SPRM/洋葱重做；以终为始 |
| 选题 | 只有收藏不涨粉 | 加互动/共鸣/关注钩子，避免纯搬运合集 |
| 算法 | 有曝光不涨粉 | CES：评论+4、关注+8 > 点赞收藏 |
| 封面 | 跳出高 | 前 5 秒/首图亮点前置 |

## 商单报价速查

粉丝数 **÷10 去零头**，上下浮动约 10%（大品牌可略高）。中小博主几百粉亦可接广案例存在，但蒲公英常见门槛 **1000 粉**。
