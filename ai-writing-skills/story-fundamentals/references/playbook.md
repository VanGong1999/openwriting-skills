# Story Fundamentals Playbook（公式速查）

> 本文件为自包含公式速查。口语中的流量、变现数据标注为 **【经验口径】**。平台专属玩法在本文件中标 **N/A（见体裁 skill）**。

---

## 1. 好故事三标准

> **对抗 + 变化 = 吸引；共情 = 留住。**

| 标准 | 作用 | 本质 |
|------|------|------|
| 对抗 | 瞬间抓人 | 人先天爱看冲突，越激烈越好看 |
| 变化 | 保持注意 | 人和动物本能被「变化」吸引 |
| 共情 | 长时间留住 | 人类共通情感、感同身受 |

**用法**：任何情节、场次自问——是否同时服务尺子中的至少一项？

**体育验证（查理）**：拳击（对抗）商业性强；足球（结果难料=变化）；有本国选手/支持队（共情）才熬夜看。

---

## 2. CTFDP（核心创意 / 选材）

> **写什么比怎么写更重要。**

| 字母 | 类型 | 好创意的规律 |
|------|------|----------------|
| C | 角色 Character | 弱者 / 强者 / 组合（全面相反、假身份） |
| T | 目标 Target | 诱人 或 要命；最好 mission impossible |
| F | 幻想 Fancy | 共同愿望 / 共同担忧 / 社会比喻（越幻想越要规矩） |
| D | 困境 Dilemma | 自然 / 人为 / 非自然 / 体制；**角色越普通越好** |
| P | 谜题 Puzzle | 核心=悬念：把结果悬置，提问与解决之间的时空悬置 |

**商业片**：最好 **复合两种**（例：楚门 F+D，哈利 C+F，绝命 C+T）。

**与一句话故事**：孵化营模型 —— 一个「什么人」在「什么情况」下，仍然要「完成什么目标」；目标须**主动**。

**十大设定模型（10 选 1～3，4 为极限）**：困兽、出水之鱼、壮举、人物关系、激励、环境、规则、赌局、解密、对手 —— 详见孵化营精华表。

**目标六方向（6 选 1）**：赢得 / 消灭 / 阻止·守护 / 逃离 / 送达·履约 / 救回·找回。

## 3. 十五步检查清单

**铺垫期（1–7）**：搭设定、铺人物  
**核心期（8）**：主力对抗（贯穿全片）  
**转折期（9–13）**：中点转折 → 高潮前  
**收束期（14–15）**：决战与主题闭环  

| # | 步骤 | 要点 |
|---|------|------|
| 1 | 核心创意 | CTFDP，最好复合两种 |
| 2 | 环境与规则 | 锁环境+定规则；忌双重设定、强设定过度、设定过分创新 |
| 3 | 锁定主角 | 主动力、特别又共情、底线忠诚、可拆分、**必须有缺陷** |
| 4 | 激励事件 | 戳破龟壳；常拒绝，二三次才上路 |
| 5 | 外部目标 | 主动、共情；**可能是错的** |
| 6 | 骑士对手 | 利益对冲，未必坏人 |
| 7 | 添加配角 | 伙伴/导师/爱情；其他工具人；身份可转换 |
| 8 | 主力对抗 | 环境→对手→自身，由小到大 |
| 9 | 故事拐点 | 中间点，虚假胜利/失败；之后无慢节奏 |
| 10 | 调整目标 | 改/调/放大→最终目标，关乎缺陷与主题 |
| 11 | 确认对手 | 实力相当、不低智商、有步骤；换人要伏笔 |
| 12 | 遭受重创 | 至暗时刻、死亡气息 |
| 13 | 解决方案 | 武/智/解读起始道具/大道至简；忌对手失智 |
| 14 | 最终决战 | 主角亲手；时间锁则最后一秒爆炸；可再意外 |
| 15 | 回到原点 | 呼应最初、实现主题、归来已不是少年 |

### 隐形联动（知识体系）

1. **缺陷主线**：激励→拐点→调整目标→对手逼出蜕变  
2. **目标进化链**：创意 T ≠ 外部目标（可错）→ 第十步最终目标  
3. **对手进化链**：骑士对手 → 确认最终对手  
4. **故事是圆**：第十五步呼应第一、二步  

### 第十三步四方向

| 方向 | 备注 |
|------|------|
| 武力 | 最偷懒 |
| 智力 | 机关、漏洞 |
| 解读起始道具 | 开篇道具终局 reinterpret |
| 大道至简 | 本来技能/身份救命 |

### 十五步边界

**能做到**：搭基本结构，获得进一步创作的「源代码」。  
**不能做到**：直接成完整剧本——还需强化人设、增大对抗、视觉化情节、悬念与包袱。

### 关键概念一句

激励事件=戳破龟壳；悬念=悬置；最后一秒爆炸=倒计时必须记到最后一秒才解。

## 4. 三幕 / 四幕与节拍要点

### 博士课：故事本质与三幕

> **故事 = 意外。** 稳定的人被不可抵抗之力打破（第一扇门）→ 挣扎（中间）→ 爬出（第二扇门）。

三幕：**开端（掉进去）→ 中间（挣扎）→ 结局（爬出来）**。

**写作流程（博士）**：故事线（一句）→ 节拍表（15 节拍）→ 场景（40–60，每场景一冲突+转折）→ 人物/情节/对话。

**故事线两要素**：① 意外 = 本可做 A 却做 B；② 故事空间 = 一句可膨胀全篇。

**节拍三节点**（110 页剧本参照）：

| 节点 | 位置 | 含义 |
|------|------|------|
| 中间点 | 约第 55 页 | 「一无所有」的假结局 |
| 反中点 | 中间点之后 | 与中间点完全相反 |
| 绝症时间 | 反中点→结局 | 对人物价值的大考验 |

### 孵化营：三幕 → 四幕

| 三幕 | 比例约 | 四幕对应 |
|------|--------|----------|
| 建制 | 1 | 第一幕·建制 |
| 对抗 | 2 | 第二幕·推进 + 第三幕·转折 |
| 解决 | 1 | 第四幕·解决 |

**四幕节拍（摘要）**

| 幕 | 关键节拍 |
|----|----------|
| 建制 | 开场画面 → 世界 → 人物（救猫咪）→ 激励 → 争执 → 目标 → 主题（约 5 分钟点题） |
| 推进 | 仪式感 → 伙伴/导师/道具 → B 故事 → 游戏时光 → 试炼 → 接近目标对抗 → **故事中点（伪胜/伪败，约 55 分）** |
| 转折 | 否决中点 → 调整方向/方法/对手 → 对抗升级 → 大意外 → **灵魂黑夜/死亡气息** |
| 解决 | 仪式感 → 疗伤 → 大成长蜕变 → **解决悖论** → 决战 → 目标达成 → 结束画面（呼应） |

**解决悖论三法**：重新解读道具 / 孤注一掷 / 自我牺牲。**金牌道具**：开场埋下，末幕 reinterpret。

**影视四硬性**：可视听化、按放映顺序、禁闪回、禁旁白独白（拿事儿说话）。

**拉片打点【经验口径】**：商业片约 35–45 个信息节拍；前史约 10 分钟进戏。

**与十五步对齐**：激励≈4，故事中点≈9，灵魂黑夜≈12，解决悖论≈13，决战≈14，结束画面≈15。

### 事件五要素（孵化营框架）

核心问题（钩子）/ 阻力（三座大山：对手·环境·自我）/ 转折 / 代价 / 结果（高阶：行动失败但目标达成）。

## 5. LOCK 与虐主心法（北大博士课）

> 课程命题：讲故事有规律，可学会；变现路径多样 **【经验口径：期刊/网文/影视等】**。

### LOCK 系统（剧作基本法，最简四元）

| 字母 | 英文 | 含义 |
|------|------|------|
| **L** | Lead | 主角 — 谁的故事 |
| **O** | Objective | 目标 — 他想要什么 |
| **C** | Confrontation | 冲突 — 什么阻止他 |
| **K** | KO | 一击致命的结尾（拳击式收束，非温吞收场） |

与虐主一体：**目标 + 冲突** 决定你要千方百计阻止主角在「第二扇门」前如愿。主角不能放弃的三解法：英雄身份 / 后果严重（生死级）/ 偏执狂。

**36 种情节模式【经验口径】**：讲师称约 90% 能出版传播的故事落在此框架内；其中 6 种最受欢迎（不幸、解谜、为主义牺牲、为骨肉牺牲、恋爱罪恶、恋爱被阻隔）。本 skill 不展开枚举，写大纲时用 LOCK + 十五步即可。

### 线一：虐主（怎么对待主人公）

> **把主人公当成今生最大的仇人，尽你所能虐待他。**

| 技法 | 内容 |
|------|------|
| 三角冲突（邪恶的选择） | 价值大且正面 → 替代方案在反面 → 代价最大（最好涉生命） |
| 怨憎会 | 目标相反、阻挠成长的反派，与主角**捆绑** |
| 怕什么来什么 | 恐惧即剧情燃料 |

### 线二：撩观众（怎么对待读者）

> **把观众当情郎，故事是姑娘。**

| 技法 | 内容 |
|------|------|
| 认知差异 | 观众认知与真相不同步；引导，勿急着消除 |
| 偏离预期 | 先立预期，再偏离 → 情绪 |
| 结论自悟 | 坏人反着写；让观众自己得出结论 |

### 场景微公式

一个场景 = 一个微故事 = **一个冲突 + 一种转折变化**（功能：情绪改变 + 推进目标）。

### 人物三法宝（摘要）

不写典型人物（形容词反替）；表里不一；与缺点斗争至克服或反噬。

### 悬疑写情节（8 步摘要）

目标 → 提高筹码 → 增加危险 → 推向危险 → 利用未知 → 戏剧反讽 → 秘密 → 变身。

## 6. 公共叙事三段论要点（馒头商学院 · 仅结构层）

> **故事的本质 = 建立信任**（听故事分泌催产素）——用于动员、运营、说服的 **Why**，不是院线分场模板。

**底层**：价值观 ──（缺情绪）──→ 行动；故事补情绪 → 唤醒价值观 → 推动行动。

### Marshall Ganz 三段论

| 故事 | 回答问题 | 常见坑 |
|------|----------|--------|
| **我的故事** Story of Self | 我是谁？为何在乎？为何有能力？ | 不真诚、只吹厉害 |
| **我们的故事** Story of Us | 我们是谁？共同传统与挑战？ | 不了解用户、凭空想象 |
| **眼下的故事** Story of Now | 为何现在必须做？希望大吗？做什么？ | 只讲糟糕、不给希望 |

**虚构长片**：三段论 N/A 作主结构；可作宣传片、片头动机、角色演讲 nested story。  
**英雄之路（13 元素）**：坎贝尔模型；要点写**努力过程**、障碍递进、结局大团圆 —— 与十五步「回到原点」可对照，不必逐元素机械填满。

**平台传播技巧**（开场 10 秒、病毒情感、个别人物法则等）：**N/A 本 playbook**（属运营课，非虚构结构必需）。

## 8. 一页对照：三课程体系如何叠用

```
评判：三标准（对抗·变化·共情）
  ↓
种子：CTFDP + 一句话故事（+ 十大设定可选）
  ↓
骨架：十五步（缺陷·目标·对手 进化链）
  ↓
时间轴：四幕节拍 或 博士 15 节拍 + 场景冲突
  ↓
压力：虐主三角 + 撩观众认知差
  ↓
（可选）动员包装：公共叙事三段论
```

**北大课金句**：情节=因果关系；对白是行动；结构失败占多数【经验口径：90%】。

**孵化营金句**：创作是服务观众；熟而后生；悬念=悬而未决的念想（参与·未知·可能·压迫）。

**查理十五步金句**：从观众侧出发，CTFDP 找种子，15 步搭框架 = 源代码。
