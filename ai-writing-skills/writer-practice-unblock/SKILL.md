# Writer Practice & Unblock（训练·素材·破卡·心态）

本 skill **自包含**：写作训练、素材库存、卡文破法、拖延七法、新手误区与同人边界均写在本目录 `references/playbook.md`，发布时无需附带课程原文。

**完整公式与表格**：见 [references/playbook.md](references/playbook.md)。

**与 `story-fundamentals` 分工**：那边管故事结构与节拍；本 skill 管**怎么练、去哪找料、动不了笔时怎么救、心态别歪、同人特例**。

---

## 适用场景

| 用户说什么 | 优先走什么 |
|------------|------------|
| 不知道从哪练、开篇没人看 | 六步构思 + 6000 字钩子训练 |
| 没故事、没素材、写不接地气 | 素材渠道 + 观察者纪律 |
| 拖着不动笔 /「等准备好了再写」 | 拖延分型 + 七法 |
| 很想写但卡住、桥段想不出 | 卡文分型 → 对症 SOP +（编剧向）五查 |
| 新人纠结艺术/才华/赛道/得奖 | 新手误区十条速查 |
| 同人扑街、只会主角碾压 | 互动中心 + 边界 SOP |

## 不适用

- 分集卡点、男女频品类、短剧节奏 → 体裁 skill
- 从零搭 LOCK/十五步完整大纲 → `story-fundamentals`
- 法律咨询、平台版权认定 → 仅给原则，不代判

## 工作流：先分诊，再开药

```text
Step 0  是「不动笔」还是「动笔但卡住」？
        不动笔 → 第四节拖延
        卡住   → 第一节卡文分型

Step 1  若是结构性卡文 → 第二节轮子 / 五查 / 细纲
Step 2  若是表达层卡文 → playbook 描写与工具
Step 3  若是长期没料   → 第三节素材库存
Step 4  若是心态/定位歪 → 第五节误区 + 红娘子六步校准
Step 5  若是同人        → 第六节互动
```

交付时按用户问题**只展开相关章节**，并给出**可立刻执行的下一步**（写多久、查什么、产出什么中间物）。

## 一、卡文分型（先分类再开药）

| 类型 | 表现 | 首选破法 |
|------|------|----------|
| **大情节** | 不知下一大事件 | 回大纲/细纲；渴望—障碍—行动轮子；烂笔头自检 |
| **小情节/走场** | 知目的，不知场景内容 | 明确场景功能 → **沉浸代入**替角色走完 |
| **衔接** | 知下段，不会转场 | 过渡转场法（playbook） |
| **描写** | 主线清楚，卡在遣词 | 反向词典/写作助手 + 长期阅读积累 |
| **桥段洁癖**（编剧常见） | 知这场戏干嘛，嫌桥段俗 | **先保节拍**：俗桥段先写上，后面再改；流畅 > 精彩 |

**编剧向加成**（长篇/剧本卡住）：按 **五查** 顺序跳脱迷局——主题 → 核心对抗 → 主角成长 → 人物关系 → **攻击不足**（多数问题在此）。用「攻击源 × 攻击目标」连线表补缺（见 playbook）。

**卡文三条急救**：① 先保节拍顺下去 ② 素材枯竭则回去调研/看同类型 ③ 讲给信任的人听，看对方反应。

---

## 二、大情节破卡：轮子与细纲

1. **没有冲突 = 没有故事**：还能给主角制造什么问题？
2. **渴望 + 障碍 = 冲突**：渴望要戏剧化（遥不可及或与生死挂钩）；障碍要「不理会就遭重创」以逼行动。
3. **冲突 + 行动 + 结局 = 故事**：轮子卡在哪，改哪一环。

**细纲纪律**：很多卡文是**没有细纲**；想剧情最费时，有细纲后扩写更快。

**红娘子对齐**：卡大情节点时，可并用动笔前六步自检——灵感、读者、热点、框架、字数、人物是否有一环空了。

---

## 三、素材库存（不是天赋，是信息面）

**底层**：想象力不凭空生长，来自认知框架；写代入感需要**生活细节 + 艺术加工**。

**渠道**（日常 Habits，非一次性挖矿）：

- 热搜/社会新闻：多人关注 = 值得观察；打动你的新闻往往也能打动读者
- 大型论坛分板块：看精华/高回复；**旁观者**不判对错，收多元观点与对话颗粒
- 知乎第一人称体验问答：细节可入文；勿迷信「我有个朋友」
- 百度贴吧/豆瓣小组/微博：按题材检索失恋、前任、职场等细分帖

**加工边界**：可虚构、组合、夸张；忌照搬真名纪实侵权。素材像食材：洗、切、烹，不是生吞新闻。

**量变**：一人一点，千人成线，万人成片。阅读面别太窄——只看一类书易写窄。

**工具**：语音输入、手机写作 App、WPS 等任选趁手即可（名称随时代变，选顺手的）。

## 四、拖延：成因与七法

**破除借口**：拖延 ≠ 完美主义（完美主义是边做边要求高）；拖延本质是**懒 + 对延迟回报没信心**（眼前抖音确定，两年后片酬不确定）。「十编九拖」——克服即甩开多数同行。

| # | 方法 | 要点 |
|---|------|------|
| 1 | 目标具体化 | 把遥远回报换成看得见的小奖励 |
| 2 | 计划拆分 | 每天 1–2 小时稳定推进，不拼猝死日更 |
| 3 | 关闭干扰 | 写作期隔离手机/短视频/游戏 |
| 4 | 十分钟法则 | 只写十分钟，常能进入状态 |
| 5 | 先写最爱一场 | 写最有冲动的戏降启动门槛 |
| 6 | 明确「为了谁」 | 外驱：不让老师/搭档/家人失望 |
| 7 | 找个搭档 | 双人组互相督；三人以上易扯皮 |

**行动派**：等「时机成熟」往往错过时机。

## 五、有效训练法（动笔前 + 开篇）

**六步构思**（环环相扣，顺序可弹性，但要想清）：

1. 至少 10 个创意 → 选最喜欢/最熟 → 追问「什么打动我」= **原动力**
2. **读者定位**：写给谁；写自己能驾驭的生活/职业
3. **热点/卖点**：共鸣点 + 赛道冷热（可接受窄市场）
4. **框架**：新闻/身边提炼 + 虚构加厚
5. **目标字数**：练精准控制（如强制 3000 字内完结小故事）
6. **讨喜人物**：美德公约数；反派宜讨厌；标签明朗

**开篇专项**：前 **6000 字** 如钩子；多看对标书开头，可模仿标杆（成熟后脱壳）。要听的反馈：**想不想看下去**；不是指指点点式改稿会。

## 六、新手误区（认知十则）

动笔前若自我怀疑，用 playbook 全文；此处只列**一行锚点**：

1. 搞**服务观众**，非自嗨艺术  2. 才华非门槛，坚持是才华  
3. 别灌输价值观；揭露现实可  4. 创作苦，延后满足反人性  
5. 规则**先熟后破**  6. 个人创作者写擅长/所爱，非追热赛道  
7. 被买下 ≠ 播出，别提前「要红」  8. 别眼高手低判烂片  
9. 逐利无错，能量守恒  10. 先赢观众，非堆小奖

---

## 七、同人与边界

**定位**：二创，自带流量与人设省设；代价是挑读者、上限、原作降温、易写崩。

**核心不是弥补遗憾，是互动**：主角是**引发同人角色反应**的装置，不是 solo 装逼机。

**SOP 摘要**：选 IP → 主角目标 → 设计砸情绪事件 → 写足反应链 → 自检「删掉同人反应还剩啥」→ 改命运要逻辑圆回。

**心声/反差**：内心真实、不装；信息差曝光类可长线。

**边界【需自行核实】**：版权与平台规则因时因地变；课上「硬写」仅为录音口径，**不构成法律建议**；上架以平台实时政策为准。
