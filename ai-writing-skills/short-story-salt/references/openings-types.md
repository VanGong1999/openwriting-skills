# 爆款开篇与类型拆解

> 本文件为自包含技法说明，与 [playbook.md](./playbook.md) 流程互补，专注**类型、开篇、导语与节奏公式**。

---

## 使用说明

1. 盐选短篇约 **8000–15000 字**；制作人常在前 **800 字**形成判断。
2. 开篇前 **50 字**宜有看点（爆款四要素之四）。
3. 本文件不覆盖案件选题表全流程——见 [playbook.md](./playbook.md)。

---

## 一、严选三大类型与细分

### 1.1 三大爆款类

| 大类 | 细分要点 | 求新方向 |
|------|----------|----------|
| **情感** | 古言、现言、世情 | 人设亮点（主动有力女主）、职业差异、人物关系翻新（复仇重心非出轨） |
| **脑洞** | 悬疑向、同人文/IP | 形式创新（对话体等）、非典型视角解读熟悉 IP |
| **真实** | 职业故事、案件解析 | 真实性+稀缺性+获得感；忌纯猎奇血腥 |

### 1.2 鼓励拓展

- **科幻**：生活化情感，读者可理解的讲故事方式（非硬核/软核之争）。
- **悬疑推理**：重逻辑、现实感；与脑洞悬疑差别在于**推理与现实场景**。

### 1.3 情感类速写

- **古言**：穿越、宫斗、权谋空间大；《洗铅华》类穿书女配保命。
- **现言**：现实场景恋爱；可主动型女主（如《男友常来救火》）。
- **世情**：家庭伦理、复仇内核；爱情可点缀非主驱动力（如《我被学渣攻略了》）。

## 二、爆款四要素（选题+开篇自检）

1. **有话题性的素材**：年轻用户话题（室友、职场打压、表白墙等）或周期性热点（彩礼、女性成长等）。  
2. **出人意料的设定**：人设或情节；付费内容忌平淡实录——「有共鸣题材 + 爆款设定」= 创新（夏洛特烦恼例）。  
3. **清晰流畅的主线**：一句话中心；短篇忌空泛（「追求正义」）或跨度太大（弃婴到女皇）。要具体到场景任务（如职称作弊举报）。  
4. **信息量爆炸的开篇**：前 50 字有看点；做不到先拆爆款。

**归纳**：素材有话题 · 设定有特色 · 主线清晰 · 开篇有亮点。

## 三、拆解爆款（17 课）

### 3.1 识别途径（四）

1. **会员页热门榜单**：知乎 APP 底端会员页 →「严选榜单」「故事热度榜」或「严选故事」按热度筛选类型深耕。  
2. **回答数据**：首页/问题下带「会员特权」的付费回答；**上万赞同**常代表经市场检验；**必翻评论区**看打动读者的细节与讨论灵感。  
3. **官方账号**：故事档案局、推理档案馆、小陈神仙研究所、异想奇妙物语、宫墙往事、真实职业故事等推广号。  
4. **站外流通**：高赞严选内容常全网转载，留心出处并反思「为何被大众选择」。

### 3.2 两大步

1. **细读**：分约 10 节带着问题读；重人物、情节点、感受、高亮。  
2. **提炼**：一句话主线（主角谁、遇何事、做什么、结局如何）。

### 3.3 六列表格模板

小节标注 → 小节大意（≤10 字）→ 人物/关系/出场 → **情节（只写行为动作）** → 感受 → 高亮之处。

## 四、结构与开篇（21 课）

### 4.1 单线叙事

一条主线、一种情绪、一个内核；支线只包裹主线；**不可用新故事解释旧坑**。

### 4.2 四句话故事

| 段 | 任务 |
|----|------|
| 起 | 扔进漩涡；悬念/反差/冲突开篇 |
| 承 | 矛盾升级，**勿重复起** |
| 转 | 最高能；推理类可推翻坚信的「真相」 |
| 合 | 圆满交代；短篇忌开放式烂尾、忌合部开金手指 |

### 4.3 开篇三问题

**① 铺垫太多**：删感慨、风景、大段背景；只留 **2–3 个关键细节**；边讲边渗透（《生身母亲来袭》开篇例）。  
**② 亮欲望**：尽快让读者 get 动机；用**冲突开篇**（信息量大）；躺平也要有「啥让他没法躺」。  
**③ 写好第一句话/导语**：简洁 · 耐看 · 定基调；读完有回响，不挂羊头卖狗肉。

### 4.4 导语四元素（满足其一）

| 元素 | 作用 |
|------|------|
| 反常识 | 认知越界，连串问号 |
| 内涵深刻 | 平淡句下藏深意 |
| 情绪波动 | 怒/笑/紧张/难过 |
| 悬念 | 极端情境+谜题 |

例：「腊月初八，八戒死了。」（简洁、耐看、定神怪悲凉基调）

导语约 **100 字、约三行**可作起承转合：起＝起因，承＝冲突升级，转＝打破常规的预期/反转钩子（**不是全文总结、勿泄底**）。

## 五、06 专题：爆款公式与节奏

### 5.1 编辑/达人视角

- 主线体现在**导语**；爽/甜/复仇类型须在导语一眼可见。  
- 免费试读约 **3000–5000 字**；节奏慢 → 完播率低 → 无流量。  
- 爆款公式：**清晰主线 + 精心设计剧情 + 极致人设 + 强代入文笔**。

### 5.2 类型情绪（竹节）

虐/爽/甜公式、十个矛盾点、**冰糖葫芦式**矛盾点；点前置（爆点前置支撑试读）。

### 5.3 节奏参考

- 编辑向：**300 字小矛盾、1000 字大矛盾**（四大坑/竹节）。  
- 短篇无废话；冲突优先于冗长细节（细节易暴露文笔、拖节奏）。

### 5.4 极简情节公式（06）

**情节 =（什么）+ 为什么**（福斯特：王后为何死）。  
缺「为什么」→ 档案式罗列；缺爽虐 → 昏昏欲睡。短篇单线为主。

**三幕式情节线（细分）**：目标 → 阻碍 → 行动 → 结果 → 意外 → 不可回头（第一扇门）→ 更大意外（至暗）→ 高潮（第二扇门）→ 结局回落。

## 六、开篇优化工作流（合并 17/21/06）

```text
定类型+一句话主线 → 导语（四元素之一 + 类型可见）
→ 删废话，2–3 关键细节 → 冲突亮欲望
→ 起承转合大纲，检查承不重复起
→ 免费段：冰糖葫芦矛盾点 + 截断大悬念套小悬念
→ 对内测：朗读、受众反馈
```
