# 编剧拉片 Playbook

> 四方向、信息节拍、幕结构、打点表、前史 10 分钟工作簿、范例要点。

---

## 1. 编剧 vs 导演拉片

| 编剧看 | 导演看（本 skill 不教） |
|--------|-------------------------|
| 类型、幕、悬念、成长 | 镜头、光影、调度 |
| 信息节拍、AB 线 | 场面调度 |
| 细节是否落地 | 场面美术 |
| 情感/情绪曲线 | 表演指导 |

**阅片量**要大，但必须 **第二遍扒节拍**，光看热闹不够。

---

## 2. 四方向检查单

拉完一部片，每方向写 5–10 句：

### 2.1 总体结构

- 主类型与共情点（可叠加多型）
- 四幕起止拍
- 大悬念是什么、何时收紧/解开
- AB 故事各一句
- 主角/双主角成长句

### 2.2 细节元素

- 列出 **3 个**「只有调研才写得出的细节」
- 标出 **悬浮**处（职业戏没干活、设定没用具）

### 2.3 情感

- 关系阶段表：相识→互助→误会→决裂→和解→成为彼此
- 是否完成「**成为彼此的样子**」

### 2.4 情绪

- 笑点密度区段
- 泪点/紧张点
- 是否只有单一情绪（商业片通常多情绪）

## 3. 信息节拍与信息熵

### 3.1 定义

- **一拍** = 观众获得 **一坨新信息**（推进认知/局面/人物）。
- **信息熵** ≈ 全片节拍总数与分配；商业片常见 **35–45 拍**。
- 先数数量，再谈质量；逻辑通 + 数量够 → 下限稳。

### 3.2 动画片偏多的原因

1. 世界观交代成本高  
2. 无明星状态戏拖时间  

### 3.3 无信息拍识别

- 纯风景、重复情绪不提新事、明星发呆——真人片常见；编剧拉片时标「信息≈0」警惕。

---

## 4. 幕结构标尺（90 分钟商业片常用）

| 幕 | 常见拍段 | 结束标志 |
|----|----------|----------|
| 第一幕 | 1–17 | 激励事件：接不可逆任务 |
| 第二幕 | 18–28 | **故事中点**（约 55′ 级） |
| 第三幕 | 29–36 | **灵魂黑夜**（一无所有） |
| 第四幕 | 37–45 | 终场呼应开场 |

> 90 分钟是国内动画长片常见底线时长；合拍片长变化则 **按比例平移**，勿机械套 45 分钟中点。

### 4.1 高频争议纠正

| 误区 | 正解 |
|------|------|
| 中点必在 45′ | 有 ~10′ 前史则中点 **后移**（如 55′） |
| 童年挨打 = 激励 | 激励须在 **现状**；童年属前史 |
| 前史 = 现状 | 前史延伸现状，**不等于**现状 |
| 美国式童年阴影刚需 | 可本土化，勿机械照搬 |
| 只认单主角 | 商业片常见 **双主角**（伙伴第一幕即可同框） |

### 4.2 激励事件之后

- 常伴 **拒绝与争执**（长官不给→贵人推一把）。
- 第二幕首步常 **找搭档/坏人查案**（B 故事启动）。

### 4.3 第四幕「母胎重生」

- 灵魂黑夜后回 **家乡/母体** 汲取新认知。
- **忌机械降神**；用 **旧道具新解读**（线索反转）。
- 终场 **呼应开场画面**。

### 4.4 类型与共情

- 愚者成功 / 伙伴之情 / 探案 **可并存**。
- **共情点**决定观众感到的主类型。
- **大道理给反派**（绵羊/灭霸式），主角用行动点题。

## 6. 前史 10 分钟工作簿

用于判断 **何时进现状**、激励是否在正确位置。

### 6.1 填写步骤

1. 标 **片长** T；算 `前史预算 ≈ T × 10%`（90′ → ~9–10′）。
2. 从开场到 **主题曲/进城/入职/到新世界** 类节点，记 **分钟数**。
3. 回答：

| 问项 | 你的片 |
|------|--------|
| 前史结束时间点（分:秒） | |
| 前史交代了什么（性格/世界规则/主题句） | |
| **现状** 一句话（主角处境） | |
| 龟壳/舒适区是什么 | |
| 激励事件（必须在现状后） | |
| 激励是否让现状「不可接受」 | |
| 若激励在前史 → 标错，重做 | |

### 6.2 现状 vs 前史判定

- **前史**：成形于过去，解释「我是谁/世界规则」。
- **现状**：片子 **现在进行时** 的日常困局（差房、差工作、不被信任）。
- **心理阴影** 单独通常不够激励，除非在现状被触发并迫使行动。

### 6.3 打点联动

- 在打点表 **第 6–7 拍** 类位置注：`【≈10′ 进现状】`。
- 第一幕末拍注：`【激励】`。

## 7. 范例：90′ 动画商业片 45 拍结构要点

> 用于学习节拍密度与幕节点，**不必背台词**；用户对片时自行填表。

### 7.1 关键打点（记节点不记剧情细节）

| # | 节点意义 |
|----|----------|
| 1–5 | 前史：世界观+童年主题+训练蒙太奇 |
| 6 | **~10′ 进主城/奇幻展开** |
| 7–16 | 现状困局：差住房、职场轻视、与搭档初遇冲突 |
| 17 | **激励**：接限时不可逆任务 |
| 18–19 | 被迫与「坏人」结盟查案 |
| 20–27 | 线索链+险境+搭档转身 |
| 28 | **故事中点 ~55′**：保住最后期限 |
| 29–33 | 伙伴关系深化+阴谋上浮 |
| 34–35 | 公开决裂+世界秩序恶化 |
| 36 | **灵魂黑夜**：放弃身份回乡 |
| 37 | 回乡+ **旧线索新解读** |
| 38–44 | 反击+高潮+反派哲理+决战 |
| 45 | 终场 **呼应开场**（典礼/身份反转） |

### 7.2 结构规律

- 前两幕 **拍多、换场快**；后两幕大场面占用时长多、拍数可少。
- AB 线例：明线「消除群体偏见」/暗线「消除自我偏见」——台词喊与世界，行动暴露真偏见。

### 7.3 细节元素学习点

- 多体型动物城交通/门类 = 世界观落地。
- 慢树懒公务员 = **细节即讽刺**。
- 致敬经典 = 情绪加餐，不替代信息。

### 7.4 情感金句

- 双主角 **互补** → 决裂 → 成为彼此（骗子手段 vs 体制内身份互换）。

## 10. 作业：梗概 → 40±5 节拍

1. **1500 字梗概** 定类型与激励。
2. 拆 **40±5 拍**，每拍一行无空话。
3. 标四幕与 10% 前史预算。
4. 用四方向各写一段自检。
5. 删 **连续 3 拍无新信息** 的段落。
