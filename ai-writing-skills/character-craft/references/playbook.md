# Character Craft Playbook（人物塑造速查）

> 自包含公式与模板。口语流量数据标 **【经验口径】**。**【待核实】** 表示行业经验非常识性断言。

---

## 1. 顶层原则

| 原则 | 内容 |
|------|------|
| 谁推谁 | 主角 **人物推动情节**；多数配角 **情节推动人物** |
| 保谁 | 人设大变时 **保人物完整，宁可改情节**；主角慎崩 |
| 呈现 | 构思 100%，观众见 ~10%；只写 10% 则观众只见 ~1% |
| 定义 | 故事中人物 = **一系列动作、选择的集合** |
| 探索 | 每个角色创造都是作者对自我的某次探索；观察供外部，内在须挖自己 |
| 拒绝 | 网上填空式人设模板；无效设定观众无法感知 |

---

## 2. 立体角色：内外维表

### 2.1 外部条件

| 块 | 要问什么 |
|----|----------|
| 家庭 | 从哪来、居住、成员职业、与主角喜恶、家中大事及影响 |
| 成长环境 | 时代、物质精神、社会关系网、工作、政治军事大环境（内环境+外环境） |
| 外貌 | 轮廓、氛围、气质；可柔化；忌过细锁脸 |
| 身体 | 残疾、慢性病等 → **直接约束选择与行动**（自卑、推开爱人等） |

### 2.2 内在条件

| 块 | 要点 |
|----|------|
| 性格 | 对现实的稳定态度 + 习惯行为；可用身边人/作品性格 **相似不抄** |
| 弧线 | 设障 → 经历 → **改变或成长**；为结果铺节点（为何垫底、谁促使转变、中间坎） |
| 核心欲望 | 无欲望无波澜；可「欲=0」再撕开；表面欲 vs 真欲；嵌套升级（钱→宅→人） |
| 心魔/弱点 | 关键时刻**阻止行动**；挣扎处才立体（怕火、软肋是妹妹、抽象恐惧症等） |

### 2.3 知乎三要素 + 麦基两维（短篇/通用）

| 知乎三要素 | 作用 |
|------------|------|
| 外在 | 外貌动作神态，读者第一判断 |
| 社会 | 职业身份、地位、教育、关系 → 影响互动 |
| 心理 | 性格、价值观、秘密、心魔 → **变化根源** |

| 麦基 | 含义 |
|------|------|
| 人物塑造 | 外部可观察：身高衣品职业、大大咧咧/谦卑 |
| 人物真相 | 本心：善恶、冷热、利己利他；**复杂人物常反差** |

**欲望 / 情感 / 信念** 三抓：

- **欲望目标**：动笔前必答「他想干什么、困境是什么」
- **情感**：指过不去的「情结」非日常情绪；友情亲情爱情、特殊境遇、障碍来源
- **信念**：一定要做的事、价值取向；**信念无对错**，不同信念 → 决裂与冲突

## 3. 打造主角：六向 + 四技巧

### 3.1 六向思考（顺序可乱）

1. 人物初定（关键词）
2. 印象点 / 记忆点
3. 完善性格
4. 基本设定（外貌言行）
5. 争议点
6. 合理行为理由

### 3.2 印象点类型

| 类型 | 例 |
|------|-----|
| 行为情绪 | 黛玉爱哭 |
| 口头禅 | 总炫耀旧事被打断，临死说全 → 原来是缅怀 |
| 动作 | 爱摸鼻子 |
| 外貌脸谱 | 大胡子、红脸（慎用过度脸谱） |
| 技能/金手指 | 辨识度 |

### 3.3 性格五条纪律

1. 言行跟性格
2. 不要太完美 → 小缺点
3. 缺点勿让读者反感（病娇好色过头）
4. 性格可变要有转变逻辑
5. 自问能否驾驭（高冷主角极难）

### 3.4 争议点公式

```text
本质（善/勇敢…）+ 印象点 + 可接受小缺点 + 争议点（反派可放大缺点）
→ 立体、接近平衡
```

- 正派：优点突出，缺点酌情
- 反面：优点多加，坏得有理

### 3.5 刻画四技巧（课内「四种方法」收束）

1. **人设稳定** — 不偏性格
2. **加强印象点**
3. **争议点** — 正反趋平衡
4. **成长线完整** — 行动有理可依

## 4. 三维空间落笔（开篇快速立体）

### 4.1 三维定义

| 维 | 典型内容 |
|----|----------|
| 一维 | 外貌、身份、动作、语言、脸谱主性格 |
| 二维 | 背景、身世、秘密/金手指、成因经历 |
| 三维 | 主动抉择、推动情节 |

**质量线**：热销小白常一维+二维一点也能跑量；**写满两维**已超多数基础文。

### 4.2 开篇性格

- 主性格清晰标签；次性格前期勿堆多 → 易被认为崩
- 缺陷勿开篇抛光；文笔不够易主次颠倒
- 例外：对不同人显不同面且服务感情线（温客行式）

### 4.3 落笔 SOP（可迁移）

1. 侧面外貌进场（他人视角）
2. 小动作升级性格标签
3. 对话点明身份
4. 转主角视角行动
5. 极端行为夯实（跪、鞭、不叫等）

**外貌**：分散、多视角；眼用动态（眼尾弧度、睁垂变化）非静态套话。

**感官对话**：动词密集（颤、缩、吻落）→ 画面与烟火气。

### 4.4 言情男主逻辑（大女主/言情）

- 作用：吸睛；女主人设可平但不能讨嫌
- 基础：帅+魅力；近年反差/反派感/病娇/难亲近唯独女主
- **逻辑自洽**：高不可攀 → 攻略；童年不幸+唯一光；铺垫量决定「怎能爱」
- 脸谱组合例：女主桀骜冷傲 + 男主话痨

## 5. 人设亮点四块（团队/单人通用）

1. **人物弧线**
2. **记忆点**
3. **争议点**
4. **人格魅力**（抉择段瞬间拉满：名声/爱情/兄弟 → 选与代价）

**黑化铺垫**：读者知恶、主角不知（伏笔型）；或付出—背叛—不甘链写足。

**感情捷径**：开书即情侣直撒糖（回避暧昧台阶）——商业选择，非唯一正解。

## 6. 团队人设

### 6.1 总原则

- 单人人设靠细磨；团队靠**套路**
- 本质：还原亲密关系；期待从张力到和解

### 6.2 四组合

| 方法 | 含义 | 例 |
|------|------|-----|
| 冲突 | 性格重叠易怼 | 双暴脾气 |
| 互补 | 背景性格特长互补 | 大叔萝莉；忠犬女王 |
| 镜像 | 极似，选择分道 | 复制体黑化线；令狐冲/林平之 |
| 反差 | 破刻板 | 兔子警官；捉妖师×顶级妖 |

### 6.3 人数套路

| 人数 | 结构 |
|------|------|
| 双人 | 父子、闺蜜、爱情、宠妹、人与动物 |
| 三人 | 领袖 + 逗逼 + 智囊女；变体一男二女：小龙女/郭芙、周芷若/赵敏 |
| 四人 | 领袖 + 能者 + 福将 + 忠诚 |
| 五人+ | 四组合叠；对照人设（同家庭结构不同财富 → 人生差） |

### 6.4 欢乐颂式对照

安迪（智商领袖）、曲筱绡（情商能者）、邱莹莹（福将）、关雎尔（忠诚）、樊胜美（与曲对照）。

## 7. 反派：两技巧 + 五特点

### 7.1 团队课两技巧

**更坏反派**：主角灰度时抬对手恶行（拐卖屠城 vs 顺手牵羊）。

**镜像反派**：身世/经历/能力似，关键节点分道；可敌可友后敌；站在其立场写「伟大事业」；临死辩解 = 使命认知。

### 7.2 孵化营对手五特点

1. 具体成人形
2. 强大（**含智商**）
3. 有逻辑、分步计划 → 压力递进
4. 促使主角成长
5. **主角镜中另一选择**（一般状态同，压力下分道）

### 7.3 十五步相关

- 步骤 6：骑士对手，利益对冲，未必坏人
- 步骤 11：确认对手，实力相当、不低智商、换人要伏笔
- 步骤 13：**忌对手突然失智**

### 7.4 重要反派行为问卷

- 为何害人？经历何扭曲？想得到什么？
- 大 BOSS / 重要女配：笔墨多、弧线全
- 小混混：可简单坏

## 8. 催化剂主角

**定义**：自身不大成长、坚持明确，但所到之处**刺激他人成长**。

| 片例逻辑 | 要点 |
|----------|------|
| 落叶归根 | A 送死人回家，B 送活人回家；一路众人找「家」 |
| 疯狂的麦克斯 | 逃命路上助他人回家/活命 |
| 阳光小美女 | 胖女孩坚持选美；家人五毒俱全被她催化 |

**与正剧**：正剧描绘坚持可无经典弧光；商业筛选常要可见成长或 **声明催化剂功能**。

## 9. 配角、分身、工具人

### 9.1 配角功能

1. 推情节（帮或阻主角愿望）
2. 塑主角（侧面印证性格）

短篇：**核心角色 ≤3**；单场景 ≤3 人。

### 9.2 孵化营四类 + 分身

| 类 | 说明 |
|----|------|
| 主角 | 有主动力，切忌被动 |
| 对手 | 见 §7 |
| 分身/伙伴 | 从主角拆出 |
| 爱情 | 传统目标/催化；现代多装伙伴（**拆优点**）或对手 |

**拆缺点** → 群像弧光（西游贪嗔痴、绿野仙踪稻草人狮子铁皮人）

**拆优点** → 互补情感（泰囧责任、布兰与阿多）

想做群体成长拆缺点；想做兄弟/CP 情拆优点。

### 9.3 工具人纪律

- 先问作用、戏份多少
- 带功能登场；相似配角合并
- 加一两笔记忆点
- 不写小传、前史、弧光（四主角色除外）

### 9.4 人物关系图

- 圆心 = 主角 + 分身（目标一致）
- 配角连两线：**关系线** + **作用力线**（仅推进 / 阻碍）

## 10. 共情与压力二元

### 10.1 共情三层

1. **人物**：可怜、可信、可爱（救猫咪）
2. **境遇**：横财、困局等
3. **逻辑/选择**：共情行动而非人设（印度母亲卧底救女）

底层：**观众在角色身上看到自己**。

### 10.2 外部状态 vs 压力状态

- 安逸时人差不多；**压力下选择**才分人
- 勿写天生全善全恶；电视剧群像尤适用

### 10.3 孵化营七步草稿链

```text
外在 → 大环境(规则) → 缺失 → 价值观/龟壳 → 境遇(龟壳碎)
     → 目标(want) → 行动 → 共情点
```

**缺失** 优于窄义「缺陷」（含缺母爱等）。

### 10.4 人物小传五层（对外）

外在（含血统关系）→ 内在（价值观>性格标签）→ 状态（应激、口头禅）→ 行动 → 弧光

转变要**弧**非直角；忌大段台词感化。

## 11. 延迟满足：识人与 CP 写戏

### 11.1 定义

> 为更大未来收益，在 **A 眼前满足** 与 **B 更重要收益** 间选合理项。不是凡欲皆憋。

### 11.2 机制（写戏可用，非医学断言）

| 系统 | 压力下 |
|------|--------|
| 冲动（杏仁核等） | 易激活 |
| 冷静（前额叶） | 易被抑制 → **压力大时见真人品** |

### 11.3 识人应用

| 场景 | 看什么 |
|------|--------|
| 通用 | 冲突、利益、竞争下的选择 |
| 分事儿 | 工作 / 感情 / 对弱者 分开评估 |
| 恋人 | 肯花**时间+情绪**；大五后四项筛风险 |
| 熟怒 | 对熟人宣泄或说明关系里「成本收益」算过 |
| 知行合一四分 | 知行合一 > 知而不行 > 瞎折腾 > 无知无行 |

### 11.4 落到 CP / 感情线

- **甜与信**：延后兑现（忍住冲动表白/占有 → 换信任、尊严、长线关系）
- **虐与刀**：压力下看谁先退回到本能（延迟满足弱 = 冲动索取、指责、背叛短期快感）
- **反派博弈**：对手分步得逞 = 对手在工作线延迟满足强；主角输一阵不写好 = 主角在彼事上算力不足
- **镜像线**：同一诱惑前主角选 B、反派选 A → 分道一眼可辨

### 11.5 训练四法（角色自律时可外化）

物理隔离、转移注意、抽象思维（拉长时间线）、第三方视角 / 想对方在想什么

## 12. 知乎三步 + 趣味套路

### 12.1 三步

找原型（人/新闻/糅合）→ 三要素框 → 个性化（高亮特点、层次矛盾、标志动作）

### 12.2 趣味

- **反差萌**：高手嘤嘤、女高管卡通睡衣
- **表象 vs 真相**：悬疑（老实摊主 vs 杀手）

### 12.3 弧光三件事

| 项 | 要求 |
|----|------|
| 目标 | 贯穿；无目标必卡 |
| 变化 | 目标与能力匹配；至少一次完成可能 |
| 结局 | 关键选择发光（药神式） |

### 12.4 严选向

反套路、接地气（职业日常细节脑补人设）；真实感 = 合理喜怒哀乐非照搬现实。

---

## 13. 影视对标五维

找对标角色后记录：

1. 外在特质
2. 人物真相/本心
3. 目标
4. 情感
5. 信念

再：**聪明 + 长线谋划 + 复仇/动机 + 博弈困难** 等迁移项。

> 定义和标签不能打动人；要知道他**具体**会怎样说话、选择。

## 14. 建立角色的 20 个问题（编剧常用）

主创/编辑用于卡人设时自问；**逐字以你手头完整表为准**，此处为 distilled 版：

1. 姓名、年龄、外貌气质一句话？
2. 家庭与血统？最重要的一段关系？
3. 成长环境里哪条规则最压他？
4. 最大**缺失/缺陷**是什么？
5. 核心价值观或信仰？
6. 表面欲望 vs 真实欲望？
7. 心魔/软肋，何时触发？
8. 压力下第一反应（战/逃/骗/求）？
9. 印象点（动作/口头禅/外形）？
10. 可接受小缺点与争议点？
11. 开场共情点（可怜/可信/可爱/境遇/选择）？
12. 外部目标（want）是什么？可能错吗？
13. 龟壳/小环境是什么？什么事件戳破？
14. 人物弧光：从 A 到 B 的关键节点？
15. 若不是弧光主角，是否是**催化剂**？
16. 在团队中是冲突/互补/镜像/反差哪一种？
17. 与主角/对手的利益对冲点？
18. 对手看到他身上的哪一面自己？
19. 延迟满足：在工/情/弱前三线各举一行为例？
20. 读者会记得的他哪一个选择或台词？

---

## 15. 防崩与实操禁忌

| 问题 | 对策 |
|------|------|
| 脸谱化 | 深挖背景三层；对标五维拆细节 |
| 工具人 | 不得不理由 + 共情弱点 |
| 高冷主角崩 | 改配角或降话量；五大描写跟性格 |
| 配角抢戏 | 新人勿群像；笔墨服务主角 |
| 主角被动 | 给目标与主动解决问题的场次 |
| 暗示变实锤 | 人物转变靠事件堆叠非独白 |
| 物化女性 | 爱情勿仅目标位；现代宜伙伴型 |

**编剧习惯**：主要角色想**演员原型**；编剧自述「书房影帝」演台词。

**主角出场**：仪式感、辨识度（别全场黑衣打六分钟不知谁是男主）。

## 16. 总检查清单（成稿前）

### 主角

- [ ] 有主动力、有缺陷/缺失、有欲望与心魔
- [ ] 印象点 + 争议点 + 行为理由闭环
- [ ] 人设稳定；重大选择符合性格或已铺转变逻辑
- [ ] 弧光清晰 **或** 催化剂功能明确
- [ ] 共情入口至少一层
- [ ] 开篇一维立住，重要戏有两维+

### 重要反派 / 对手

- [ ] 智商与主角匹配；计划分步递进
- [ ] 坏有理；优点可见
- [ ] 非决战降智；镜像/更坏轴至少命中其一

### 团队 / CP

- [ ] 组合类型明确（冲/补/镜/反）
- [ ] CP 有交集逻辑与铺垫量
- [ ] 感情线可见「忍 A 求 B」或等价代价

### 配角池

- [ ] 仅 3–4 人深度塑；余者功能+记忆点
- [ ] 无工具人专场盖主角

### 识人金线（可选场次）

- [ ] 压力下选择与人设一致
- [ ] 分事儿一致或刻意写出分裂（剧情需要）

### 与结构联动

- [ ] 缺陷在拐点/终局目标升华上有回响
- [ ] 对手服务步骤 8–13 对抗升级

---

## 17. 一句总结

> 立体来自 **外内维 + 欲望心魔 + 压力下选择**；独特来自 **稳定 + 印象点 + 争议点 + 有理行动**；酣畅来自 **强队对手与镜像**；深情来自 **延迟满足与情感信念**；成稿前用 **§16 总表** 扫一遍。
