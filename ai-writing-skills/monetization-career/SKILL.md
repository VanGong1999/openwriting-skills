# 故事变现与写作职业

## 何时启用

- 规划 **多通道变现**（投稿、网文、影视、短视频、短剧编剧、IP）
- **投稿出书**：杂志短篇 SOP、平台匹配、编辑关系、先有粉再纸书
- **抖音/短视频**：九种变现方式、三角定位、需求三级与局部优势
- **短剧编剧接活**：征稿/圈子/经纪、片酬批次、署名与后项分账、完成度与改稿
- **全媒体运营**：流量三层、平台选择、定位与斜杠/副业节奏
- 区分 **经验口径** 与可核实平台规则

## 第一原则

1. **谁会为你的故事买单？**（商业写作先于纯技巧）
2. **写作与投稿/推销同等重要**——只写不投 ≈ 失败
3. **先定变现方式（至少两个）再选赛道**（短视频三角定位顺序）
4. **副业默认优于新人全职**；正反馈比「一书封神」更现实
5. 涉及金额、ROI、片酬、分账比例：**标注「经验口径」**，执行前核对合同与平台现行政策

## 变现地图（入口）

```text
                    ┌─ 杂志/期刊短篇（快、热点、投稿册）
                    ├─ 网文长篇（大纲系统、平台气质）
  故事能力 ─────────┼─ 新媒体中篇（强代入、首章生死线）
                    ├─ 影视/定制（故事线 pitch、稀缺题材）
                    ├─ 短剧编剧（项目制片酬、规格交付）
                    ├─ 短视频/IP（三角定位→九种变现）
                    └─ 品牌/说服/带货（情绪产品、一招鲜）
```

路径细节、SOP 与合同清单见 [references/playbook.md](references/playbook.md)。

## 默认咨询流

```text
1. 弄清用户阶段：零基础 / 有稿无投 / 已接单 / 多平台分散
2. 锁定 1–2 个主变现通道 + 1 个储备通道
3. 匹配体裁 SOP（短篇快投 vs 长篇纲 vs 短剧规格包）
4. 若走短剧接单：获客三路径 → 合同三块 → 完成度与修改预期
5. 若走短视频：先选变现方式 → 自身×用户×平台 → 稳定标签
6. 输出行动清单（本周可做）+ 标注经验口径数字
```

## 输出前自检

- [ ] 是否写清 **主变现通道** 与下一步动作（非空泛「多尝试」）
- [ ] 体裁与平台是否 **气质匹配**
- [ ] 收入/ROI/片酬数字是否标 **经验口径** 或「待核实」
- [ ] 短剧接单是否提醒 **一稿多投披露**、违约与署名证据
- [ ] 新人是否避免 **无生活费全职** 与 **只写不投**
- [ ] 未把短剧 **充值逻辑** 当成期刊/广电唯一标准
