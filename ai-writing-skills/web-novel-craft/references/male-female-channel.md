# 男频 / 女频分轨参考

> 本文件为自包含技法说明。小程序短剧男女频办事路径见 [short-drama-manhua/references/playbook.md](../../short-drama-manhua/references/playbook.md)（交叉引用，不重复全文）。

## 使用说明

1. **先定平台与流派**：番茄免费流女频规则（锁 20 万、首秀心态等）见 `playbook.md` §7；勿套到纯订阅男频。  
2. **标口径**：稿费节点、收入曲线为 **【经验口径】**。  
3. **四换三、五要素、前三章**与男频「循环/五信息点」可并存：女频偏人设情绪，男频偏目标爽点循环。

## 一、男频专节

### 1.1 读者与卖点重心

| 维度 | 课内口径 |
|------|----------|
| 感情线 | 多半**不是主线**，常是调味剂（零基础班 15） |
| 人设主战场 | **二维**：用事件、行为、语言堆积（49、精华公式-29）；一维纸面美文男频**不吃** |
| 爽点机制 | **对比** + **读者预知**；循环：目标 + 金手指 + 核心爽点来源 |
| 题材 | 相对更吃题材热度；想快速挣钱课内建议可试男频（09） |
| 开篇 | 约 2000 字内**五信息点**：世界背景 / 穿越重生 / 危机 / 优势+思考定目标 / 进入事件 |
| 稳妥开头五步 | 危机→系统能说清→章末预知→欲扬先抑打脸→收获与下一目标（狂更猫 SOP-10/11） |

### 1.2 男频性格：成长 vs 转变（49 · 公式-29）

> **主性格稳定；次性格可转变。**  
> 区分 **成长**（能力/地位）与 **转变**（性格侧面）。

| | 成长 | 转变 |
|--|------|------|
| 含义 | 能力、力量、身份升级 | 性格→行事风格变 |
| 难度 | 天天写，相对好写 | 很难；写砸=堵点 |
| 读者 | 接受升级 | 少耐心看长期性格虐变 |

**开篇人物稳定原则（49）**：

1. 重生前/惨过去：**几句话带过**，勿十几二十章卖惨。  
2. 要虐则开局性格须「可虐」（软弱、圣母等）；太坚毅虐不起来。  
3. **主性格暂不变**；用**次性格**做可感变化。  
4. 小人物须有强者潜质（倔强、求生欲等）。

**次性格**：贪财、怕死、自私等无伤大雅缺点 → 代入；本心可不变，行动可升华（《大王饶命》式**触动逐级累加**）。

**女性角色在男频（49）**：

1. 制造爽点（美、类型多样）；课内调查口径：**温柔姐姐 > 御女 > 萝莉**【经验口径】。  
2. 可倒贴；男主姿态高级勿油腻。  
3. **正反馈必须写出来**——男主赢须得崇拜等；赢了还被女生嘲 = 大堵点。

### 1.3 男频扫榜与跟风（狂更猫精华 + 零基础班）

- 日扫推荐榜/人气榜；翻前约 **10 万字**，偷「解决问题的方式」，非背剧情。  
- 开题材三问：能否说清爽点**循环**？中位数能恰饭？同人是否改够？  
- 仿写红线【番茄·免费流】：切入点、金手指、第一章结构高度相似易判像。  
- 零基础班：自然榜 + 四表（梗概|卖点|感情线|节奏），问「它怎么帮平台赚钱」。

**选题顺序（男频免费流主推）**：

```text
扫榜 → 书名 → 简介 → 开头 → 写到首秀
禁止：先写开头再补书名
```

### 1.4 男频团队与人设（零基础班 44–45）

- 主性格清晰；前期勿堆复杂次性格致「人设崩」感。  
- 团队：冲突 / 互补 / 镜像 / 反差；反派更坏或镜像主角。  
- 三维可选：心魔、伴侣观、小世界观。

## 二、女频专节

### 2.1 心态与平台【经验口径】

- **不靠一本封神**；番茄是流量池，**数据不好 ≠ 写得不好**（09）。  
- 第一本锁 **≥20 万 + 书册**，勿因首秀差轻易切书（狂更猫 07/26）。  
- 女频起量慢，完结后相对稳；竞争漏斗：日更 → 10 万 → 20 万书册 → 50 万 → 百万（09）。  
- 更吃 **人设 + 情绪**，不如男频极端依赖题材（09）。  
- 想快速挣钱可试男频；写不了就**踏实女频一本本积**（09）。

### 2.2 金手指与题材（09 等）

- 系统 vs 空间：看要不要主线任务防写偏。  
- 穿越/穿书/重生：各自限制见 09 表（重生≠突然变高手；穿书可圆「原书写过」）。  
- 反向读心：女主是剧透工具人，勿积极改命；心声须**可立刻验证**。  
- 大剧情 **4–5 万字** 常见（含支线），不必死磕男频 3 万循环。

### 2.3 开书 SOP（40 · 精华 SOP-16）

```text
定题材（喜欢能写 > 只跟最火）
→ 1 对标 + 5 参考（看前约 60，拆前约 20）
→ 四换三或六本缝合
→ 题目简介
→ 第一章五要素 + 有效突发
→ 第二章兑现人设承诺
→ 第三章按渣男/配角人设分叉
→ 前三章勿与对标情节雷同
```

**纯新人缝合法**：第 1 本对标**节奏**；第 2 本人设；第 3–6 本借剧情片段。**红线：前三章绝不能与对标书雷同**（40）。

### 2.4 第一章五要素 + 突发事件（09/40/45）

1. 女主是谁  
2. 在怎样的世界（重生穿书勿大段前世）  
3. 金手指/优势（系统别话痨站桩）  
4. 面临现状（出场名字约 **3 个内**）  
5. 面对现状的**思考**（主线方向，防写偏）  
6. **有效突发事件**：能接第二章；忌「门外有声音」空钩子  

### 2.5 前三章任务（45）

> **节奏 ≠ 剧情。**  
> 拆对标每章「功能」（重逢 / 立人设 / 透信息），按**相同功能**写自己情节；信息靠对话、心理、议论**渗透**，忌第一章说明书。

### 2.6 套路轮回与十万字（50）

- **主线** ≈ 女主终极目标；**核心** = 增强主线、给清晰目标感（近金手指或人设）。  
- 单剧情 **11 要素**：环境｜优势倚仗｜引入事件｜思考打算｜突发事件｜增加难度｜对手反应｜爽点（读者向后果）｜厉害之处｜震惊｜收获（须服务主线）。  
- **没写过一本：倒推十万字暂不硬套**（50）；先 20 万完结再练。  
- 复仇线 ∥ 感情线**交织**，勿前十万只复仇后十万只恋爱（50 演示）。

### 2.7 扫榜四要素（精华 SOP-15）

```text
每本榜书四问：背景 / 女主人设 / 金手指 / 主线本质
→ 保留主线本质，换其余（四换三）
→ 章节拆：梗概/节奏/五要素/人物/转场/钩子/爽点
```

| 维度 | 男频 | 女频 |

## 五、感情与情绪（女频主战场 · 男频避让）

### 5.1 零基础班感情线定位（15–16）

- 女频：感情线常重头戏；男频：多半调味。  
- **感情线六步**（见 `romance-dialogue.md`）：初相识→暗恋→感情契机→表白→经历磨难→结局。  
- 误区：新手慎一见钟情、勿为恋爱而恋爱、勿为矛盾而矛盾、忌转变生硬。

### 5.2 狂更猫爱情总公式（75）

> **男女主感情好时 → 往分开了写；感情不好时 → 往一起凑。**

解除误会后**必须感情升温**，否则循环空转。

### 5.3 情绪拉扯（70）

> **一方十拿九稳、即将得手 → 被另一方主动终止 → 掌控者换人。**

| 算拉扯 | 不算拉扯 |
|--------|----------|
| 下药以为稳了 → 被扼喉叫停 | 第三方敲门打断 |
| 递杯想结识 → 女主举杯就走 | 换姿势继续（那是开车） |

关键词：**延迟满足、巨大落差**；终止方须**积极主动**。  
剧情拉扯口诀：**逆着距离写**——甜蜜→误会分开→撮合解除→再拆（70）。

### 5.4 男频勿踩的女频解法

- 信息不对等疼爱向拉扯（男主知女主不能行而推开）在女频常见；男频同类易成**堵点**（能睡不睡）（75）。  
- 误会解除须升温；男主不解释、久了变渣感。

## 六、日常怎么写（女频 65）

- 日常**可以出爆款**，但**每段日常必须有目的**（水字数也要有目的地水）。  
- 功能：塑造人设、促感情、舒缓节奏、埋伏笔/信息差、转场、世界观等。  
- **前三章尽量少日常**，节奏要快。  
- 核心：**知道下一场要写什么 → 倒推这场日常怎么编**（逛街同场景可引向盘账、争衣、商机三不同走向）。  
- 外貌：写感觉与服装动作，**不写具体五官**（束缚想象）。

## 七、大女主与无 CP（21）

| 概念 | 课内定义 |
|------|----------|
| 大女主 | 可有可无可 CP；核心 = **人设 + 自主权**（清醒要什么且得到） |
| 无 CP | 无感情线；走**剧情线**成就升级，不是「喜欢但不在一起」 |
| 读者期待 | 职场/独立/反击不公；厌倦纯言情者可看事业爽感 |
| 立人设 | 对比绿茶/恋爱脑；第一章五要素里**思考+决定**最清 |
| 拉扯 | 无 CP 用套路循环/十万字倒推做**剧情线拉扯**，非感情拉扯（70） |

新人慎：规则怪谈/无限流无 CP、纯情绪国运等（21）。

## 八、四换三详解

### 8.1 四元素

**背景、人设、金手指、主线（剧情本质）。**

### 8.2 操作原则

- 新人（约三本内或 60 万字内【经验口径】）：**保留主线，换另外三个**（45）。  
- 现言霸总可换古言、年代、修真、种田、星际等；末世更适打脸，不太适纯追妻甜宠（45）。  
- 设定一变，**剧情走向必变** → 借鉴≠抄袭（40）。  
- 短剧可四换三借鉴，**禁止整段照抄**（09）。

### 8.3 课上示范（40）

古言重生大女主 → 现言穿书大女主：背景/金手指换，**内核**仍为打脸极品亲戚、自己掌命运。

### 8.4 与男频微创新边界

男频番茄仿写避三项同质；女频四换三强调**保主线本质**。二者可并用：同一灵感，男频做循环变体，女频做四换三换皮。

### 8.5 缝合 vs 四换三

| 不会四换三 | 会四换三 |
|------------|----------|
| 1 对标节奏 + 5 参考零件 | 自写情节，只借节奏功能 |
| 先动笔优先 | 拆「章功能」后对位写 |

## 九、检查清单

### 开书前

- [ ] 平台与男女频已定；经验口径已隔离  
- [ ] 女频：喜欢能写 > 只追最火；男频：循环三问过关  
- [ ] 女频：1+5 积累或四换三表已填  
- [ ] 书名简介先于正文（男频免费流强制）

### 第一章

- [ ] 男频：五信息点或稳妥五步  
- [ ] 女频：五要素 + 思考定主线 + 有效突发（非空钩）  
- [ ] 女频：人物 ≤ 约 3 名  
- [ ] 感情线：三章内男主将出场/被提及（75）

### 前三章

- [ ] 女频：信息渗透完毕；人设立住  
- [ ] 与对标**情节**不雷同；可对齐**节奏功能**  
- [ ] 男频：优势展示、章末读者预知

### 连载中

- [ ] 女频：单剧情爽点=读者爽（议论+损失层叠）  
- [ ] 人设与行为一致（55 渣男反例）  
- [ ] 日常段有目的（65）  
- [ ] 拉扯=主动终止，非外力打断（70）  
- [ ] 男频：女性正反馈；主性格稳  

### 长线

- [ ] 女频第一本 ≥20 万再判断切书【经验口径】  
- [ ] 50 万字后再练倒推十万字（50）  
- [ ] 大女主：自主权与人设清晰，非仅无男主（21）
