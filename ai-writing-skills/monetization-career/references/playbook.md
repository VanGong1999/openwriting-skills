# 故事变现与职业路径 Playbook

> 本文件为自包含变现与职业路径手册。金额均为**经验口径**，非平台官方。

---

## 一、变现总地图

```text
                    ┌─ 杂志短篇：热点+快投+投稿册（唯快不破）
                    ├─ 网文长篇：平台气质+大纲日更+编辑关系
  故事/剧本能力 ─────┼─ 新媒体中篇：首章/首3000字生死线
                    ├─ 纸书：先有网络读者证明+选题+合作方
                    ├─ 影视 pitch：一分钟故事线+稀缺题材
                    ├─ 短剧编剧：规格包+项目制片酬+（可选）后项
                    ├─ 短视频：九种变现+三角定位
                    └─ 品牌/带货/说服：情绪产品、一招鲜、情感先行
```

**商业写作第一问：** 谁会为你的故事买单？

**两条腿：** 写作 = 投稿/推销，同等重要。

## 二、体裁与通道对照（红娘子）

| 体裁 | 体量直觉 | 打法 | 生死线 |
|------|---------|------|--------|
| 微型 | 极短 | 命题练构思 | 构思僵化 |
| 短篇 | 杂志投稿 | 热点+快投+开篇高潮+正能量结局 | **唯快不破** |
| 新媒体 | 约3～10万字 | 强代入·快节奏·冲突·白话·翻身套路 | 第一章约 **3000 字** |
| 网文长篇 | 连续剧级 | 千字大纲+分章细纲+按纲日更 | 无大纲必崩 |
| 影视向 | 可拍框架 | 大背景+密集冲突+逻辑+过审 | 不可拍/不过审 |
| 纸书 | 出版体量 | **先粉丝品牌**，再合作方 | 无读者难出 |

### 短篇变现 SOP

```text
1. 盯热点，选题要快
2. 备投稿册（平台/编辑/栏目）
3. 情节新闻化、接地气
4. 开篇最精彩（高潮前置）
5. 结局意外且正能量
6. 持续投；退稿正常；工具提效
```

口诀：**天下稿费，唯快不破。**

### 长篇与出书

- 千字大纲四块：故事 / 人物 / 冲突 / 立意  
- **出书：** 网络粉丝证明「不砸手里」+ 对路选题 + 靠谱合作方  
- 纸书红利已过；勿埋头写没人买的书  

### 定位六原则（钉赛道）

喜欢 → 积累 → 市场 → 类型清晰 → 第一印象 → 不乱换

## 三、北大博士：故事卖钱通道（结构向 pitch）

**命题：** 讲故事有规律，可学会、可变现（≠纯文学天才）。

| 通道 | 关键点 |
|------|--------|
| 期刊作家 | 小人物+重大问题+角度刁钻 |
| 网文 | 低门槛高炮灰，也可能大富大贵 |
| 卖影视 | **故事线 1 分钟**打动投资人；稀缺题材 |
| 构建品牌 | 五模式：斩妖除魔/白手成家/一路追寻/远行归来/重生 |
| 短视频带货 | 情绪产品；一招鲜=熟悉场景+相反内容 |
| 说服 | 情感先行，逻辑后置 |
| 短故事实战 | 自建困局自解；梗概无省略号 |

（虐主/撩观众、三角邪恶选择等**写作心法**归 story 类 Skill；本 Playbook 只取变现表。）

## 四、抖音：九种变现 + 三角定位

### 4.1 九种变现（短视频商业训练营）

| # | 方式 | 直播? | 要点（一句） |
|---|------|:-----:|--------------|
| 1 | 直播带货 | 是 | 全品类难复制；赛道型/自有产品 |
| 2 | 打赏 | 是 | 存在感→上帝感；**经验口径** 约 80% 来自 5% 榜一 |
| 3 | 付费直播 | 是 | 稀缺大事件 |
| 4 | 付费连麦 | 是 | 咨询类 |
| 5 | 短视频带货 | 否 | 品控+赛道人设 |
| 6 | 接广告 | 否 | 按条，含探店 |
| 7 | 流量分成 | 否 | 传统（如西瓜） |
| 8 | 平台任务 | 否 | 小游戏/表情包等 |
| 9 | 订阅/会员 | 否 | 短剧/微剧等 |

### 4.2 三角定位（顺序固定）

```text
① 自身（局部优势）→ ② 用户（要什么）→ ③ 平台（怎么变现）
```

- **先定变现方式（至少两个）**，再选赛道  
- 自身：互联网信**长板**；百里挑一；2–3 优势叠加；人人叠加创作能力（拍写剪）  
- 用户需求三级：激素级（性/暴力/快乐）→ 人性级（优越感、归属、认同…）→ 价值（实用/效率/欣赏）  
- **越靠前受众越广**；爽点与价值**叠加**；选定后**标签稳定**

## 五、短剧编剧：接活 · 合同 · 产业语境

### 5.1 获客三路径（查理短剧 4.3）

| 路径 | 做法 |
|------|------|
| 独立编剧 | 盯征稿；维护圈子/合作方；经纪人/中介 |
| 入职 | 平台公司制 / 大编剧工作室（上手快、署名快） |
| 周边 | 短剧解说等推广业态 |

### 5.2 商业闭环（写长剧者亦应知，≠本 Skill 创作标准）

```text
成片 → 剪线索 → 投放 → 小程序转化 → 充值
```

**经验口径：** 规模投放 ROI 约 **1.2–1.3** 可持续滚量；老师口述链条案例含「收入 2 亿」等，利润与成本须**待核实**，勿当真实现象保底。

### 5.3 合同三块

**1) 稿酬 / 片酬**

| 项 | 经验口径 |
|----|----------|
| 体量 | 一套剧本约 **5–6 万字** |
| 区间 | **1–5**（行业语境为万元/套；录音待核实单位） |
| 上限 | 常有作品+爆款更易谈高 |
| 支付 | 分批；争取**预付多、交付结清**；慎拖到上线才结 |

**2) 署名**

- 片中常不署名属现实；合同约定**海报/组照/开机物料署名**留证据，利于下一部涨价  

**3) 后项分账**

- 新人多无；有作品后可谈  
- **经验口径** 约 **5‰–20‰**（0.5%–2%）  
- 老师举例：千万/亿级充值 × 2% 可得数十万～百万级分成（**演算示例，非承诺**）  

### 5.4 职业底线

- **完成度 = 信誉**：签约须在期限内写完规定字数；半途弃稿 ≈ 违约  
- **修改是常态**：剧本是剧组工作手册；忌亲妈滤镜  
- **死磕一条擅长赛道**，勿空问「哪条最赚钱」却不写  
- **一稿多投**：若多方购买须**披露**；隐瞒可能触赔偿/罚款条款  

### 5.5 投稿规格（短剧创作向）

人物小传 + 故事大纲 + 十集剧本 + 简介 + 信息表；按规格打包；先写完再狂投。

## 六、知乎全媒体与 IP（08-运营与变现）

### 6.1 定位与 IP（找准定位打造 IP）

- **定位不对努力白费**；**想不想要 > 适不适合**  
- 书定位 → IP → 职业 → 人生定位层层递进  
- **点线面体**：一件事 / 能帮的一个问题 / 核心能力 → 时间轴深耕 → 媒介杠杆 → 系统正循环  
- 稀缺性：**个人特点 × 专业积累 × 兴趣爱好**  
- 内容公式：故事 → 问题 → 观点 → 方法 → 总结 → 发问  
- 穿越周期：**少就是多、慢就是快、后发先至**；克服规模/捷径/短视  

### 6.2 全媒体运营（上）

- **全媒体运营** = 在各平台生产让人爱看、能粉丝化、**能变现**的内容  
- 流量三层：获取 → 使用 → 调整（要**能赚钱的流量**）  
- 来源：付费 / 免费 / 私域  
- **公共对比法**：把大众熟知人事与自身内容对比，拉高好奇（讲师称可倍数级提升播放，**经验口径**）  
- 平台选择：知乎 / 小红书 / 抖音等，按人设与变现方式匹配  

### 6.3 斜杠与技能（双师分享）

- 改变模型：思维（by design）→ 行动（by focus，小半径）→ 收获（leverage）  
- 成长型思维 + 自律；避免「浅尝辄止的梦想家」  
- 刻意练习、反馈、导师；**行动半径要小**（如每晚十个俯卧撑式目标）

## 七、副业心态与新人节奏（九格开营等）

| 原则 | 要点 |
|------|------|
| 勿急于全职 | 备约 **一年生活费**；**经验口径** 80%–90% 人经历 3–6 月无连续收入 |
| 副业更持久 | 期待值低，偶尔过稿更易坚持 |
| 勿一书封神 | 先用**最短路径正反馈**（如新媒体/小程序文） |
| 质量优先 | 未入门时质量 > 数量；可日写百字精磨 |
| 指数曲线 | 约半年习惯后收益可能指数上扬（**经验叙述**） |
| 跟自己比 | 容错空间；坚持 ≠ 强迫自己 |

训练营机制举例：**经验口径**「6 个月月稿酬达 1 万」类奖励 — 仅作课内激励，非行业 universal 标准。

## 八、决策树（给用户 actionable）

```text
目标现金快？
  ├─ 是、能日更热点 → 杂志短篇 SOP + 投稿册
  ├─ 是、能写噱头文 → 新媒体首章 3000 + 平台匹配
  ├─ 是、有脚本能力 → 短剧征稿+规格包（同时练完成度）
  └─ 否、愿深耕 → 网文大纲跑 + 单一标签六年原则

目标 IP/流量？
  ├─ 先定 ≥2 种变现方式
  ├─ 三角定位填表
  └─ 全媒体只选一个主平台先打透

已有短剧甲方？
  ├─ 读合同：预付/交付节点/署名位置/后项
  └─ 多投披露 + 修改预期

目标出书？
  └─ 先证明读者 → 再选题与出版合作方
```

## 九、收入数字复述规范（Agent 必守）

凡提及下列类别，句首或句末标注 **「经验口径」** 或 **「待核实」**：

- ROI 1.2–1.3、充值 2 亿/利润三四千万等短剧链条案例  
- 片酬 1–5 万/套、后项 5‰–20‰、分账演算  
- 打赏 80%/5% 榜一、公共对比 2–3 倍播放  
- 九格月入/稿费奖励、八零九十无收入阶段比例  
- 任何「市场 XX 亿」行业规模预测  

**法遵与结算**以书面合同、平台后台、税规为准。
