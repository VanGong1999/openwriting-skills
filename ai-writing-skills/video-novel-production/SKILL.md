# 视频小说制作

## 形态定义

**视频小说** = 以配音叙事为主、画面多为火柴人/分镜图象的 **2–4 分钟**（约 3–4 千字，语速参考约 333 字/分钟）叙事视频。平台可非独家多投；连载单集须 **独立能看懂**。

## 与文字小说的四差异（写稿铁律）

| 维度 | 文字小说 | 视频小说 |
|------|----------|----------|
| 开头 | 约五六百字耐心 | **第一句**给齐：类型 + 主角 + 矛盾 |
| 主线 | 主线+支线 | **仅单一主线**，无支线 |
| 过程 | 可数千字一段 | **约 30 秒**（≈166 字）至少 1 梗/反转/推进 |
| 连载 | 可默认读过前文 | 每集 **一句话前情提要** |

**行业参照**：搞笑前 8 秒要有笑点；知识类约 30 秒内回应标题承诺。

## UP 主入场五建议

1. **定位** = 兴趣 ∩ 擅长 ∩ 市场（多试再收敛，勿过早锁死）。
2. **做擅长方向**才能接住爆发流量。
3. **记忆点**（画风/声音/文风）靠重复植入，勿随意换配音人设。
4. **跟市场调**，砍掉低效系列（如他人配音导致声线混乱则收回自配）。
5. **多平台布局**，不因单平台暂时低迷而弃坑。

## 写稿工作流（五步法）

1. 先写全文（别卡细节）
2. 润色删废句
3. **标爽点**
4. 缩到一页看标注分布
5. 目标：**爽点均匀密集**；删只增气氛、不改变意的「2、3、4 级句子」（视频里每句都是时间）

**练笔**：写「1」让读者感受「2、3」——能删则删。

## 制作工作流（制作链）

```
完稿 → 分解镜头 → 人设/火柴人 → AU 配音 → PR 合成 → 导出
```

| 环节 | 工具要点 |
|------|----------|
| 画面 | Procreate 1920×1080；**分图层**（脸/发/五官/四肢）分组；PNG **透明底** |
| 配音 | AU 多轨 48k；轨道1 本人、2 他人、其余 BGM/音效；对轨、降喷麦/噪 |
| 剪辑 | PR：图片追加式 **或** 口型/表情/关键帧互动式；**BGM 不盖人声** |

## 代理输出规范

帮用户写/改稿时默认交付：

1. **开篇一句**（类型+主角+矛盾）
2. **分镜摘要表**（每 30 秒：画面意图 + 文案片段 + 爽点类型）
3. 连载时加 **前情一句**
4. 可选：火柴人图层清单、AU/PR 操作提醒（见 playbook）

## 自检

- [ ] 第一句三要素齐全
- [ ] 无支线、无长跑铺垫段
- [ ] 每 30 秒有推进/梗/反转
- [ ] 爽点分布均匀
- [ ] 分集可独立看懂
- [ ] 声画记忆点一致
