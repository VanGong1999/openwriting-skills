## 一、唯一标准：足够有吸引力

| 口径 | 来源 |
|------|------|
| 网文耐心 | 可能半章、一句就劝退（25） |
| 开篇手段 | 冲突 / 悬念 / 设定可叠加，**非**硬凑「三章小高潮」（28） |
| 与纲的关系 | 在整条故事线上选**足够有看点的时间点**切入，非人生起点流水账（25） |
| 书名→简介→正文 | 书名亮核心 → 简介亮冲突悬念 → 前三章兑现吸引力，章末瞬间悬念（精华） |

**零基础班开篇路线 SOP**

```text
先问：读者想看深陷困境的人生，还是平凡幸福流水？（多数选前者）
→ 选路：冲突 / 悬念 / 设定（可叠）
→ 按所选路套用对应公式
→ 与狂更猫「扫榜→书名→简介→开头」顺序并行时，勿先写开头再补书名【番茄·免费流】
```

## 二、冲突开篇：「一个乱字 + 两个关口」（25–26 · 公式-12）

### 2.1 「乱」

- **定义**：生活失平衡、反常之事切入；今天发生的事跟原来不一样了。
- **烈度**：都市玄幻/仙侠可贴生死；校园/都市宜先接地气再撕大口子（《大王饶命》路人消失→当众杀人）。
- **对比**：「和妻子醒来」平 vs「和老王的妻子醒来」乱。

### 2.2 第一关口：有进无回

- 挑起行动欲望；主角卷入麻烦**无法脱身**。
- 关尊严＝回头心理之死；关生命＝回头生死险。
- **反例**：配角轻劝「不努力就嫁人」——压力太浅，不宜当关口。

### 2.3 第二关口：推动前进

| 方向 | 作用 |
|------|------|
| 正向 | 麻烦中发现线索/助力，困境将解 |
| 负向 | 再遇危机，困境更难 |

两关口可搭配、可重复；故事自由拆，不必死扣唯一节点（斗破：废柴嘲笑→父亲施压→退婚三年之约→药老为正向第二关口）。

### 2.4 与旧写法的差别

| 旧 | 新 |
|----|-----|
| 找一个麻烦再解决 | 乱 + 一级→二级→三级压力递升 |
| 层次感弱 | 进关口后主角必变、方向必变 |

### 2.5 做好冲突三条标准（26）

1. **微创新**：阅读量规避八成雷同套路。  
2. **可共情**：紧贴人物，正常人接触不到的事难代入。  
3. **反转解决路径**：读者以为 A，办了遇新麻烦或触犯规则。

**硬条件**：势不两立两面**不能轻易调和**；须给主角「不行动就死/崩」理由（生理之死或心理之死，如三年之约式羞辱）。

**实践**：用「乱+两关口」拆几本对标开篇；自问每一压是否到「不得不行动」。

## 三、悬念开篇：四类 + 全书贯穿（27 · 公式-13）

### 3.1 成立条件

结果悬而未决 → 读者猜 → **当下得不到答案** → 必须往后读。

### 3.2 四类悬念

| 类型 | 悬的是什么 | 例（课内） |
|------|------------|------------|
| **核心悬念** | 主线能否达成 | 三年之约；献祭重生能否报仇；悬疑真相 |
| **超级悬念** | 说不清发生什么，主角读者同步懵 | 全球高考式生死考；人口失踪无新闻；魂殿级未知反派 |
| **场景悬念** | 进场景有目的，能否克服障碍 | 救人遇险；车厢谁牺牲；打斗谁赢、得何奖 |
| **段落悬念** | 一连串场景共享的更大未知 | 救人反被挟持如何逃脱；恶斗能否到安全车厢 |

《西游记》对照：段落（大闹持续？）/ 场景（斗二郎）/ 超级（真假猴）/ 核心（取真经）。

### 3.3 运用原则

- **不只开篇**；段落、场景、句段都宜留「想解答的点」（27、38）。
- 核心悬念网文长篇可**迭代添加**，勿过简一猜即中。

## 四、设定开篇：背景 + 人物（28–29 · 表-14）

### 4.1 吸引力总表

| 大板块 | 方向 |
|--------|------|
| 背景 | 世界观 / 金手指 / 特殊经历（重生穿越穿书等） |
| 人物 | 特殊职业·火热爱好 / 身份·性格反差 / 人物魅力 / 热点元素 |

**男频**偏重背景设定耳目一新；**女频**更擅开篇烘托魅力（29）。

### 4.2 背景三方向要点

1. **世界观**：只改少点、其余近现实，好带入（全球高武武科）。  
2. **金手指**：别出心裁难；细节见 `golden-finger-setting.md`。  
3. **特殊经历**：重生穿越等宜**尽早**亮出整书卖点。

### 4.3 人物注意（29）

- 服务情节；忌过分冷门圈；亮点随情节渗透，忌说明书。  
- CP：**互补反差**，至少一人情绪外放，否则高潮难推。  
- 热点：综艺人设、梗、社会事件作燃料。

**兜底**：仿写爆款开头框架（拆书四表），禁止抄袭正文（28）。

## 五、狂更猫：前五章基调与信息点（04 / 27 / 46）

### 5.1 总基调（04）

> **前五章唯一基调 = 展示主角优势（金手指）**  
> 金手指＝主角优势，不限于系统；医生展医术、通晓人情世故亦可。  
> 无优势者不成主角（盘点文分支课内另论）。

### 5.2 第一章三件必做（27）

1. **世界观 + 基础运行规则**（非仅时间地点；同人标明时间线）。  
2. **身份 → 拉出主线目标**（目的在目标不在身份本身；目标由身份+金手指定）。  
3. **金手指**：压缩（非跳过）不爽过程；**提出问题后再给**，比平铺功能列表重要。

**慎用事件开局**：第一章信息未清就扎进别人目标的事件里 → 易乱（27）。

### 5.3 男频第一章五信息点（46 · 约 2000 字）

| # | 信息点 |
|---|--------|
| 1 | 世界背景（约 100 字） |
| 2 | 穿越/重生（可与危机调换序） |
| 3 | 当下危机或事件 |
| 4 | 优势/系统 + **思考定目标**（思考不可省） |
| 5 | 进入世界/事件（副本、现场等） |

缺一项＝不合格；卡文时可把五项存手机对照。

**第一章三大忌**（46）：大段冲突打脸（读者未认人）；大段对话分不清主角；无节制背景或纯炫文笔零信息。

### 5.4 万能稳妥开头五步（04 · 循环步骤，可跨章）

```text
① 穿越醒来+世界观+危机或催系统+出系统说明能力+章末读者预知
② 铺垫视角（震惊对象）→ 回主角定小目标+再强调优势
③ 增加视角（直播/专家质疑等）
④ 欲扬先抑→装逼打脸（必有对比）
⑤ 爽点扩散+收获盘点+下一目标仍服务大目标
```

### 5.5 第 2～5 章（27 / 46）

- **非**一个完整大循环，而是拉齐：人物动机、场景服务事件、矛盾。  
- 配角也要目标；龙套不给心理活动。  
- 场景宜极端（符合或打破固有印象）；代入靠心理共鸣。  
- 46：第二章推进剧情；第三章起可有小震惊/小爽点。

### 5.6 开篇须埋：设定 + 循环（46）

- 设定决定能写多长、有无提升。  
- 第一章是否建立**可重复的循环引擎**决定能否写长（反例：仅有弹幕无升级 → 三万后乏）。  
- 循环通俗理解：同套路换场景/怪物（西游、武林外传式）。

## 六、男频 vs 女频开篇差异（精华交叉）

| 维度 | 男频（46/04） | 女频（playbook / male-female-channel） |
|------|----------------|----------------------------------------|
| 信息 | 五信息点/稳妥五步 | 五要素+有效突发事件接第二章 |
| 节奏 | 约 2000 字浓缩 | 忌第一章人过多、空钩子、设定后置第二章 |
| 展示 | 优势+思考+预知 | 信息对话心理渗透，拆对标「章功能」 |

## 七、开篇自查清单

### 吸引力（零基础）

- [ ] 非硬凑三章高潮；标准是否「足够吸引」  
- [ ] 冲突路：乱 + 两关口 + 不得不行动理由  
- [ ] 悬念路：四类中至少一种清晰，章末有卡点空间  
- [ ] 设定路：背景/人设亮点与书名简介一致，非说明书堆砌  

### 信息（狂更猫）

- [ ] 世界观规则读者一眼懂  
- [ ] 身份→目标→金手指因果链通  
- [ ] 思考定目标已写（不可省）  
- [ ] 章末读者预知：优势将如何作用  
- [ ] 男频五项 / 女频五要素是否齐全  

### 避坑（04/25）

- [ ] 前五章展示主角优势  
- [ ] 下一小目标仍服务大目标  
- [ ] 避免开篇上千字纯打斗、主线不清（22 课·打斗专文）  
- [ ] 避免只陈述无动因（14 课：多问为什么）
