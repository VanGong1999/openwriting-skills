# 短剧与漫剧实操 Playbook

> 短剧、AI 漫剧、视频小说实操合集，可独立使用。执行时以具体平台方最新规范为准。

---

## 一、产品认知与商业闭环

**品类重点：** 小程序**竖屏重付费短剧**（非横屏网剧、非仅免费竖屏流量款）。

**运营闭环：**

```text
成片 → 剪线索素材 → 投放获客 → 小程序转化 → 充值
```

- 规模投放常见门槛：ROI 约 1.2–1.3 可持续滚量
- 制作量级（课程口径）：约 30–60 万 / 6–10 天 / ~10 景·角 / ~100 集
- **付费买的是明确爽点**，不是含糊的「吃席式」体验

**三类常见误区：** 神话赚钱≠无流程；纯小白也要学结构；长剧经验≠对短剧降维打击。

## 二、选题系统

### 2.1 基础公式

```text
选题 = 爽点 + 共鸣（YY）+ 故事壳
```

- **共鸣**：五大爽点 × 现实生活困境；主力用户偏强 YY 人群
- **爽点可叠加**（爆款常「全家桶」）；投放须分清男女频

### 2.2 极简爽剧公式（6.8）

```text
爽剧 = 想怎样 + 通过啥
```

| 项 | 要求 |
|----|------|
| 想怎样 | 欲望具体、过瘾、大众可共鸣（打谁的脸、怎么打、在哪打） |
| 通过啥 | 广义金手指：相对合理 + **规则极简**；创意砸在欲望，不砸在设定书 |

### 2.3 投稿实战（5.1）

| 类型 | 策略 |
|------|------|
| 满级号 | 有创意的**明确目标** |
| 小号 | 优先**开挂三型**：①单一金手指（预知/隐身等）②集成身份道具（多技能一套理由）③重生（悔不当初，共情强） |

### 2.4 五大爽点

| # | 爽点 | 题材举例 |
|---|------|----------|
| 1 | 两性 | 离婚、赘婿、霸总、宠爱 |
| 2 | 征服 | 战王、暴富、金手指、穿越征服 |
| 3 | 优势 | 神医、官场、阶层碾压、家族系统 |
| 4 | 归属 | 帮派、门派、家国情 |
| 5 | 秩序 | 复仇打脸、善恶有报、重生改命 |

逻辑链：繁殖→征服→优势/归属→秩序。  
**两性见证**可作全模型放大器（有人看着，爽感倍增）。

### 2.5 故事壳（短剧用前四，忌谜题主壳）

| 壳 | 入戏点 | 短剧 |
|----|--------|------|
| 人物导向 | 这人太特别 | ✅ |
| 目标导向 | 要干成某事 | ✅ |
| 困境导向 | 陷入大麻烦 | ✅ |
| 奇遇导向 | 穿越/重生/开挂 | ✅ |
| 谜题导向 | 谁干的怎么回事 | ❌ 易理性冷静，不利充值 |

## 三、人物与叙事纪律

- **经典叙事：** 一个绝对主角、一个视角、线性推进
- **人物 = 行为总和**；小传：**身份 / 缺陷 / 境遇 / 目标 / 行动**
- 共情：**可怜 · 可信 · 可爱**（及课中延伸人设法）
- 设定：**最多约两个**且合逻辑

### 男女频办事路径（高频易错）

| | 男频 | 女频 |
|--|------|------|
| 办事 | **自己动手**变强/报仇 | **借男人之手/借势**、先获爱 |
| 雷区 | — | 女主天天亲自武力揍人易跑偏 |
| 拉片抓手 | 复仇期待+赐福双轨；量化升级 | 女主画像×善良因果×观众开天眼 |

本质：能力多来自「从天而降」；差别在挂在自己身上还是身边男性身上。

## 四、二十节拍（短剧全剧骨架）

体量约 150–200 分钟净内容（~6 万字量级）。**强度可调，节拍与节奏不可丢。**

| # | 节拍 | # | 节拍 |
|---|------|---|------|
| 1 环境规则 | | 11 调整目标 |
| 2 主角登场 | | 12 确认对手 |
| 3 激励事件 | | 13 冲突升级 |
| 4 外部目标 | | 14 第一次决战 |
| 5 走出舒适区 | | 15 遭受重挫 |
| 6 初尝红利 | | 16 疗伤反省 |
| 7 伙伴/爱情 | | 17 找到方案（须牺牲/成长） |
| 8 起始对手 | | 18 最终决战 |
| 9 阻力对抗 | | 19 胜利后不狂 |
| 10 故事拐点（约一半） | | 20 回到原点 |

**大转折（腰）：** 落在物理时长正中；五类故事五种转法（成长/目标/困境/幻想/谜题——短剧少用谜题壳）。

**场（原子单位）：** 每场必须 **交代信息 + 推进剧情 + 带来变化**，自带小起承转合。小程序少换景时，仍按**集**重置任务与对抗。

**防流水账·三角设计：**

```text
目标 → 反义铺垫 → 逻辑回落 → 抵达目标
```

**开场方向（7 种）：** 环境 / 技能炫技 / 共情 / 激励 / 动作（须绑技能或激励）/ 悬念（捞后戏）/ 回忆（后文必有用）。详表见 [beats-hooks-scenes.md](./beats-hooks-scenes.md) 第四节。

## 五、台词、桥段与充值心理

### 台词

```text
态度 + 信息 + 潜台词
```

短剧加强：信息量大、情绪拉满、舞台化/概括、个性化；台词是行为补充。

### 八桥段关键词（场级爽点）

打脸 / 碾压 / 运气 / 地位 / 集体 / 因果 / 极限 / 哲思（慎用过度）

### 悬念与充值（预期管理）

- 充值 = **To C 预期管理**
- 双轨：**节奏被动上头** + **主动期待（悬念优先）**
- 信息差：常优**观众知道、角色不知道**（或按课中四属性设计）
- 兑现：**一加一**（满足预期 + 再加一截惊喜）
- 贯穿期：**一次只揣一件事**

## 六、漫剧（AI 动态漫 / 仿真人漫剧）流程

与短剧**共用爽感与打脸节奏**，形态差异：分镜+台词、单集字数/场景上限、过稿与去 AI 味、国内/海外稿费档位不同（海外部分渠道收益更高；自营可避免第三方高额分成）。

### 6.1 准备

- **AI 工具**：DeepSeek/豆包（主）、辅助编辑/去 AI 味工具
- **新人**：仿写训练——拆解消费榜热门文约 **30 篇**（黑岩/知乎/抖音等），情绪线与词汇密度 **1:1** 对标
- **核心梗提示词要素**：题材要求 + 注意事项 + 生成目的 + 格式（核心梗 / 标签 / 主角动机复仇线+事业线 / 主角危机 / 开篇结构：自述+配角危机+震惊+小弟或金手指登场）

### 6.2 标准流水线

```text
(1) 定核心梗：男频脑洞向为主；女频婚恋甜宠重生等；人设微创新+逻辑自洽；爆点前置
(2) 生成前十集大纲（表格转文字时注意 DS 与文字版细微差别）
(3) 生成第一集：分镜画面 + 台词，禁小说化形容词
(4) 每 10 集一轮；单集 AI 校正（见 6.3 提示词）
(5) 去 AI 味：场景化描述替代概括；忌全篇无人工（易被拒稿）
(6) 手动精修 ~20%：逻辑、删 AI 套话、镜头合并、人设语言、伏笔钩子
(7) 扩展后续大纲 + 人物小传 → 循环 (3)–(6) 至完稿
```

**分集正文提示词要点**：

```text
按分集大纲生成第一集；剧本非小说；严格「分镜画面 + 台词」：
分镜一：画面内容（具体可视）
A：（情绪）台词
去除形容词与小说化描述；情绪用简短台词标出。
```

**单集校正提示词（通用）**：

```text
单集过少则结合大纲补情节与台词：每集 800–1200 字，≤3 场景；
台词（含旁白）≤500 字；对话须推动情节；集尾留悬念。
```

**去 AI 味**：删「综上所述」「值得注意的是」；减排比比喻华丽符号；**场景化**替代总结句；全稿 AI 比例过高时编辑直拒（常见阈值约半数 AI 痕迹即高风险）。

### 6.3 漫剧内容硬要求

- 开局：**强冲突、强情绪、强噱头、强画面**；节奏快；男频 **装逼打脸** 高能；受众偏下沉男性
- 题材窗口（随市场变）：国内「追妻火葬场」、海外「黑手党+霸总」等——以当期编辑收稿为准
- 男频动态漫擦边须**高级化**（审核抓不到明显违规点），底线仍是合规
- **赛道×形式**：仿真人 AI 剧（强情绪女频、宅斗甜宠逆袭）/ 2D·3D（玄幻大场面）/ IP 改编 / 沙雕（慎长期）

### 6.4 漫剧全剧开场类型库（与短剧七开场并列使用）

按题材择一：**虐点**（要够狗血，如活埋级惨）/ **危机** / **系统绑定** / **重生遗憾** / **掉马大场面** / **规则怪谈** / **搞笑** / **甜宠** / **高能名场面**（爆炸打斗异能）。

### 6.5 每集结尾钩子（必填项）

1. 台词预示冲突/秘密  
2. 主角立 flag  
3. 宣布震惊事件  
4. 定格震惊表情（如「等一下！」卡黑）  
5. 反转、未答问题、神秘对白、预言、转折点  

### 6.6 百集四幕通用模板（与 20 节拍可对照）

每幕约 25 集；**每集须推动主线**；爽点节奏：**每集小爽、约 5 集中爽、约 20 集大爽（放付费卡点后）**；打 Boss **必有收获**；**幕末预示新危机**。

| 幕 | 集数 | 核心 |
|----|------|------|
| 一 | 1–25 | 立人设世界观；1–3 虐+金手指+首次打脸；收小弟/宝物；11–15 反杀准 Boss；24–25 击败单元 Boss+闪回埋悬念 |
| 二 | 26–50 | 扩地盘、收核心伙伴、规模升级；当地大势力摩擦→单元 Boss→决战得身世线索 |
| 三 | 51–75 | 低谷：误解孤立、假死、绝地传承；回归清算背叛者；惨胜付代价 |
| 四 | 76–100 | 真 Boss、填坑反转、连战高能；留 3–5 集收尾；可开放结局或第二季钩子 |

**第一幕分集锚点（手写提纲用）**：

- 1–3：虐、觉醒、必有小胜打脸  
- 4–5：第一个小弟/宝物/技能  
- 6–10：清小怪攒资源  
- 11–12：被准 Boss 压制  
- 13–15：反杀准 Boss+收获  
- 16–20：备战队 Boss、第二批帮手  
- 21–24：交锋→危机→绝地反杀  
- 25：庆祝+研究标记+新危机  

**常见失误**：无提纲跑偏忘主线；打完 Boss 无奖励；幕末无新牵引。

## 七、视频小说

与短剧/漫剧**同属短内容**，制作链为 **文稿 → 画面 → 配音 → 剪辑**，勿强行套 100 集短剧制片规格；**爽点密度逻辑可共用**。

### 7.1 定位与结构

| 项 | 要点 |
|----|------|
| 定位 | **兴趣 × 擅长 × 市场** 三圈交叉 |
| 开头 | 第一句交代 **类型 + 主角 + 矛盾** |
| 主线 | **只能单一主线** |
| 节奏 | 约 **30 秒** 一梗/反转/推进（约 **166 字** 量级） |
| 五步法 | ①写全文 → ②润色 → ③标爽点 → ④缩到一张纸看分布 → ⑤均匀密集则传播好 |

### 7.2 制作链（实操顺序）

1. **画面**：Procreate 火柴人，**分图层**（头/身/四肢等便于关键帧）  
2. **配音**：AU 等对轨、去噪；台词配合 30 秒节拍  
3. **剪辑**：PR 等「图片序列 + 关键帧动画」；一梗一段，忌长独白无画面变化  

### 7.3 与短剧写作衔接

- 用**八桥段、一加一、30 秒梗密度**写稿；单场三场事可压缩为「半分钟能拍完」的冲突单元  
- 长剧式铺垫、谜题主壳、多线跳切 → 不适用  
- 自检：缩一页看爽点是否均匀；空档超过 30 秒 → 补反转或情绪点

## 八、写作 SOP（短剧从零到交稿）

```text
1. 定用户（男/女、困境）→ 选爽点叠加 → 落成 YY
2. 选故事壳 → 「想怎样+通过啥」钉死选题
3. 人物小传（五要素）
4. 铺 20 节拍大纲
5. 逐场写（三场三件事 + 小起承转合）
6. 台词达标；埋悬念钩子，兑现一加一
7. 八桥段检查爽点是否落地
8. 搁置后用修改 20 法则体检
9. 按规格打包投稿
```

**投稿包（5.1）：** 人物小传 + 大纲 + 十集剧本 + 简介 + 信息表；不玻璃心；**一稿多投须告知**。

**交付八规范（4.1）：** 提案三件套 · 全本节奏 · 角色名 · 选角 · 表演 · 剪辑 · 物料 · 包装

**审查（4.2）：** 政治、两性、历史版权、脏话地名、价值观红线；**为合规了解边界，不是研究擦边**。

## 九、修改 20 法则（改稿体检）

1. 男女频是否跑偏  
2. 八爽点/桥段是否用开  
3. 一主角一视角一线形  
4. 设定 ≤2 且合逻辑  
5. 每集/场有吸睛点（第一集必须有）  
6. 悬念贯穿期一次只揣一件事  
7. 只共情一个人  
8. 主角正直有原则  
9. 主角出场有场面有辨识度  
10. 中后段大问题主角主动解  
11. 约 50 集后可用两难调剂  
12. 乏力时加反派或背叛  
13. 配角有记忆点  
14. 单场起承转合、每集独立能打  
15. 不明/情绪处可补独白旁白  
16. 片名直白说清爽点赛道  
17. 有关键道具  
18. 别怕俗——先完成场目标  
19. 喜剧不强求  
20. 悲剧最多末尾含泪一次  

> 先感性写完，再理性改。

## 十、AI 协作（短剧课）

- 会取代**不用 AI** 的人，不取代会用 AI 的编剧  
- 初学四法：指令四段式 / 对标 / 交互 / **元素法**  
- 进阶五法：章节创造 · 扩写 · 解决方案 · 视觉化 · 台词个性化  
- **工作流：** 每一步输出变成下一条指令（从 0 到 1 交换），勿一上来要全剧  
- 漫剧：**禁止**全篇无人工即投；须去 AI 味 + 逻辑人工复核

## 十一、避坑速查

| 坑 | 做法 |
|----|------|
| 长剧优先级写短剧 | 解压>审美>故事 |
| 谜题主壳 | 换人物/目标/困境/奇遇 |
| 多主角多线复杂成长 | 一主角线性 |
| 金手指规则书 | 极简理由 |
| 流水账 | 三角设计；每场三件事 |
| 女频女主天天开打 | 改借势/情感线 |
| 悬念揣太多 | 贯穿期一件事 |
|  tragedy 滥用 | 最多末尾一次 |
| 没中就死磕一稿 | 投完写下一本 |
| AI 甩锅全本 | 分步协作 + 人工改稿 |

---

## 十二、值得刻住的结论

1. 先对齐产品，再谈故事。  
2. 选题对了文笔差一截也可能卖；选题错了文笔难救。  
3. 爽点叠加 + 故事壳清晰 + 金手指简单。  
4. 结构保节奏，场保心跳，悬念保充值。  
5. 感性写、理性改。  
6. 市场会变，**解压·代入·粘度**与「想怎样+通过啥」相对稳定。
