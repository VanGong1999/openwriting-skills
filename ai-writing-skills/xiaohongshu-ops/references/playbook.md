# 小红书运营 Playbook

> 自包含实操手册：认知、定位、算法、选题、结构、冷启动、与长文带货差异。

---

## 1. 平台认知

### 1.1 人群与搜索

- **四高**：高素质、高价值、高消费、高活跃。
- 男女比约 **3:7**（男性占比持续上升，穿搭/数码等有蓝海）。
- **日均搜索占比约 60%**；查询量级大，是「年轻人的决策搜索」之一。
- 内容 vs 商业：平台优先保 **优质内容**；冷启动硬广无效。

### 1.2 种草机制

- 核心：**卖家秀不是买家秀**。
- 例：面包机不卖 365 度产品图，而做「100 种做法教程」。
- 知识类：**真诚、真实、实用**；忌假大空。

## 2. 变现地图

### 2.1 公式与四大方式（系统课口径）

**流量 × 变现**；获流量需：懂算法、定位清、内容优、发布后复盘。

| 方式 | 要点 |
|------|------|
| 商单种草 | 中小博主可接；报价见下 |
| 获客接单 | 设计师/摄影师等：作品+背后故事，利他实用 |
| 电商薯店 | 0 粉可开店；选品权限常见 **1000 粉**（企业号例外） |
| 知识技能 | 小粉可起步；忌大规模站外导流、低质水文 |

**报价**：粉丝 **÷10 去零头**，±10%。例：10 万粉 ≈ 1 万/条量级。

### 2.2 实战课：产品 × 流量 × 人设

三者 **乘法**，任一为 0 则失败。起号前答三问：怎么赚钱 / 赚谁的钱 / 怎么信我。

### 2.3 四大变现（门槛低）

| 方式 | 门槛 | 备注 |
|------|------|------|
| 蒲公英商单 | 常见 1000 粉 | 素人单周接广数千案例 |
| 笔记带货 | 0 粉 | 挂橱窗；硬广限流需与内容种草平衡 |
| 直播带货 | 初级 5000 / 素人 1000 | 可不露脸对货播 |
| 私域/知识/虚拟资料 | 有技能即可 | 直播间可挂虚拟品 |

### 2.4 两条腿走路

例：笔记带货 + 商单 **兼容**，规避单一变现「被累死」与限流。只做左下角硬橱窗易被当硬广。

### 2.5 按粉丝路径

- **0–1000**：笔记带货、直播带货、私域、资料。
- **≥1000**：笔记带货 + 商单。

## 3. 定位模型

### 3.1 以终为始

终极问题：**我想让什么人链接我？实现什么变现？** 别把涨粉当目的。

### 3.2 洋葱模型（已有商业）

顺序：**商业定位 → 内容定位 → 人设定位**。

- 母婴店 → 宝妈 → 真实宝妈/宝爸人设。
- 减脂教练 → 减肥人群 → 「自己减成功」人设。
- 优先 **个人号** 温度；企业蓝 V 可后置。

### 3.3 SPRM（无商业）

| 字母 | 问 |
|------|-----|
| S Streams | 擅长什么（全列） |
| P Passion | 划掉无热情的 |
| R Resource | 货源/人脉/圈子 |
| M Market | 趋势、成功案例、需求是否满足 |

交集/叠加 = 优势方向；资源型从 R 转，能力型从 S 转。

### 3.4 价值定位填空

> 基于我的 **[优势能力]**，我为 **[什么人]** 提供 **[内容/产品/服务]**，让他们在 **[情境]** 下解决 **[痛点]**，获得 **[收益]**。

### 3.5 定位呈现五维

身份 / 价值 / 变现 / 形式（图文 Pl 站口播，普通人慎剧情）/ 人格（真实）。

### 3.6 IP 五件套

昵称简短中文优先 | 真人头像 | 简介=身份+价值 | 背景图放高光 | 资料尽填（同城同校标签）。

## 4. 算法与流量

### 4.1 流量入口

发现页（新号主）、关注页、个人主页（爆款引流）、搜索、转发群聊等。

### 4.2 CES 权重（热度）

| 行为 | 分 |
|------|-----|
| 点赞 | +1 |
| 收藏 | +1 |
| 评论 | +4 |
| 转发 | +4 |
| 关注 | +8 |

**纯干货合集**易爆款少涨粉：只有收藏，无评论/关注。

### 4.3 分发与长尾

基础池 → 数据达标 → 更大池。关注点击率、完播、互动；开头跳出高则难爆。

搜索 + 关键词沉淀 → **长尾/滚雪球**（停更仍涨粉案例：六成来自搜索）。

### 4.4 薯条

= 买发现曝光；**只投自然跑出的爆款**；冷投浪费。

### 4.5 笔记六要素 + 爆款七要素

六：用户喜好、标题、封面、低跳出、活跃度、热门规则/灵感话题。

七（创作顺序）：**选题 80 分** > 文案 > 封面 > 标题 > 拍摄 > 剪辑 > 运营（可改标题）。

## 5. 选题与文案

### 5.1 选题五维度

1. 与我相关（地域/群体/标签）
2. 对我有用
3. 令我好奇
4. 让我动情
5. 理想自我

**至少 1–2 条**再写；五条全无 = 自嗨。

### 5.2 文案四价值

情绪 / 实用 / 决策（值不值得买）/ 资讯。

主标签 + 1–2 副标签与人设一体。

### 5.3 四种图文结构

1. **痛点 + 方案**（内耗自测 + 12 法类）
2. **故事 + 干货**（反常识标题 + 经历）
3. **聚合清单**（书单/护肤真相——**必须植入自己**）
4. **走心共情**（金句 + 感悟）

**Plog**：多图（最多约 18 张）、透气排版、图压字；多图优于单图。

### 5.4 用户垂直 vs 内容垂直

- **内容垂直**：单赛道（更贴抖音逻辑）。
- **用户垂直**：同一目标用户的多赛道（母婴号可含影片、穿搭、副业、剁手指南）——**变现入口更宽**，给商家留合作空间。

反例：8 万粉母婴号零商单 vs 4000 粉多赛道月净赚数千。

### 5.5 Y 字形选题

```
        目标用户是谁
       /              \
   需求A            需求B
（亲子/情感/副业…同账号可共存）
```

### 5.6 三步法原创爆款选题

1. 搜赛道词 → 找 **10 万+粉** 账号 → 记高赞笔记 ≥3 篇（课内拆解口径常以 **5000+赞** 起；口语「万赞爆款」同指高互动对标笔记，拆法相同）→ 凑 **合集式原创**。
2. 进爆款评论区挖 **暴露需求** 的留言 → 需求 + 验证爆点 = 新标题。
3. 新账号可参考风向：自媒体成长 Pl、副业晒收入、好物日常、生活 Pl。

### 5.7 四大爆款选题风向（新号）

自媒体过程 / Pl 日常 / 副业搞钱数据 / 好物分享。

## 6. 封面与工具 SOP

### 6.1 两步法封面（实战课）

**Step1 跨平台找图**：另一平台热点工具 → 搜品名 → 切 **图文** → 时间选 **近七天** → 双指内缩截图去水印（不用商家脸）。

**Step2 设计模板**：设计 App 模板中心「抖音-小红书」风 → 替换图 → AI 消除原文字 → 滤镜/自加文案去同质化。

### 6.2 常用工具

黄油相机（封面）、醒图/美图（修图）、剪映（视频）。

### 6.3 发布

目标人群活跃前 **30–60 分钟** 发布；发布后改封面/标题/话题；图文全能改，视频本体不能改。

排版参考：十字一标、三行一段；关键词埋标题/正文/话题。

## 7. 人设三件套模板

**昵称**：爱+领域+昵称 / 职业+昵称 / 产品+哥姐。

**简介三句**：我是谁 | 能做什么 | 带来什么帮助（人话，非简历）。

**头像**：真人最佳；不露脸可用昵称生成专业头像截图。

**三大赚钱人设**：好物分享（朋友）、好物测评（朋友+专业）、经验分享（老师）。零基础首推 **好物分享**。

## 8. 与知乎带货（commercial-content）对照

| 维度 | 知乎带货向 | 小红书向 |
|------|------------|----------|
| 长度 | 千字级、证据链 | 短句+多图、首屏决断 |
| 说服 | FABE、三分法、三模板 | 五维度选题+四结构+价值感 |
| 转化 | 好物卡片、专业背书 | 薯店、蒲公英、评论区「在哪买」 |
| SEO | 问题/搜索词 | 笔记搜索词、长尾堆积 |
| 人设 | 答主/专栏 | 朋友/老师+IP五件套 |
| 合规 | 广告法+好物规则 | 敏感品类先价值后链接 |

同一 SKU 改写：**知乎**写清对比与经历证据；**小红书**写场景+情绪+决策+封面关键词。
