# 长剧与视听剧本写作

本 skill **自包含**：不依赖外部课程路径；执行细节在 `references/` 下三份文档。

## 何时启用

- 开发 **电影 / 网剧 / 电视剧** 故事概念、梗概、节拍表、分场、台词
- 写 **Pilot（原创试播集）** 或评估 Spec、单元剧 vs 连续剧、有线 vs 广播
- **类型片**选型、人物弧光、商业片悬念与拉片
- **广电向**提案（1500+300）、过审价值导向、To B 市场逻辑
- 用户带着 **短剧/竖屏** 习惯来写长剧时，先做优先级纠偏

## 与短剧 Skill 的边界

| 维度 | 本 Skill（长剧/电影向） | short-drama-manhua |
|------|-------------------------|---------------------|
| 第一优先级 | **故事 · 节拍 · 人物弧光** | **解压 · 充值 · 强粘度** |
| 结构工具 | 四幕节拍表、信息熵 35–45 拍、Pilot 23 情节点 | 20 节拍短剧大纲、充值钩子 |
| 台词 | 服务场面与潜台词；忌用台词推剧情 | 态度+信息+潜台词，节奏更密 |
| 市场 | To B 完播/定制/分账；别先写全集去卖 | 投放 ROI、小程序转化 |

**不要**用竖屏短剧的「解压第一」标准去砍长剧人物线与主题；**可以**在改编时重新选题，而不是硬套节奏。

## 默认工作流

```text
1. 立项：一句话故事（主动目标）+ 10 设定 × 目标六方向 → 讲给真人测冲动
2. 展开：十五元素 → 人物小传 → AB（Want/Need）→ 类型片主共情点
3. 结构：四幕节拍表（或 Pilot：Teaser+四幕情节点）→ 流畅 > 精彩
4. 场级：锁定任务→对抗→事件包裹→转变；视听化、禁旁白独白大段闪回
5. 台词：事件重于台词；坐谈不超三场；炸弹/错位/争论
6. 交付：梗概/节拍/分场规格；广电向 1500+300；提案命中率心理预期
7. Pilot 线：先答 Pilot/Episodic/Cable → 五步法 → 模板填点 → 检查清单
```

## 输出前自检（极简）

- [ ] 一句话里目标是否**主动**、听完是否想问「后来呢」
- [ ] 节拍是否**连贯**（先做对再做好）
- [ ] 每场是否有**信息/推进/变化**之一，无变化是否可删
- [ ] 类型片共情点是否清晰，是否堆超过「只加两个」爽点/设定
- [ ] 剧本是否**可视听**、少 Q&A 式台词
- [ ] Pilot：是否为 **55 页量级样本**、核心问题（A/B/C）是否在 Act 1 打底
- [ ] 未混用短剧「解压>故事」优先级
