## 一、金手指是什么（39）

| 维度 | 课内定义 |
|------|----------|
| 词源 | 点石成金；作者是造梦人 |
| 本质 | **把不合理合理化**；遇困难可解的外挂 |
| 形态 | 宝物、异能、随身老爷爷、重生记忆、系统等 |

**六个作用**：增吸引力｜推剧情｜成亮点｜强代入｜合乎逻辑｜增爽点。

**与狂更猫统一口径**：金手指＝**主角优势**；也是压缩不爽过程的道具（25、27）。

## 二、从四方面构思 + 三共性底线（39 · SOP-24）

### 2.1 四方面

1. **主角成长路线**（升级、宫斗、设计成名等）。  
2. **背景环境**（打压到无路可退 → 金手指须与背景融合，否则跳戏烂尾）。  
3. **主角目的**（复仇、致富等决定缺什么）。  
4. **缺乏因素**（缺什么给什么，如囤货空间）。

### 2.2 三共性（缺一不合格）

凸显与众不同｜助主角克服困难｜满足读者 YY。

### 2.3 设置原则（雷区）

| 原则 | 课内要求 |
|------|----------|
| 数量 | **少胜多**；万能女主多技能易扑 |
| 延伸性 | 随成长可扩展（空间变大、技能点增多） |
| 适度 | 勿开局满级；勿过废成鸡肋 |
| 成长空间 | 可持续产出（药园/洞府）优于一次性卖药 |
| 潮流 | 套路+**微创新**；勿与正文割裂 |

### 2.4 出场时机

- **勿大半本才给**；虐五六章读者已走。  
- 常见：半章遭遇 → 反转出金手指（可弱开）→ 希望与期待。  
- **主次**：金手指勿抢戏；读者可能为金手指点进，留住靠节奏人设剧情。

### 2.5 常见类型（课内表）

技能类｜空间类｜系统类｜外挂类（家世、头脑、重生预知、萌宠等）。

### 2.6 检验四特征

1. 能否表达思想与主题（选择→冲突解决逻辑）。  
2. 背景与金手指**碰撞**出矛盾火花。  
3. 勿喧宾夺主（新人慎重度系统文→主角傀儡）。  
4. **持续性**：中后期仍能解决主要矛盾，勿变幕后无聊。

### 2.7 与篇幅收入（课内口述·经验口径）

设定过好可持续更长；开过大与主题割裂 → 易早崩【待核实具体字数对比为课内举例】。

## 三、创新：微创新为主（40–41 · 公式-25）

### 3.1 定位（40）

- **勿神话开类型**；开创流派需极高阅读量与天赋，且可能无受众。  
- **微创新**＝在别人基础上调整 → 读者一时想不起完全一样＝**陌生化**。  
- 新手：阅读量低可先俗套+新媒体节奏；冲老站须持续微创新。

### 3.2 陌生化四法

| 法 | 内容 | 新人难度 |
|----|------|----------|
| 叙述结构 | 罗生门、环状、倒置、多线 | 结构中高；多线不推荐新手 |
| **反套路** | 打破固化预期 | 41 节主修 |
| **穷举组合** | 背景×人设×主线×金手指×职业…排表碰撞 | 41 |
| **变换关键元素** | 结构/情节/人设/背景/冲突五块替换 | 41 |

### 3.3 反套路（41）

- 换视角重讲经典（郭芙视角神雕）。  
- 例：女主不救男主反被逼救；《苍兰诀》不盲从复仇；《天道图书馆》金手指是见人成书→徒弟打怪。  
- 要点：**骗过读者「本该如此」的脑补**。

### 3.4 穷举与变换元素

- 快递小哥×古代/末世/山海经；总裁×末世……  
- 六要素归四块：**背景、情节、结构、人物（+冲突）**——可换情节不变结构、换人设不变冲突等。  
- **刻板形象 vs 典型形象**：创新要典型可辨，非贴标签（41 下节）。

### 3.5 与扫榜关系

刷榜穷举表 + 四换三（狂更猫）＝在验证过的核上做微创新，非纯抄三项【番茄·免费流】。

## 四、狂更猫：好设定能写长（66）

### 4.1 好设定标准

帮建框架、造剧情、增冲突与期待；**不是**只求极品脑洞。

开篇 2000～4000 字须塞下：金手指、世界观、主线、外界压力、力量体系、冲突、主角目标、读者预知、切入视角——写不够＝设定失败。

### 4.2 审设定三问（核心）

| 问 | 不过的后果 |
|----|------------|
| 金手指有无**成长性**？ | 几万字后无趣 |
| 什么**重复套路且保持新颖**？ | 剧情克隆 |
| 主角**目标如何更替**？ | 写崩或卡死 |

直播间审题同问：书名简介+金手指→能否写。

### 4.3 正反例（课内演示）

| 题材 | 结论 |
|------|------|
| 电竞仅「手机代打」 | 无成长无循环 → 不能写 |
| 阴间中单骚操作 | 每局不同 → 能写 |
| 直播卖货 | 人气解锁货+国家级视角 → 隐藏期待 |
| 高考满分 | 绑定国家末题变世界难题 → 成长性 |
| 医生会点刀法 | 推荐「不断解锁会点××不过分」路线 |

**启示**：无脑题材+设定加成常最帮新人；设定主要服务**循环**（见 `outlining.md`、`playbook` 三万字）。

### 4.4 万能模板（新人）

- 面板加点 + **人气/震惊/破防值**买技能或抽奖 → 逼每循环造声势。  
- 注意数值读者会算，勿加错。

### 4.5 与循环三位一体（44 / 51）

设计书时同步：**金手指（怎么解决）+ 核心（最爽处）+ 主角目标**。  
例：帅杀诡异可循环；帅不能杀狼则循环不成立。

## 五、跨课金手指七特质（写作课程2 · playbook 引用）

唯一性｜升级空间｜有限制｜隐匿｜易懂｜不要太多｜不完全依赖

与零基础「少而可延伸、弱开有成长」叠加使用。

## 六、开书自检清单

### 金手指本身

- [ ] 从四方面想清，过三共性底线  
- [ ] 少、可延伸、弱开、有成长、与背景碰撞  
- [ ] 第一章或前五章已展示能干嘛（04/46）  
- [ ] 非满级开局又堆多个全能技能  
- [ ] 中后期仍能服务主要矛盾  

### 创新与跟风

- [ ] 新手主**微创新/反套路/穷举**，非神话开类型  
- [ ] 仿写避开切入点+金手指+第一章结构三项【番茄·免费流】  
- [ ] 叙述结构创新仅局部使用，开篇视角仍宜稳（40）  

### 狂更猫三问（66）

- [ ] 成长性｜重复且新颖｜目标更替  
- [ ] 能否说清爽点**循环**（03/51）
