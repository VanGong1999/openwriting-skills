# 编剧拉片与信息节拍

## 立场（与导演拉片分清）

- **编剧拉片**看：故事创作相关——结构、落地细节、人物情感、观众情绪刺激。
- **不看**：机位、光影、镜头运动（那是导演课）。
- **拉片是工具**，不能替代系统写作训练；好编剧仍需大量阅片 + 带方法肢解。

## 四方向（每次拉片必填）

| 方向 | 看什么 |
|------|--------|
| **1. 总体结构** | 类型、四幕大结构、大悬念、AB 故事、人物成长 |
| **2. 细节元素** | 职业、穿戴、环境、动作、器物——戏是否落地（悬浮=缺调研） |
| **3. 情感** | 主角/双主角关系弧线（互补→误会→决裂→和解→成为彼此） |
| **4. 情绪** | 笑/哭/紧张/焦虑的密度与分布 |

## 核心工具：信息节拍

- 每向观众输送 **一坨新信息** = **一拍（一个信息包）**。
- **商业片**常见 **35–45 拍**；信息总量 = **信息熵**（耐不耐看的重要指标）。
- **动画片**常偏多拍：世界观要交代 + 无明星「状态戏」拖节奏。

## 拉片步骤

1. **第一遍**：整体感受，不扒表。
2. **第二遍**：拉出信息节拍表（打点）。
3. **第三遍**：填四方向分析 + 幕结构争议点（前史/激励/中点/黑夜）。

## 结构打点（通用标尺）

| 节点 | 要义 |
|------|------|
| **前史** | 约片长 10% 时间（如 90 分钟片约 10 分钟）交代性格/世界观；**第 10 分钟前后常「正式进戏」** |
| **现状** | 前史结束后主角的可感知处境（非童年单独一段） |
| **激励事件** | 必须在 **现状** 内，打破龟壳、接不可逆任务——**不是前史里的挨打/阴影** |
| **故事中点** | 常在第 55 分钟级（若前史占 10 分钟，则非机械 45 分钟） |
| **灵魂黑夜** | 第三幕末：一无所有、信仰崩塌 |
| **第四幕** | 「母胎重生」：往往回乡/母体，**用旧道具新解读**再反击 |
| **终场** | 画面/情境 **呼应开场** |

**类型判断**：分类是工具；**共情点**决定观众感到的类型（同一片可叠愚者成功 + 伙伴之情 + 探案）。

**写作原则**：**大道理留给反派讲**；主角用选择和行动点题。

## 标准工作流 A：拉一部片

输出结构：

```text
1. 基本信息（片长、估算拍数）
2. 节拍表（# | 时间约估 | 信息节拍 | 备注）
3. 幕划分（1/2/3/4 起止拍号）
4. 四方向短评（各 5–10 句）
5. AB 故事一句
6. 可迁移的 3 条创作教训
```

## 标准工作流 B：梗概 → 节拍（作业口径）

把 **约 1500 字梗概** 拆成 **40±5 个信息节拍**（对标商业片熵）；先保数量与顺序流畅，再雕精彩度。

## 自检

- [ ] 激励事件是否落在现状而非前史
- [ ] 故事中点是否因前史后移而误判「正片中线」
- [ ] 每拍是否真有新信息（删无信息状态戏）
- [ ] 细节是否可调研（职业戏是否真会做这事）
- [ ] 情感线是否有「成为彼此」或等价完成度
