# AI 写作工作流 · 实操手册

与 `../SKILL.md` 配套：含可复用提示词骨架、分体裁 SOP、去 AI 味细则、缺点速查。体裁交付标准仍以 `story-fundamentals`、`short-drama-manhua`、`web-novel-craft` 为准。

---

## 一、底层判断（写 prompt 前先对齐）

1. **AI 不替代判断力**：市场、审美、阅历、合规 — 人定；AI 枚举与填肉。
2. **概率抽卡**：训练数据偏旧套路；换提示词不能根治老梗，靠对标市场 + 人改核心事件。
3. **输出可用率**：粗算只取 30%–50%；先抽卡 3–4 版交叉对比，勿无脑 Regenerate（易断层）。
4. **单次质量窗口**：约 2000–3000 汉字最佳；超长指数下降；对话变短 = 预警，换新窗 + 摘要续写。
5. **第一次输出定基调**：梗概/首集/首章偏了，后面全偏 — 宁可慢改第一步。
6. **手搓起点**：从 AI **第一份**输出就改，不是成稿后一锅端。

## 二、查理短剧 · 四段指令模板

```text
【定义角色】
你现在是一名（竖屏）短剧编剧 / 资深剧本顾问。

【背景信息】
项目：〔男频/女频〕、〔类型〕、约〔N〕集。
已确定：〔核心悬念/人物关系/前情摘要，≤300字〕。

【任务目标】
本步仅完成：〔例：第5拍「虚假胜利」的一场戏 / 为「密室偷证」提供5种偷法〕。

【输出要求】
- 语言：中文口语化，可剪
- 篇幅：〔字数/场数〕
- 结构：〔人物数、转折、情绪〕
- 禁止：〔心理小说式旁白 / 机械降神 / …〕
```

**对标法（四段说不清时）**：贴对标场次/桥段（标明「学结构不学原文」），要求同功能不同情节。

**元素法**：只写「一个桥段元素」——一句威胁、一个反转道具、一场对峙草稿，禁止「写完全部剧本」。

**交互法（0→1）**

| 步 | 人审后进入下一步 |
|----|------------------|
| 1 | AI 写世界观/时代背景 |
| 2 | 5 人小传（欲望+恐惧写具体，忌「怕黑」式空词） |
| 3 | 300 字梗概 |
| 4 | 分集/分幕大纲 |
| 5 | 单集/单场（最多单场） |

## 三、知乎 · 故事文结构化大纲 prompt

```markdown
## 任务
请构思故事大纲（不要直接写正文）。

## 篇幅
〔短篇盐选 / 中篇 / 网文长篇〕

## 故事三要素
- **环境**：（时间、地点、特殊规则）
- **情节**：五幕式 — 开端 / 发展 / 转折 / 高潮 / 结尾
- **人物**：主角目标+缺陷；配角关系网

## 叙事
- 人称：〔第一/第三〕
- 手法：〔顺叙/插叙…〕

## 思维链
1. 先列出人物关系与核心冲突
2. 再按五幕各写 3–5 句情节点
3. 标出每幕情绪曲线
```

**正文 · 成语接龙**

```text
我将提供背景、人设、大纲。请先阅读并复述关键约束（不超过200字），确认无误后：
- 你写第一段（约300字）
- 停笔等我回复「继续」或插入我的句子
- 每段结束自问：有无 AI 总结句、有无过滤词堆砌
```

**跑团指令**：只给关键词 — 「女主推门，看见末日广场，人群静止」→ 让 AI 扩画面，禁止一次生成全文。

**润色四法（摘要）**：① 让 AI 自评删冗 ② 指定感官/画面/人设 ③ 模仿作家风格（学习用）④ 排版建议。

## 四、漫剧 · 九格分步 SOP

| 步 | 动作 | Prompt 要点 |
|----|------|-------------|
| 1 定梗 | 批量 10–20 梗，人筛 | 题材约束+爆点前置+标签+动机+危机+开篇结构；见手册 §一 |
| 2 前十集纲 | DS/豆包 | 爽点模型+卡点类型+核心梗全文；表格转文字时核对 DS 差异 |
| 3 第1集 | 剧本格式 | 「学格式不学范文内容」；分镜+台词；禁形容词堆砌 |
| 3+ | 分镜化 | 正文后接：「改分镜画面+台词，情绪用简单词，画面详述」 |
| 4 轮生成 | 10 集/轮 | 每集 800–1200 字，≤3 场景，台词+旁白 ≤500，台词须推进情节 |
| 5 集级校正 | 薄集加厚 | 「结合分集纲增情节与台词；第X集；集尾悬念」 |
| 6 去 AI 味 | 专用提示/模型 | 场景化描写替概括；之后必手搓 |
| 7 手搓 | 人 | 逻辑→AI词→镜头→台词人设→钩子伏笔 |
| 8 后续纲 | 循环 3–7 | 输入：核心梗+已有分集+参考案例 |

**台词优化附加段**（短剧课口径）：短句、带刺、装逼靠铺垫与证据打脸、节奏快交锋。

## 五、核心梗四步叠加 · Prompt 骨架

```text
你是资深漫剧编剧。按四步为我生成 5 个核心梗，每个两句话，必须有反转与追剧点：

1. 世界观：（末世/修仙/赛博/规则怪谈+限制）
2. 身份反差：表面___ / 实际___
3. 金手指+限制：（系统/异能/道具）+ 代价或冷却
4. 核心动作：每集可重复的「爽动作」或视觉名场面

输出：每个梗附「元素拆解表」；标注男频/女频；标注跟热点的元素。
```

**筛选标准（人）**：跟热点 + 微创新；期待感在梗末句拉满；禁「混成传奇」式空结局。

**反面**：规则怪谈裸写、末世送外卖字眼、纯 AI 续写国民 IP 商用。

## 六、换元法 · 可用 Role 模板（换元法创作大师 3.0）

**操作口径**

- **一度置换**：换背景、人物、道具；事件结构尽量保留。  
- **二度置换**：换核心事件，其余联动改；AI 给出的核心事件易老套，**必须人改**。  
- **六大故事源**：事件、结构、主体、背景、人物、道具；仿写时量化章数、章字数、情节点密度 **1:1 对标**。

将下列全文作为 system / role prompt，或在用户消息中粘贴「原作梗概 + 一度/二度目标」：

```markdown
# Role：换元法创作大师3.0

## Profile：
- **Author**：Nines AI
- **Version**：3.0
- **Language**：中文

## Background：
换元法作为一种高效的创意工具，通过系统化置换故事元素，帮助创作者重构经典文本，激发全新叙事可能。

## Core Skills：
- 精通换元法的核心原理和应用技巧，能够指导作家进行深度创新而非表面修改
- 熟练掌握六大故事源（事件、结构、主体、背景、人物、道具）的分析和运用
- 擅长一度置换和二度置换技巧，能够引导作家进行多层次、多维度的故事重构
   - 一度置换：换背景、人物和道具，其他不做替换
   - 二度置换：主要是核心事件替换，同时其他元素也会替换
- 具备强大的跨领域知识整合能力，能够启发作家进行创新性的元素组合
- 拥有敏锐的逻辑分析能力，能够帮助作家检查和优化故事的连贯性和合理性
- 具有丰富的文学鉴赏经验，能够评估和提升作品的视觉与情感冲击力

## 常用换元方案库：
### 背景置换
- **时空转换**：古代⇄现代、现代⇄未来、现实⇄虚拟
- **文化迁移**：东方⇄西方、都市⇄乡村、地球⇄外星
- **环境重构**：和平年代⇄战争时期、文明社会⇄末日废土

### 人物置换
- **身份重塑**：性别转换、正邪反转、物种变更
- **关系重构**：主角降格/升格、视角转换、角色融合
- **动机重置**：爱情⇄事业、复仇⇄救赎、个人⇄集体

### 事件置换
- **冲突升级**：个人矛盾⇄社会危机、内部斗争⇄外敌入侵
- **结构创新**：线性叙事⇄多线并行、顺序⇄倒叙插叙
- **结局重构**：悲剧⇄喜剧、开放结局⇄多重结局

### 主体置换
- **价值更新**：传统观念⇄现代思潮、个人主义⇄集体主义
- **内涵深化**：表面故事⇄哲学思考、娱乐性⇄社会批判

### 道具置换
- **系统转换**：魔法⇄科技、超能力⇄黑科技
- **道具升级**：传统物品⇄智能设备、普通工具⇄神器法宝

## Constrains:
- 始终尊重原作的核心主题和精神，确保创新不偏离作品的本质内涵
- 在鼓励大胆创新的同时，保持故事的内在逻辑和连贯性
- 避免简单的元素堆砌或表面修改，追求深层次的创意重构
- 遵守文学创作的伦理准则，避免抄袭或过度借鉴他人作品
- 注重作品的社会价值和影响力，引导创作积极向上的内容

## Workflow：
1. **故事诊断**：分析原作六大故事源，识别核心元素
2. **方案匹配**：根据创作目标，选择合适的换元方案组合
3. **框架重构**：重建故事框架，设计情节线与高潮点
4. **细节深化**：重塑人物关系与场景设定
5. **逻辑校验**：检查故事连贯性，优化情感冲击力
6. **迭代完善**：基于反馈进行多轮优化，并按照指定格式输出

## Output Format：
1. **换元思路**
   - 原作核心分析
   - 换元方案选择理由
   - 新旧元素对比映射

2. **故事架构**
   - 新故事梗概（150字）
   - 关键情节点（8-12个）
   - 主要人物画像
   - 标志性场景（3-5个）
   - 延伸开发方向

## Initialization：
您好！我是换元法创作大师，拥有完整的创意方案库和实操经验。请告诉我：
1. 您想改编的原始作品是什么？
2. 您希望达到怎样的创新效果？（如：现代感、颠覆性、深度思考等）
3. 是否有特定的置换方向偏好？
```

**人改重点**：二度换元后 **核心事件** 常老套；设定输入错误 AI 会顺错写（例：罪臣之女嫁侯爷逻辑链）。

## 七、五类高频扩写指令（短剧课二）

| 法 | 指令示例 |
|----|----------|
| 章节创造 | 「第12拍目标：女主获知真相但装不知；写本场，含信息+推进+变化」 |

## 八、去 AI 味 · V3.8 执行清单

### 基本原则（润色时坚决贯彻）

1. **禁止**改变原文主题思想、故事走向、结局等核心内容。  
2. **禁止**删减原文中任何场景、人物、对话等关键要素。  
3. **务必**完整保留原文的写作风格和语言基调。  
4. **在不改内容前提下**丰富表达、增加有效篇幅；以短句为主，**长句一般不超过 20 字**，注重节奏。

### 润色步骤（九层）

1. **初步修整**：修语法标点别字；拆冗长段；去不符合身份的方言；拆长句。  
2. **创新表达**：替换高频同义句式；叙述适度口语化；可加有效细节；用动作/神态/心理替比喻。  
3. **优化人物**：言行个性化；对话加语气与动作；外化内心；避免千人一面与平铺心理。  
4. **强化细节**：动作具象化情感；环境融入人物视角；生活化细节过渡场景。  
5. **创新修辞**：**禁止**「像/仿佛/宛如/如同」比喻 → 改动作、神态、他人反应。  
6. **革新环境**：味香声色切入；以情带景；忌全知视角堆砌。  
7. **深化情感**：抽象情绪改肢体与表情；可借回忆联想；情景交融。  
8. **精简语言**：删累赘心理、重复句、「感觉/好像」等模糊词、华丽空词。  
9. **严控禁用**：清除「像朵凋零的牡丹」「割破人心」「胸口一堵」「不知所措」等程式与陈词。

### 快速对照（写作/精修时）

| 类型 | 处理 |
|------|------|
| 比喻套话 | 像/仿佛/宛如/如同 → 动作、群体反应、环境细节 |
| AI 总结词 | 综上所述、值得注意的是、不禁 → 删或改具体叙事 |
| 过滤词链 | 看到、听到、觉得、感觉、想到 → 能删则删，直接呈现 |
| 笼统动词 | 走/拿/打 → 踉跄、攥、抄等具体动词 |
| 机器痕迹 | `**`、异常碎标点、多余空行 → 清理干净 |

### 保留原则

- **不改**：主题、结局、关键场面与对话信息。  
- **要增**：有效细节、口语、人设差异（非凑字数）。

### 提交前自查（须逐项过）

- [ ] 不改变核心内容与走向的前提下，语言明显更丰富  
- [ ] 无明显表达雷同；无「像/仿佛/宛如」残留  
- [ ] 已删「感觉/似乎」等模糊词，改为准确表达  
- [ ] 抽象情感已外化为动作/神态/环境  
- [ ] 去掉角色名仍能分辨谁在说话  
- [ ] 句长节奏适合体裁（网文/剧本/漫剧）；漫剧每段可执行画面  
- [ ] 长句已拆，以 ≤20 字短句为主、有节奏  
- [ ] 未因怕检测删成「尸体文」  
- [ ] 对话与叙述有口语化，人物言行有个性  
- [ ] 细节推进情节且服务氛围，无堆砌  
- [ ] 已清除陈词滥调与过度夸张句

## 九、AI 缺点 · 写作时对照

| 类别 | 表现 | 对策 |
|------|------|------|
| 逻辑 | 机械降神、伏笔缺失 | 人通读；可让 AI「列出可能漏洞」但人改 |
| 大纲 | 丢 30% 情节、衔接弱 | 人补衔接点；细纲写「怎么发生」 |
| 人设 | 后期 OOC、千人一面 | 每 10 集喂人设表；台词单轮个性化 |
| 漫剧 | 小说腔、表情过多 | 分镜 prompt；表情两字化 |
| 短篇 | 文艺空泛、缺钩子 | 导语四要点；人写导语 |
| 工具 | DS 加戏、豆包啰嗦 | 分工具分步；下载/表格用豆包，逻辑用 DS，人统稿 |
| 合规 | 洗稿、IP 续写盈利 | 换元+二创边界；合规 skill |

## 十一、与体裁 skill 的交接单

**交给 `short-drama-manhua`**

- AI 分集 → 核对 20 节拍、充值悬念、场「信息+推进+变化」
- AI 台词 → 潜台词、身份、可剪长度

**交给 `story-fundamentals`**

- AI 大纲 → CTFDP、缺陷、意外+困境、15 步体检

**交给 `web-novel-craft`**

- AI 短篇 → 导语、爽点密度、平台品类、扫榜对标

**本 skill 停止的地方**：prompt 与分步生成策略；**体裁 skill 开始的地方**：好不好卖、能不能过稿。
