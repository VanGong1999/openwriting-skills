# 四级纲、细纲与循环（零基础班 10–14 · 狂更猫 03/39/44/51）

> 本文件为自包含技法说明。千字大纲总览见 `playbook.md` §2。

---

## 一、四级纲：角色与路径（10）

| 层级 | 比喻 | 作用 |
|------|------|------|
| **草纲** | 骨架 | 谁因何做什么→遇何问题→如何解决→结局；几句话 |
| **总纲** | 脏腑 | 人设、配角、背景、地图、等级、兵器、故事线；边想边补 |
| **大纲** | 经脉 | **有技巧的故事线**；给编辑看剧情非设定堆 |
| **细纲** | 向血肉过渡 | 时间地点人物环境；比大纲细、比正文粗 |
| **正文** | 血肉 | 成文 |

```text
灵感/核心梗 → 微创新 → 设定（人设+背景）
→ 草纲 → 总纲 → 大纲 → 细纲 → 正文
卡文回层：大情节→大纲；走场→细纲/代入（精华）
```

**不必每一级写死**——名词为帮你想故事（10）。  
**日码万字以上靠细纲**（14）。

## 二、总纲四步（11–12）

| 步 | 内容 |
|----|------|
| 1 | **一句话主线**：谁想做什么，结局如何 |
| 2 | **独特性纲要**：为何做、如何努力、阻力（草纲级扩展） |
| 3 | **人设表 + 背景设定**（名词/地图/规则） |
| 4 | **分阶段剧情**（下节）：地图法/等级法/进度法；言情感情四步 |

纲非绝对必备但最好有；大纲不必一次完美，先框架 HE/BE（11）。  
总纲按**故事时间顺序**；大纲按**叙述结构**（13）。

### 给编辑的大纲（13）

- 约 **600–2000 字**（平台有别）。  
- 含：主线、重要事件/支线、重要人物、**亮点总结**。  
- 只见「呈现成什么样」，非设定百科全书。

## 三、大纲：九节点 + 冲突推动（13）

九个故事节点可只用 3–5 个；全书＝**N 个小九节点**重复（换人换景换因）。

| # | 节点 | 作用 |
|---|------|------|
| 1 | 设置悬念 | 知发生不知结果 |
| 2 | 第一部分说明 | 布局，朝目标前进 |
| 3 | 情节点出现 | 矛盾出现，给一巴掌 |
| 4 | 第二部分说明 | 被迫换路径 |
| 5 | 中间点 | 切前后半；可有大转折 |
| 6 | 第三部分说明 | 主角变主动 |
| 7 | 情节点再出现 | 顿悟、试金石 |
| 8 | 第四部分说明 | 后期推手，埋伏笔 |
| 9 | 结尾 | 目标完成/未完成/续勾 |

**卡大纲**：唯一答案是**冲突**——升级＝渴望强大 vs 低微；可强行制造新冲突（13）。  
**叙述顺序 ≠ 时间顺序**（悬疑先查后揭凶过程）。

开篇级可用冲突公式：**一个乱字 + 两个关口**（26，见 `openings-hooks.md`）。

## 四、细纲拉长四法（14 · 公式-06）

### 4.1 剧情拆解

五元素：**时间｜地点｜人物｜事件｜结果**。  
大纲一句 → 细纲多问：**为什么**（少问什么样，防陈述无动因）。  
大目标拆小目标再拆行动（掌中之物式）。

### 4.2 剧情推导（逆推）

定初始状态 + 最终结果 → 从结果往前推人物与小细节 → 加工戏剧性。  
失败需谁暴露 → 谁符合人设 → 安插人物。

### 4.3 戏剧冲突

```text
需求 → 阻碍 → 行动 → 结果
```

每环可再展开（西游取经、牢房破案）。

### 4.4 产生对比

找对比点（人/时/地/世界/解法）→ 落差 → 人物+读者情绪。

### 4.5 细纲使用注意

- 可分配章节但**勿按细纲字数死卡章切**（14 强调两遍）。  
- 思考按时间线，正文可打乱（悬疑详略）。  
- 细纲＝思考结晶+防卡文，非圣经。

## 五、狂更猫：三万字节奏与倒推（03 / 51 · SOP-06）

### 5.1 三万字是什么

- **口号/量词**，非精确 30000；平均约三万一个剧情节点（可 2～4 万波动）。  
- 新人难靠「感觉节奏」→ 用三万节拍器**少犯错**（03）。  
- 长篇＝套路重复（斗破式多段升级；脑洞向多段 3 万叠上架）。

### 5.2 倒推 SOP

```text
书名/金手指确定
→ 能否建立循环、有对标热度、难度适合
→ 定第 1 个三万终点（震惊/阶段性变强/装逼结算）
→ 倒推第 1 章须交代什么
→ 中间章只推进到终点
→ 第 2 循环 = 第 1 加强版
→ 约 15 章章纲（章约 2000 字）可配套（03）
```

**剧情定义**（51）：主角怎么达成目标写出来就是剧情。  
精力投**动机与行为逻辑**，少狂想「下一步剧情叫啥」。

### 5.3 循环三要素（51 / 44）

1. **主角目标**（主线）  
2. **金手指**（解决方式）  
3. **核心**（爽点来源，≠主线）

> 升级常是来源不是爽点本身；误会须对准核心（误以为菜鸡才爽）。

**循环正确定义**：用固定金手指**反复解决问题**的思路，非「报复一人一次就完」（44）。

### 5.4 第一个十万字倒推（playbook · 狂更猫 50）

定背景人设金手指主线 → 先定大结局 → 定 10 万中点 → 倒推节点 → 切约 3 个大剧情填满 10 万。

### 5.5 稳书（SOP-32 · 56）

主线一句 + 核心亮点一句 + 约 12 万内四个剧情都绕核心；跑偏删。  
主线 ≠ 核心亮点。

## 六、搭台子：副本与卡文（39 · SOP-20）

### 6.1 解决什么

- 卡文只允许在**设定**或**过渡**；循环内无事件＝不合理。  
- 控制要素膨胀；强者同字数事件更少更满。

### 6.2 副本定义

**独立循环空间**，内自洽，离开不带累赘。  
一首歌≠完整台子 → 须**场景+时间+听众视角+服务核心的目标**。

### 6.3 搭台步骤

```text
双方目标（主角 + 主要配角）
→ 时间
→ 场景
→ 演员进场
→ 过渡
→ 下一座台
```

剧情自循环：**目标碰撞**造戏；下一循环可换配角目标、**故意加难度**（白鹿倒追例，约 3 万字级）。

## 九、开纲自检清单

### 四级路径

- [ ] 草纲有句能讲清因→果  
- [ ] 总纲有人设表+背景名词  
- [ ] 大纲只写重要转折事件+叙述顺序  
- [ ] 细纲用四法至少其一拉长关键段  

### 循环/三万

- [ ] 第一个三万终点可写成震惊/阶段性变强  
- [ ] 三要素：目标+金手指+核心爽点来源  
- [ ] 第 1 章倒推信息齐全（对照 `openings-hooks.md` 五信息点）  
- [ ] 下一循环是否加强版非同人报复清单  

### 搭台

- [ ] 本段是否有双方目标碰撞  
- [ ] 场景是否服务核心（非空换场）  
- [ ] 离开副本是否带走多余设定累赘
