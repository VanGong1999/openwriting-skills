## 一、顶层认知

### 1.1 课内定位

> **感情线很简单；不简单的是 CP 互动与中间过程。**（15–16 原意）

- 女频：感情线常重头戏，甚至主线。  
- 男频：多半调味剂；写感情可参考本节，但篇幅与主次不同（见 `male-female-channel.md`）。

### 1.2 两大感情类型（15）

| 大类 | 要点 |
|------|------|
| **一见钟情** | 暗恋型 / 迷恋型（含强取豪夺）；**新手慎写** |
| **日久生情** | 必须给**感情契机**；先婚后爱、追妻火葬场、欢喜冤家等 |

**讨巧路径**：先婚后爱等同屋檐下自然生发，不必硬写一见钟情。

## 二、感情线六步模板

> 老师原话大意：六步几乎逃不掉——难的是中间情节、人设、互动。（16）

| 步骤 | 内容 | 备注 |
|------|------|------|
| 1 | **初相识** | 可套先婚后爱、冤家、青梅等 |
| 2 | **暗恋** | 升温/降温；可「爱而不自知」 |
| 3 | **感情契机** | 爆破升温；一方意识到自己有多爱对方 |
| 4 | **表白** | — |
| 5 | **经历磨难** | 升温或降温（误会=降温） |
| 6 | **结局** | 好或坏 |

与 playbook **感情线六步**（相遇→好感→误会→拉扯暧昧→内心突破→反转稳定）同骨架，课内 16 表为创作主模板。

**零基础班创作前四件事**（16）：

1. 多问**为什么**（为何喜欢/不喜欢）  
2. 走向清晰：相识→相知→生情→爆发→归于爱情，**不可跳步**  
3. 没谈过恋愛：影视代入、观察「撒狗粮」、独自看剧记心跳  
4. **感情人物脉络图**：影响 CP 的配角须故事之初安排好，忌天降  

**创作中六点**（16）：打造 CP 感 → 细化互动 → 设障碍 → **铺垫暧昧（极重要）** → 内心突破 → 适当反转。

### CP 感怎么打

两人必须接触的事件：共同破案、项目、逃亡、幽禁等——**独立空间**最易升华感情。

### 暧昧期写什么（16）

捅破窗户纸前的**拉扯**比表白更重要；铺垫不好后面油腻。

- 常联系、好事先想到对方、眼神微笑、惦记、情绪随对方走  
- **酸涩**：女配攻势、同事玩笑 → 男女主不舒服 → 读者代入期待  
- 例取向：《去有风的地方》发短信、朋友圈点赞——小事生活化  

### 内心突破（契机点）

压力下做决定：为救对方弃诺、见对方重伤才懂有多爱等——**必须给契机**。

### 反转

未按读者以为的逻辑发展；例：表面虐实为保护、说反话制造误会。

## 三、感情线六大误区（15–16）

| # | 误区 | 正解要点 |
|---|------|----------|
| 1 | 新手硬写一见钟情 | 比例要高；易恋爱脑；先试婚后爱等 |
| 2 | 为了恋爱而恋爱 | 事业线与感情线交杂；让他们**做事促成感情** |
| 3 | 为了矛盾而矛盾 | 自然生发；先立人设再走故事 |
| 4 | 俗套情节原样搬 | 反套路=**人设反应不同**（壁咚挨巴掌类） |
| 5 | 太过平淡顺利 | 即使温馨也要有曲折（父母爱情级反差抉择） |
| 6 | **转变生硬** | 先婚后爱须经过认识→了解→生情；几章就死活不爱=跳步 |

## 四、拉扯法则（狂更猫 70 · 75）

### 4.1 情绪拉扯定义（70）

> 一方期待拉满、自觉十拿九稳、即将得手 → **被另一方主动终止** → **掌控者换人** → 势均力敌来回。

**关键词**：延迟满足、巨大落差、「裤子都脱了你看这个」式落空。

| 算拉扯 | 不算拉扯 |
|--------|----------|
| 下药以为稳了 → 被扼喉 | 敲门打断 |
| 以为女主来贴火 → 侍应生 | 换姿势继续（开车） |
| 爬床解扣 → 男主推开等婚礼 | 反压继续无落差 |

### 4.2 爱情套路总公式（75）

> **感情好时 → 往分开写；感情不好时 → 往一起凑。**

```text
相识（凑近）→ 误会（拉开）→ 解除误会（再凑近）→ 新误会 → …
每次解除后必须感情升温（信任/依赖加深）
```

大剧情里套小「误会—解除」循环 = 爱情线写长的发动机。

### 4.3 剧情拉扯口诀（70）

**逆着距离写**：甜蜜 → 制造误会分开 → 撮合解除 → 再拆……

人设决定什么误会解得开、什么裂痕撕得大。

### 4.4 信息不对等拉扯（75）

男主知、读者知、女主不知 → 男主推开 → 女主误判嫌弃。  
**女频**疼爱向；**男频**同类易堵点。须先铺信息差给读者，用场景细节带情绪（肩带、关门、车发动）。

### 4.5 感情线开篇硬性要求（75）

> **三章之内男主必须出现**（一女多男至少先出一个）。  
> 可晚见面，但不能十几万字才冒出——前期须**不断提到**男主。

## 五、暧昧与「发现自己有好感」（75 清单摘录）

未挑明时可写：占有欲、脸红、总想起、嫉妒、分享欲、患得患失、注重形象、主动制造见面、包容度变高等。

**落地**：发消息后每次手机响都雀跃 → 不是他 → 扣回桌面 → 是他又秒回——用细节写喜欢，勿空喊「我爱他」。

**相识/熟悉套路库**：英雄救美、相亲、联姻、先婚后爱、共事录节目、反复帮忙等——见 75 课五节，作脑暴清单用。

## 六、对话描写（21 · 公式-09）

### 6.1 对话是什么

> 对话是**有目的的行为**：每人在追逐某样东西。

三大作用：**传达信息** | **塑造人设** | **推动情节**（对话也是行动）。

### 6.2 写好对话四法（课内公式-09）

> **避免直答 | 压缩对白 | 安排关系位（家长/成人/孩子） | 善用沉默**

#### 方法一：避免直接回答

日常一问一答可删；无脑对白不塑人、不给信息、不推情节。

| 原问 | 戏剧性回应取向 |
|------|----------------|
| 吃了吗？ | 「好了，我们离婚吧。」 |
| 吃了吗？ | 「你是猪吗？」/ 用问题答问题（回避） |

#### 方法二：压缩对白

砍赘词（「对」「是的」「好吧」），制造紧张；**口头禅除外**（人设）。

#### 方法三：对话关系位

| 立场 | 语言倾向 |
|------|----------|
| **家长** | 定规则、强迫、终结话题 |
| **成人** | 客观、冷静捋逻辑 |
| **孩子** | 情绪化、牢骚、天真 |

写前先问：此人此刻对他人是家长、成人还是孩子？**同一人不同场景可换立场**（对弟妹像家长，对男友像孩子）。

#### 方法四：沉默

高智商/难写角色：乱写蠢话掉价 → **不说**；一人说一人低头看地，情绪仍在。

### 6.3 对话不干巴

加表情、动作、场景——**作者先看到，读者才能看到**。

干：张三对李四说：「我们还有未来吗？」  
湿：村口梧桐下背对背、看夕阳、声音嘶哑 → 同一句。

### 6.4 提示语形式

提示语在前/中/后/无提示语；无提示语前提：立场分明或语言辨识度够。

### 6.5 感情线里怎么用对话

- **渗透信息**（女频前三章）：用对话、心理、议论交代必知信息，忌说明书（45）。  
- **暧昧**：压缩+回避直答+关系位错位（一方家长式逼问，一方孩子式躲闪）。  
- **误会循环**：一方不解释（直男/高冷人设）→ 对话信息不全 → 读者开天眼（75）。  
- **群戏立人设**：同一压力场下不同对白长度与姿态（21 群戏例：霸/弱/骨气）。

### 6.6 女频答疑口径（09）

对话须推动剧情或立人设；穿插神态动作心理，避免长篇对白。心理/对话卡且与剧情无关 → 多半**删**。

## 八、常见坑

| 坑 | 正解 |
|----|------|
| 六步跳步 | 尤其契机、暧昧、磨合不可省 |
| 配角空降制造误会 | 开篇排进脉络图 |
| 误会解除不升温 | 75 循环空转 |
| 外力打断当拉扯 | 须主动终止、换人控场（70） |
| 对话洗衣机问答 | 四法改写 |
| 表白后只剩甜无波折 | 好时也要往分开写 |
| 感情线男主过晚 | 三章内出场或提及 |
| 清醒人设行为售身矛盾 | 人设扣死行为（75） |

## 九、可复用清单

### 感情线结构

- [ ] 六步各至少一点情节锚定  
- [ ] 每人喜欢/不喜欢的「为什么」写过  
- [ ] 配角非天降  
- [ ] 暧昧铺垫重于表白  
- [ ] 契机点（内心突破）有专门桥段  

### 拉扯与爱情循环

- [ ] 好时是否有「往分开」的一拍  
- [ ] 差时是否有「往凑近」的主动  
- [ ] 解除误会后信任/依赖是否加深  
- [ ] 拉扯终止方是否主动（非敲门/停电）  
- [ ] 信息差是否先给读者（疼爱向）  

### 对话段

- [ ] 本段对话目标：信息 / 人设 / 情节至少一项  
- [ ] 有无直答可改戏剧性回应  
- [ ] 可压缩否（保留口头禅）  
- [ ] 说话者关系位是否明确  
- [ ] 是否可用沉默或动作代替蠢台词  
- [ ] 有无神态场景（湿对话）  

### 开篇（感情向）

- [ ] 三章内男主出现或将出现  
- [ ] 非纯日常甜宠硬写（新人优先剧情线 75）
