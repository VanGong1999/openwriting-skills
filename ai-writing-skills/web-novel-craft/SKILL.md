# 网文写作技艺（web-novel-craft）

网文开书、扫榜、大纲、开篇、爽点与平台向实操的自包含 skill。逐步 SOP 与清单见 [references/playbook.md](references/playbook.md)；细技法见下节 **references**。

## 使用方式（Agent）

1. **先问场景**：免费流番茄长篇 / 他站订阅 / 短篇新媒体 / 纯学习 —— 再选 SOP，避免把番茄日更规则套到晋江等传统站。
2. **输出结构**：结论 → 可执行步骤 → 自查清单 → 避坑；涉及稿费、流量、签约字数一律标 **【经验口径】** 或 **【待核实】**。
3. **不编造**：未在 playbook 中载明的平台政策、收入保证、案例书名细节不得虚构；不确定处标注 **【待核实】**。
4. **需要全文模板时**：读 `playbook.md` 对应节，勿在对话中复述整本 playbook。

## 一、顶层认知（跨课共识）

| 主题 | 口径 |
|------|------|
| 目标 | 撰稿费为主；签约是路径（零基础班） |
| 读者 | 网文写给「更年轻的自己」/情绪价值，不是写给现在的审美傲骨（狂更猫） |
| 题材 vs 实力 | 题材拉首秀量；写法决定单价与留存（狂更猫） |
| 方法论 | 有规划地写、勤于思考 > 闷头苦写（零基础班）；写与投稿/被看见同等重要（红娘子） |
| 长线 | 讲故事本事 > 单站；多本累积；眼高手低利进步（写作课程2） |
| 立意 | 看懂 → 看爽 → 记住（立意）；立意是口碑与成绩的共性（写作课程2） |

**能赚钱的文·六标准**（零基础班 02，全课指挥棒）：冲突多、代入强、节奏快、有爽点、人设讨喜、设定新颖。  
**【经验口径】** 约 2–3 项可签，4 项近爆，6 项大爆 —— 非平台公式。

## 二、两条开书主轴（勿混用）

### 轴 A：四级纲工程（通用长篇 · 零基础班）

```text
灵感/核心梗 → 微创新 → 设定（人设+背景）
→ 草纲 → 总纲 → 大纲 → 细纲 → 正文
卡文回层：大情节→大纲；走场→细纲/代入
```

- **总纲**：一句话主线、独特性纲要、人设表+背景、分阶段剧情（地图/等级/进度）。
- **开篇三法**：冲突（乱+两关口）/ 悬念 / 设定，可叠加；**唯一标准：足够有吸引力**。
- **主角推动情节**；网文主流第三人称内视角固定主角。

### 轴 B：循环引擎（狂更猫 · 长篇日更向）

```text
扫榜 → 书名 → 简介 → 开头 → 写到首秀（禁止先写开头再补书名）
→ 目标+金手指+核心爽点来源 → 三万字/十万字倒推 → 循环结算接新目标
```

- **事件 + 角色目标 = 剧情**；循环 = 用固定金手指反复解决问题的思路，不是「报复一个人一次就完」。
- **稳书**：主线一句话、核心亮点一句话、约 12 万内四个剧情都绕核心；跑偏删掉。

两轴可并用：用四级纲做地图，用循环写日更段落；女频叠加 **四换三**（保主线本质，换背景/人设/金手指）。

## 三、扫榜、拆书、跟风

**零基础班**：只刷**自然榜** + 表格（类型、设定、卖点、节奏、人设、门槛）；空手刷无效。拆书落 **梗概|卖点|感情线|节奏**，问「它怎么帮平台赚钱」。  
**狂更猫**：日扫前约 10 万字，偷「解决问题的方式」；开书三问（循环、中位数收入、同人改动）。  
**仿写红线【番茄·免费流】**：切入点、金手指、第一章结构高度相似易判像 —— 三项避开；简介可抄结构换信息。

**红娘子入门**：先答「谁买单」→ **定位六原则**（喜欢、积累、市场、类型清晰、第一印象、不乱换）→ 再跟风。

## 四、书名、简介、开篇（前三～五章）

| 环节 | 要点 |
|------|------|
| 书名 | 身份+目标+反差（零基础）；题材+金手指+热词+四问（狂更猫） |
| 简介 | 环境+人物+冲突+1～2 尖亮点（零基础）；处境→金手指画饼→路径→爽点预知→收束（狂更猫） |
| 男频 Ch1 | 约 2000 字五信息点；或「稳妥开头五步」（危机→系统能说清→章末预知） |
| 前五章 | 展示主角优势；金手指进入行动；章末**读者预知**（优势将如何作用） |
| 女频 | 五要素+有效突发事件；拆对标前三章「章功能」；忌第一章人过多、空钩子、设定后置到第二章 |

**写作课程2**：黄金一章/首句 —— **类型+主角+矛盾**；打脸留升级空间。  
**红娘子新媒体分支**：第一章约 3000 字生死线（非番茄长篇主路径）。

开篇自检（最小集）：

- [ ] 吸引力优先，非硬凑三章高潮  
- [ ] 思考与定目标已写出（狂更猫强调不可省）  
- [ ] 对比存在（爽点非白送好处）  
- [ ] 下一小目标仍服务大目标/核心亮点

## 五、爽点、期待感、信息差

| 概念 | 课内定义 |
|------|----------|
| 爽点 | **对比**（狂更猫）；落差对比+环境与感官（写作课程2）；马斯洛层次映射多类套路（零基础班） |
| 期待感 | **读者预知**；提前给，新人忌把信息当悬念藏死 |
| 信息差 | 过程拉期待 → 结算画面先定 → 倒推圆谎 → 兑现超预期 |
| 情绪 | 一章约 2～3 个引爆点；女频重人设+情绪，拉扯须「主动终止」非外力打断 |

**好看段落最小式**：读者预知 + 视角对比（重点角色心理转变）。  
**主视角链**：所见→五感→思考→金手指问题→再行动。

卡文：**不卡文神器** 十步（狂更猫）—— 卡在第几步只做下一步；或零基础班分型回纲。

## 六、人设与金手指

- **三维**：一维速立 / 二维事件堆叠（男频主战场）/ 三维可选；反派更坏或镜像主角。
- **金手指**：少而可延伸、弱开有成长；把不合理合理化；服务爽点（零基础班）。写作课程2：**唯一、可升、有限制、易懂、勿多、勿完全依赖**。
- **创新**：新手 **微创新/反套路/穷举组合**，勿神话「开类型」。
- **人设倒推**（狂更猫）：类型+结局 → 节点 → 能力性格表 → 用 3+ 小剧情演给人看。

## 七、番茄免费流（仅适用免费广告流）【番茄·免费流】

以下摘自狂更猫课内口述，**发书以后台为准**：

- 习惯：**日更约 4000**，禁扎更；验证期勿断更；勿无封面/默认封面敷衍。
- 数据：重 **追更比**（宜 ≤3:1）、**完读**（大众题材常见参考 ≥15%），轻书架比/催更迷信。
- 节点（**【经验口径·待核实】**）：约 2 万签约、约 8 万验证节奏、约 10 万首秀、约 20 万书测；热门勿短时间囤满 8 万。
- 女频：首秀差较常见；第一本不宜轻易切书，建议锁 **≥20 万** 书册再判断。
- 收入粗算（**【经验口径】**）：约 1 万流量 ≈ 100 元；睡后收入叙述 tied 完结体量与曾经月稿质量（见 playbook §7）。

**勿将本节套用到纯分成订阅站**；他站用零基础班「六种站风」+ 目标站自然榜对标。

## 八、合同与收入（简述）

零基础班：合同三型 —— 纯分成 / 保底+分成 / 买断；收入 = 电子（订广赏奖）+ 版权改编。  
细节与案例数字见各课「待核实」；回答用户时不做收益承诺。

---

## 九、立意与 IP（长线 · 写作课程2）

立意不是说教，而是「读者记住什么」。IP 是可持续改编的产品；**完结后**放大常见于课内案例口径。与开书循环不冲突：先靠题材与爽点活下来，中后期再抬立意密度。

## 十、高频避坑（精选）

| 坑 | 正解 |
|----|------|
| 以签约为唯一目标 | 盯六标准与撰稿费路径 |
| 先写开头后补书名【番茄】 | 扫榜→书名→简介→开头 |
| 拆书只贴「有悬念」 | 四表+赚钱机制 |
| 无纲硬写 | 至少四级路径或千字大纲+分章细纲 |
| 爽点=发奖励 | 写对比与预知 |
| 金手指满级开局又多个 | 少、成长、合理化 |
| 游离核心的支线特写 | 稳书：删或与核心亮点无关则砍 |
| PLATFORM 错配 | 先对标站风开篇再写 |
| 盲目跟风无自检 | 扫榜+四换三/微创新边界 |

完整避坑见各课精华与 playbook。

## 十一、学习路径（归纳）

**零基础第一周（红娘子 + 零基础班 02/04/06）**  
定平台与类型 → 拆一本对标开篇四表 → 标签六原则钉赛道  

**开书月（狂更猫 02/04/27 + playbook §1–5）**  
书名简介过关 → 前三章 → 定循环终点 → 日更锚点  

**边写边修（零基础班 18–38 + 写作课程2 爽点/高潮）**  
叙述、情绪、悬念、破卡文  

**15 万字体感后**  
三维人设、英雄之旅、热销拆解（零基础班 44–49）；稳书与十万字倒推（狂更猫）
