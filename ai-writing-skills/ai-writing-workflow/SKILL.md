# AI 写作工作流

**定位**：AI 是「概率抽卡器 + 初稿机」——擅长枚举、扩写、视觉化、台词风格化；不擅长逻辑终审、市场取舍、阅历与合规。课程共识：**约 80% 初稿靠 AI，20%+ 精修必须人做**；输出通常只取可用 **30%–50%**。

**本 skill 管「怎么用 AI」；不管「怎么写好某一种成品」。** 动笔前按体裁加载：

| 体裁 | 同步加载 |
|------|----------|
| 结构/人物/节拍体检 | `story-fundamentals` |
| 小程序短剧、充值点、场戏 | `short-drama-manhua` |
| 网文连载、品类、扫榜节奏 | `web-novel-craft` |
| 盐选/短篇成稿 | `short-story-salt` |
| 电影/长剧/Pilot | `screenwriting-longform` |
| 公号爆文 | `new-media-viral` |
| 带货商业文 | `commercial-content` |

细节模板、去 AI 味步骤、漫剧 SOP、缺点清单：见 [references/playbook.md](references/playbook.md)。

## 何时用 AI / 何时不用

**适合 AI**

- 批量生成核心梗、标题、方案（多抽卡交叉对比）
- 在**人已定的**结构下：单章/单场/单集、10 集一轮
- 卡点时：多方案（解决方案法）、视觉化分镜描写、台词个性化
- 结构化扩写：梗概 300–500 字 → 大纲 → 章纲
- 润色指令：去陈词、改标点、缩短句、改口语
- 换元法 / 四步核心梗组合的**候选 brainstorming**（人筛、人改）

**必须人主导（勿甩给 AI 终审）**

- 选题、男女频、付费点、对标赛道
- 逻辑复核（AI 改逻辑易越改越乱）
- 人设一致性、伏笔节奏、商业钩子
- 合规/擦边尺度、侵权与洗稿边界
- 投稿交付：手搓从**第一次 AI 输出**就开始，禁止整篇直出

**误区（一句话）**：两个人机对话（人只转发 AI 原文）= 高 AI 味 + 高拒稿率。

## 默认工作流（按任务裁剪）

```text
0. 人定：体裁 skill + 对标作品 + 篇幅/集数/单篇字数
1. 创意：核心梗多方案（四步叠加 或 换元法）→ 人拍板 1 个
2. 骨架：人写或人机共创梗概/前十集纲 → 锁定基调（第一次输出定全篇调子）
3. AI 分步生成：单次 ≤2000–3000 汉字；10 集/章一轮；每轮喂「前序结果+格式约束」
4. 校正：补字数/场景/台词功能；分镜化（漫剧去小说化）
5. 去 AI 味 + 手搓精修（逻辑/镜头/人设/钩子）
6. 交付前质检（见下 checklist）
```

**查理短剧四法**（拟人沟通，非搜索引擎）：**指令法**（角色+背景+任务+输出要求）| **对标法** | **交互法**（小步交换）| **元素法**（单场/单元素，勿一上来全本）。

**知乎故事文 SOP**（新媒体/短篇）：选题 → 标题 → 大纲（篇幅+三要素+叙事手法）→ 正文（成语接龙共创 / 跑团关键词）→ 润色 → 排版。

**九格漫剧 SOP**：定核心梗 → 前十集纲 → 第一集剧本 → 分镜+去小说化 → 校集 → 去 AI 味 → 手搓 → 扩展大纲 → 循环。

**从 0 到 1（交互交换）**：背景 → 人物 → 300 字梗概 → 大纲 → 分目/分集 → 剧本；**每一步输出经人改后再当下一步输入**。

## 提示词结构（通用）

复杂任务用 **Markdown 分段 + 思维链**（先做什么、再做什么），避免一段话塞满导致 AI 丢需求。

**短剧指令四段式**

```text
【角色】你是（竖屏）短剧编剧 / 漫剧编剧 …
【背景】类型、体量、前情、已锁定核心梗 …
【任务】本步只完成：如「写第3集场戏」「给偷回物品的3种方案」
【输出】字数、格式、禁止项（如：不要小说化心理描写）、参考范文格式勿抄内容
```

**反客为主**（不会写 prompt 时）：让 AI **先向你提问**再写。

**核心梗四步叠加**（漫剧/脑洞向）

1. 世界观（时代/规则）
2. 人物身份反差（本是 A 实为 B）
3. 金手指 + **限制**（避免无敌空洞）
4. 核心动作 / 追剧点（强画面、强情绪）

要求 AI 一次出 5–10 个候选，附元素拆解表；**人**选有「跟热点 + 微创新」的项。

**换元法**（短篇/知乎风仿写）

- **一度**：换背景、人物、道具；事件结构尽量保留
- **二度**：换核心事件，其余联动改；AI 核心事件易老套，**必须人改**
- 六大源：事件、结构、主体、背景、人物、道具；仿写时量化：章数、章字数、情节点密度 **1:1 对标**

完整可用的换元法 Role 模板见 playbook「换元法」节。

## 去 AI 味（执行要点）

AI 直出特征：套路比喻（像…仿佛…）、总结词（综上所述）、短碎错标点、官方书面词、过滤词泛滥（看到/觉得/感觉）、笼统动词（走/拿/打）、同义堆叠、`**` 痕迹未清。

**原则**：润色时**不改**主题、走向、关键场面；**要**改表达、节奏、人物口气。单句检测工具仅参考；编辑看**通篇**。

V3.8 类流程（可让 AI 执行，人再审）：

1. 修语法标点、拆长段、短句（约 ≤20 字为主）
2. 去比喻 → 动作/神态/他人反应；去「感觉/似乎」
3. 对话口语化、人设区分台词
4. 删 AI 总结词、华丽排比、无信息抒情

完整步骤与自查清单：playbook「去 AI 味」节。

## 质量门禁（提交前）

**技术**

- [ ] 单次生成未超长；长对话后若字数萎缩 → 新窗口 + 前文摘要重喂
- [ ] 未让 AI 做「逻辑终审」或「自查完美」
- [ ] 人设/称谓前后一致（长文易失忆）

**内容**

- [ ] 漫剧/短剧：画面可拍，台词推动情节，非小说腔
- [ ] 梗/简介经人手写或重度改写，非一次性直用
- [ ] 核心事件不老套；衔接点、钩子、伏笔有人补

**AI 味与合规**

- [ ] 去 AI 味 checklist 过一遍（见 playbook）
- [ ] 格式干净、无批量生成痕迹
- [ ] 敏感题材与侵权红线已过（体裁 skill 内规则优先）

**能力养护**：周期性降低 AI 占比或停用手搓一周，避免选题能力空心化。

## 工具分工（课程口径，非唯一真理）

| 场景 | 常见选择 | 留意 |
|------|----------|------|
| 逻辑/大纲 | DeepSeek 等 | 爱加戏、爱科幻、长文平庸 |
| 可下载/表格 | 豆包 | 小说化、表情多、台词干 |
| 去 AI 味 | 专用模型/提示词（如训练营 3.8） | 工具误判存在；勿过度删词致死板 |
| 长上下文续写 | Claude 类 | 仍建议分步交换，非一次万言 |

**人**选模型；**人**判断哪 30% 能用。

## 与体裁 skill 的衔接

| 本 skill 产出 | 交给体裁 skill |
|---------------|----------------|
| AI 大纲/分集 | 短剧：20 节拍、充值点、场三角；漫剧：单集卡点、800–1200 字/集 |
| AI 人物表 | story-fundamentals：缺陷、欲望、关系网 |
| AI 短篇正文 | web-novel：爽点密度、导语四要点、平台口味 |
| AI 台词 batch | short-drama：潜台词、身份、镜头可剪 |

先结构后辞藻：AI 写得再顺，**节拍不对**仍回到 `story-fundamentals` 体检。
