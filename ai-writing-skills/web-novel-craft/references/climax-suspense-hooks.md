## 二、伏笔 vs 铺垫（32 · 公式-17）

| | 伏笔 | 铺垫 |
|--|------|------|
| 阅读感 | 闲笔，当下不注意 | 重要，缺则不流畅 |
| 距离 | 长线 | 短线 |
| 可否删 | 常可无感 | 不可删 |
| 体量 | 点、一句、小特征 | 环境、身世、信息烘托 |
| 作用 | 前后照应、结构严谨 | 烘托、推情节、造悬念、增张力 |

**伏笔要点**：有伏必有应；切忌刻意显露；伏笔与照应**勿紧贴**。  
**铺垫三常用**：背景铺垫｜衬托式（先写强者再衬主角更强）｜反差式（盼富豪儿子→穷鬼）。

课内态度：**别死抠标签，用活即可**（精华避坑）。

## 三、高潮桥段（33 · SOP-18）

### 3.1 误区纠偏

| 错 | 对 |
|----|-----|
| 高潮＝激烈打斗一场 | 取决于整体走向：前有低潮/平缓铺垫 |
| 作者砸大场面 | 读者心理：谜题将揭、胜利将近、情绪将释 |

### 3.2 欲扬先抑 · 低谷两向

1. **重重困难**：灭门陷害、屡次上当、忠仆之死等蓄力。  
2. **情绪压制**：想做不能做；装作不识亲人再爆发。

### 3.3 爆发三模式

1. **真相揭秘**：身世、三年之约决斗等悬念兑现。  
2. **主角光环**：绝处逢生、扮猪吃虎打脸（庆余年诗百篇）。  
3. **剧情反转**：意料之外情理之中；局中局。

### 3.4 大小高潮与事后

- 小高潮可反复；大高潮多线伏笔铺垫集中引爆。  
- **不可逆反馈**：新技能、正义兑现、得宝、格局回不去（33）。  
- 流程：`低谷 → 逼绝路 → 爆发 → 不可逆反馈 → 新平缓/低谷`

**避坑**：高潮≠打得凶；须欲扬先抑+不可逆反馈（精华）。

## 四、调动情绪（35 · 公式-20）

- **一章 ≥ 2～3 个情绪引爆点**；无引爆点读者难追。  
- 方向：**共鸣**（写读者熟悉的）｜**对比铺垫**｜**小事+回忆+感情**。  
- 平台画像：无限言情向（实习学生、霸凌）vs 新媒体向（35+、赘婿神医等）——写熟悉经历+主角圆梦反打。  
- 人物：**对比法**立反派/对照组；**铺垫法**先抑后扬。  
- 普通事件变重要：对主角特殊 + 回忆 + 感情流露。

扩大化感染读者；避免干巴或用力过猛尴尬。

## 五、爽点：零基础需求坐标 + 狂更猫对比链

### 5.1 零基础班（36 · 表-21）

- 网文＝解压快餐；爽点＝替读者满足需求并抬层次。  
- **马斯洛五层 → 约十二类套路**（生理困境/开车｜死里逃生｜美女如云｜全员爱女主｜碾压反派｜扮猪吃虎｜得宝｜报仇｜破规则｜征服欲｜好为人师｜推大 Boss）。  
- 不限于十二类；**铺垫与对比决定强度**。

### 5.2 狂更猫本质（22 / 61）

| 概念 | 本质 | 要点 |
|------|------|------|
| 爽点 | **对比** | 别人普通你牛逼；白给好处不爽 |
| 期待感 | **读者预知** | 新人忌把信息当悬念藏死 |
| 超预期 | 给两倍 | 承诺 vs 兑现 |
| 好段落 | 预知 + 视角对比 | 重点角色心理转变 |

**期待感有效条件**：预知须与主角或主角在乎的人**有关**（22）；作者控期待靠前置信息，不靠主角是否已知。

### 5.3 爽点分层与延续（12 · 25 · SOP-25）

- **读者预知 + 欲左先右 + 分层爆发**；勿一次砸完，可卡在期待高点。  
- 无目的铺垫＝耍流氓：须知后面打脸谁，前面才写得小丑态。  
- **未发生时更爽**：确定将爽比正在发生更易写爽（25）；超出预期须合理合逻辑。  
- 过程多看铺垫/反应/爽点；金手指用于**压缩**不爽过程（25）。

### 5.4 加料 SOP（61 · SOP-24）

```text
定事件 → 金手指=读者预知1 → 叠加预知
→ 先定结算画面 → 倒推圆谎
→ 过程信息差拉期待 → 兑现+超预期
```

### 5.5 信息差（60 · 16 虐感交叉）

- 广义：时间差、身份差、事件差、各角色知悉度差。  
- **一层信息差只榨一层期待不够**——多角度续期待。  
- 女频：对比要带群众/舆论；少只写两人对视。  
- 突变黑化须前文铺垫行为风格。

### 5.6 循环内爽点（44 / 51 · 见 playbook）

- 三要素：目标 + 金手指 + **核心（爽点来源）**；主线≠核心。  
- 八步循环：目标→阻碍→围绕核心造对比爽点→快展示奖励→结算→新目标（精华 SOP-05）。

## 六、悬念卡点：瞬间悬念七法（38 · 表-23）

**卡点**：章末留钩；**瞬间悬念**：场景内任意可加钩处。  
**原则**：不给出解决方案，把答案藏起来。

| # | 方法 | 要点 |
|---|------|------|
| 1 | 微观障碍 | 不起眼的人/物带来枝节；列 10 个障碍练插入 |
| 2 | 提高赌注 | 情节/人物/社会赌注逐级升高 |
| 3 | 限制时间 | 任务+时限+障碍；高潮前常用；可双线分叙 |
| 4 | 打断 | 话说半句、神秘人逃走 |
| 5 | 拿掉能力 | 失金手指、断通讯、失忆等拖摆脱困境 |
| 6 | 增强反派 | 盟友增援、人质、掌握秘密 |
| 7 | 情感与思想 | 内心拉锯拖延解决（手术赌命等） |

**训练**：选两页平淡场景，按上表改写（38 课后要求）。

**与四类悬念配合**：核心/超级宜长线；场景/段落宜章内；七法宜微观卡点。

## 七、一段剧情的最小验收（狂更猫 + 零基础）

```text
本章有 2～3 个情绪引爆点？（35）
爽点是否有对比、预知是否提前给？（61）
章末或段内有无瞬间悬念？（38）
本段是否服务核心亮点/循环终点？（51）
高潮前是否有抑、爆发后是否有回不去的变化？（33）
```

| 坑 | 正解 |
|----|------|
