# 叙述技艺 Playbook

> 中文网文**叙述与描写层**技艺蒸馏。公式照课堂口径；体验型建议标【经验口径】；非科学或待核标【待核实】。

---

## §1 画面转化：三大病因与五招（F-11）

### 1.1 写不出画面的三大病因

| 病因 | 表现 |
|------|------|
| 画面多而杂，缺空间层次 | 情节硬补镜头，无远近与逻辑 |
| 叙述缺总布局 | 想到什么写什么，无「导演调度」 |
| 词汇与转化训练不足 | 少写、少对照，心中无具象词 |

**「感觉宏大却无力」**：常因自觉加了情感，脑中却只有模糊色块或局部；缺衔接与细节 → 情感传不到纸上。画家练层次；写作者亦需练「脑中画面是否真可拍」。

### 1.2 五招 SOP

按段选用，可叠加，忌五招每句堆满。

#### 招 1：以点盖面（课内用语；常见成语作「窥一斑知全豹」理解）

抓**一个小重点写透**，余者由读者脑补。

- 宏大战役：不必写遍硝烟与每个士兵；**聚焦一名战士**（最后生还/濒死）的细节，衬托战役艰难。

#### 招 2：按顺序铺排（电影镜头）

脑内画面为情节服务时易乱 → **文字 = 镜头**，强制顺序。

示范链：先情侣或空镜美景 → 一声嘶喊撕裂宁静 → 视线移向吵架男女。  
优于直写「某美景中男女吵架」。

**训练**：编剧式拉片——看到什么信息点写什么；常练 **空镜 → 声音/异动 → 聚焦人物**，利 IP 向画面感。

#### 招 3：扬长避短（侧面）

脑中有的不必全写；不擅长处别硬写。

例：女主视角，夜战看不清 → 不写拳脚，写**被劈断的树、撞破的门**等声效与结果（古龙/玄幻「只写效果」感）。

#### 招 4：增设细节

画面糊、无感染力 → **一两笔**即可，不必长描。

| 意图 | 细节例 |
|------|--------|
| 被迫出嫁 | 眼红血丝；泪痕在眼角结白痂 |
| 破败/秘密/尸体 | 门前酒瓶；桌上馊饭；桌角半只鸡 |

#### 招 5：加感官（服务细节）

| 感官 | 可写 |
|------|------|
| 视 | 神态、动作、衣着、环境 |
| 听 | 语气、环境音 |
| 嗅 | 气味 |
| 触 | 触感 |

**原则**：只写能反映场景、突出情感的点；事无巨细 = 啰嗦。  
走剧情时若饭无伏笔，「香气四溢」一带即可，勿展开好吃难吃辩论。

### 1.3 提升转化力的练法

| 优先级 | 练法 |
|--------|------|
| **强烈建议** | 小说改编影视：按画面写文字 → 再对原著 |
| 可选 | 仿写他人段落，合书对比缺口 |
| 低效单列 | 单靠「写作理论书」而无拉片对照 |

### 1.4 五招自检

- [ ] 是否先怀疑「脑中画面」不完整？
- [ ] 大场面能否缩到「一点」？
- [ ] 是否有一条镜头顺序（非信息爆破）？
- [ ] 弱项是否改侧面？
- [ ] 感官是否每条有功能？

## §2 语言流畅与镜头顺序（F-08）

### 2.1 排版：短段 + 短句

- **【经验口径】** 适时分段：单段约 **1–48 字**，最多约 **50 字**；视觉约三行半舒适（非平台硬规）。
- 长句十几二十字堆一处 → 拆短句，不必等「文笔变神」。
- 气质参考：李碧华式短句朗朗上口，利网文节奏。

### 2.2 动态顺序（动作）

目标：读时有电影感。

**SOP**：笼统动作拆成**连续动词/小步骤**（作文「兔子偷萝卜」：跳进田、刨土、拔萝卜……）。

- 女频：暧昧互动（贴近、转头、拉手等）按轨迹写。
- 男频：打斗按招式/身体位移拆帧。

**【经验口径】** 练笔可细到夸张；正文不必段段如此，关键是会拆动词。

### 2.3 静态顺序（景、物、静人）

作文老法，**一次只用一种**：

- 由远及近 / 由近及远  
- 从上到下 / 从下到上  

四种混用易乱。

空镜示例链（静谧夜）：小镇远观 → 月色 → 路、墙、房 → 远处声 → 马厩 → 工人动作与烟……  
作者按「日后可漫画」想画面 → 镜头感强。

### 2.4 流畅自检

- [ ] 段是否过长？可再切吗？
- [ ] 一句是否塞多事件？能否一效一句？
- [ ] 动作用动词链；静景是否定了单一观察轴？

## §3 人称与 POV 决策

### 3.1 人称选择（网文向）

| 人称 | 网文倾向 |
|------|----------|
| 第一人称「我」 | 早期多；悬疑灵异仍有。新手弊端：视野窄、易不自觉插第三人称 → 乱 |
| 第二人称「你」 | 传统文学实验；**网文不适用** |
| 第三人称 | **主流**；配合**内视角**补代入 |

**混用【课内口径】**：网文**不建议**第一、第三混写。可全书第一人称，**番外**用第三/上帝补写。单章换人称「一章我一章他」仍不建议。

### 3.2 视角三类

| 类型 | 能写什么 | 常用 |
|------|----------|------|
| 全知（上帝） | 任何人言行与内心 | 信息全开、丰富剧情 |
| 限制（角色） | 一人或少数内心 | 悬疑、强代入 |
| 客观（旁白） | 只记言行表面 | 画面强、代入弱；案发现场等 |

上帝可进任何人内心；客观不能。

### 3.3 推荐默认：第三人称内视角 + 必要时上帝辅助

开篇尤宜角色视角：先闻、觉、见 → 再内心与信息（如重生记忆），强于纯外部背景灌输。

**新手大坑：多人心理齐飞**  
同段内 A 心想、B 头晕、A 又怒……一章 3–5 人全会潜 → 代入崩。

**规则**：所见、所想、所闻等，主要给**当前主视角**（通常主角）。

### 3.4 何时切视角？

**总原则**：稳定主视角加深代入；**必要时**才切配角。

| 场景 | 做法 |
|------|------|
| 不同场景 | 直接切（配合 §5 转场） |
| 同场·对手戏 | 为侧面烘托主角可切；**一段稳定一人**；忌来回横跳 |
| 同场·非对手戏 | ① 先镜头落到某人再写其心理 ② 双方目光落同一物上自然过渡 |

切视角 = 自然转镜；**硬注意：勿切太频，要稳定。**

### 3.5 人称代词

- 同段反复同名 → 第二次可改他/她。  
- 全篇只用专名：非致命，但能替则替。  
- 多人同场「他/她」歧义 → 必须消歧。

### 3.6 POV 与「对比剧情」的衔接（见 §8）

单场**有心理活动**的角色：**【经验口径】最多约 2～3 人（含主角），老师倾向两个**。  
一旦写心理，读者默认「自己人/重要角色」。  
次要视角：反应、对白可给；**不写心理**。

### 3.7 POV 自检

- [ ] 全书人称是否稳定？  
- [ ] 本章是否多人齐飞？  
- [ ] 切视角有过渡物/落点吗？  
- [ ] 代词是否清晰？

## §4 外貌描写

### 4.1 作用（不单为「看见脸」）

| 作用 | 说明 |
|------|------|
| 推动情节 | 美→争夺；疤→后文线索 |
| 塑造形象 | 脑海成形 |
| 表达情感 | 喜怒落在面目与形体 |

**时机**：不在严肃紧张处硬炫美（如濒死穿越大段帅描）→ 割裂；痛苦时写美须有特殊叙事功能。

### 4.2 网文原则：氛围 > 五官全集

- **一个特点/记忆点**即可（四条眉毛、「美男子」口碑而非工笔五官）。  
- 事无巨细眼鼻嘴 → 变普通人。

### 4.3 观察顺序 SOP

符合**当下角色**怎么看，非上帝乱丢。

1. 远：高矮胖瘦  
2. 近：精神面貌、穿戴  
3. 更近：具体五官或局部  

**局部→整体**：先见纤手抢物 → 手至面再周身。  
经典气质：突出特点 + 比喻（豆腐西施式）。

### 4.4 详略

| 角色 | 写法 |
|------|------|
| 路人 | 一词或一名 |
| 有伏笔配角 | 可识别特点，不必工笔 |
| 主角 | 不必登场五官齐全；光环氛围 + 一点；细节在**恰当舞台**释放（弹琴写手、观物写眼、打斗写肢体） |

**舞台效应**：不是处处可炫美，要在氛围里被体会到。

### 4.5 小白 vs 老白【赏析取向·非优劣判决】

氛围词多 vs 具体道具/细节多；古言细描需考据或笔力，做不到可氛围词 + 对标大神差距自检。

**【待核实】** 面相书（如《麻衣神相》）仅为课内「外貌—性格联想」参考，非科学公式。

### 4.6 外貌自检

- [ ] 本场写外貌是为情节/情绪/伏笔，还是作者炫技？  
- [ ] 是否一个记忆点胜过五官清单？  
- [ ] 顺序是否跟随观察者？  
- [ ] 路人是否过头描了？

## §5 过渡转场六法（F-19）

过渡 ≈ 转场，纯技巧；掌握后场景可硬切也可润滑。**轮换使用**，忌全篇只靠省略号。

### 5.1 总表

1. 时间  
2. 地点  
3. 环境描写  
4. 相似物/景/语/动作/想法/外貌/眼神  
5. 语言类（对白、介绍旁白、心理旁白）  
6. 格式（省略号等）

### 5.2 时间过渡

短时间短语切时段：××年前的一天；又过了几年；第二天一早；午时三刻……

### 5.3 地点过渡

- **无铺垫**：直接抛新地名（可用，或突兀）。  
- **有铺垫**：角色移动、禀报、邀约、要做之事 → 读者带预期再切（如喃喃「明天结婚」→ 切婚礼）。

### 5.4 环境描写过渡

下一场景**空镜**衔接：对话收束 → 角色动作一瞥 → 马车、烈日、树枝擦车声…… → 自然进入「在路上」。  
景物须服务「切到下一场」。

### 5.5 相似元素过渡

物、景、语、动作、想法、外貌、眼神等同质衔接。

例：摩挲玉佩 → 闪回塞佩；黄叶窗前 → 黄叶落脚边；名册点「小美」→ 小美还在百米外狂奔。

**原则**：直接转即可，勿过度设计。

### 5.6 语言类过渡

1. **对白/同一动作**：两场景各骂「败家」；各拍桌/喝酒。  
2. **介绍旁白**：战队成绩、屋内谁围着谁、某人进会议室被无视——场与场接上。  
3. **心理旁白**：心事被点破 → 暗想后果 → 大笑出招（动机+过渡一体）。

### 5.7 格式过渡

省略号硬切：**偶尔可用**；部分编辑不喜；【经验口径】故事够好影响小，但审美易疲劳。

### 5.8 转场自检

- [ ] 本章是否只会「……」？  
- [ ] 切地前有移动/预期吗？  
- [ ] 六种是否换着用？

## §6 电影级画面感与叙事手法

**定位**：故事已能写通之后，用**有记忆点的画面**与手法把书写漂亮。「书里先是感觉，再圆逻辑。」

### 6.1 画面 ≠ 无效肖像

摸鼻、心微颤、眼神、泛泛心理；配角棒棒糖/胖子帽当「人设」——多为**无效描写**，不留印象。  
开书阶段：**优先代入感**，勿执着堆人设标签。

### 6.2 氛围先于表演

悲伤：可先雨夜、萧瑟、满地烟头，再让人物演；怼脸「哭」常无神。  
氛围够 → 减少说明性「他很悲伤」→ 读者不易一眼看穿。

**文笔【课内口径】**：多数读者按段读，看懂即可；通感可点缀，非核心。

### 6.3 记忆点标准

读者**数天后仍记得什么镜头**？  
空洞擂台互殴 → 常只想看结果 → **无记忆点则直给结果**。  
有效：江边渔火、大桥、雨、沙滩等可设计环境；大场面用「放大镜」写局部，非全景说明书。

细节须**带情绪色**：如风吹鼻毛 → 猥琐气质；氛围物件+微表情可几乎无心理仍被记很久。

**反常识更易记住**：暧昧「差点亲上」复制千遍无点；非常态小动作（喂蚂蚁、一脚踩死）可钉住讨厌/画面。

**无意义的美**：巨大樱花「就是好看」亦可——不必句句服务剧情工具【课内观点】。

### 6.4 写作激情与「先帅后圆」

麻木路径：只盯目标、金手指、对面怎么追。  
有感觉路径：先帅场景（雨夜楼顶黑伞、松手、纵身）→ **下章再圆**怎么不死、为何跳。

没有电影一直高潮；**今天先帅，圆放后面**。

### 6.5 偷窥式叙事（爽点放大镜）

- 口感重，放大甜/爽/怖。  
- 不必真有人偷窥，要**偷感**。  
- 偷看者须**重要人物**；被偷看者通常不知 → 保逼格。  

**操作**：主角做事 → 被重要人物「无意」看见 → 放大情绪与信息差。

例：后山偷看突破；女主偷看男主做饭却电话谎称加班。

新人若爽点仍弱：先学爽点再学偷窥放大。

### 6.6 电影叙事自检

- [ ] 三天后还记得什么镜头？  
- [ ] 是否先氛围再表演？  
- [ ] 细节有情绪吗？  
- [ ] 过程可否省略只留结果？  
- [ ] 本段能用偷窥放大吗？  
- [ ] 是否误删所有「无剧情」氛围空镜？

## §7 代入感：先有兴趣，再五法

**定义**：让读者**沉浸在某一段情节**。  
**先决**：引起兴趣（戳软肋）——无兴趣，技巧难生效。题材须作者能写出真实情绪；不猎奇硬写不擅长。

### 7.0 兴趣例

救下雨天生病的猫 → 爱猫读者愿跟；换无关冷门题材 → 兴趣归零。

### 7.1 六觉法

视听嗅味触 + 心理；作者先代入再写。

追杀例：风声、心跳、血腥味、尖石、悬崖、喉间铁锈味、无力回天——**每觉须有意义**（血腥=重伤=困境）。

**不必每场六觉全上**：2–3 个即可。扮猪吃老虎引敌时，可删伤觉改心理（「仇怨在此了结」）。

发散：场景/神态/对话本质同则——**能烘托气氛的保留，不能的删**。

### 7.2 后果法

让读者知**发生后会怎样**，情绪波动代入。

- 写「1」让读者感到「2、3」：惨状暗示将被杀/折磨 → 担心、盼反转。  
- 直白：「打我的后果？我可是××少爷」→ 盼打脸。

落笔问：本情节的后果读者能感知吗？

### 7.3 聚焦法

大事件中途**不插无关线**、无推动梗。  
 analogy：解题到关键时刻被叫吃饭——扫兴；读者跳章。

一条主线深入，勿线条间乱跳。

### 7.4 重复法

重复刻画标记 → 快速联想。  
例：杀人前吃糖 → 要死人的暗示；糖与女儿、信任、决裂层层可叠。  
只点习惯不说名，读者自动联想人物。

### 7.5 普纵法

写大众**共情**价值观（逆行救灾、出轨挚友、天价衣赔不起）一句调动情绪。  
过分另类宇宙观难共鸣。

### 7.6 代入自检

- [ ] 本段目标读者会感兴趣吗？  
- [ ] 感官每条有叙事功能吗？  
- [ ] 后果可感吗？  
- [ ] 是否插了无关枝节？  
- [ ] 有无可重复的标记物/动作？

## §8 剧情段：对比、读者预知、明暗牌

> 本节管「一段戏怎么更好看」，不管全书大纲。对比是平淡剧情第一补药；**爽点本质常是对比**。

### 8.1 视角与对比

- 对比项可多，但**以视角为主**（人能反应）。  
- 视角不是越多越好；【经验口径】循环过大、视角过多 → 写不过来、代入崩。  
- 重要配角不要「写十几章只为打一次脸就扔」。  

**主次法则**（与 §3.6 同）：重要视角给心理；次要只反应/对白。

同人场可多人脸熟，仍**只给重点心理**；群像「全员心理」= 死。

### 8.2 一段剧情最小公式

```text
读者预知（信息前置，带期待）
+
视角对比（核心角色心理转变）
→ 好看的一段
```

**没有读者预知，铺垫视角无意义。**

对比对象：对手、师兄、老祖、过去的自己……选能让爽点最大化的。  
可双重对比：功法阶位 + 视角震惊。

### 8.3 读者预知怎么给

你要知道读者**期待什么**，再前置什么。

- 信息可主角知，也可**只给读者**（上帝视角导演密谈）——读者预知 ≠ 主角预知。  
- 主角不宜长期「一无所知」。  
- 满足期待 + 对比反应 = 更大爽；**额外收获** = 爽点溢出。

### 8.4 明暗牌【身份信息差】

- **明牌**：身份敞开（人人知歌神）。  
- **暗牌**：隐藏（蒙面、马甲）；读者知而书中人不知。

目的：信息差 → 期待（掉马甲震惊）→ 追更钩子。

**风险【课内强调】**：掉马甲若无更新鲜期待 → 易弃；故常「马甲掉不完」或长期不曝。  
**隐藏身份是延续期待，不是增强期待的万金油**；大部分戏 **预知 + 对比已够**，勿滥用暗牌。

### 8.5 剧情段自检

- [ ] 本段核心对比视角是谁？心理转变设计了吗？  
- [ ] 次要角色是否误写心理？  
- [ ] 读者预知几条？是否在对比前到位？  
- [ ] 有双重对比分层吗？  
- [ ] 若用暗牌：掉马甲后下一钩子准备好了吗？  
- [ ] 单场心理是否超过 2～3 人？
