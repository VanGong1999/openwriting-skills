# Commercial Content（商业带货写作）

本 skill 提炼知乎短篇创作营「商业带货实战 + 故事化商业写作 + 内容扩展」，并轻量吸收北大博士课（品牌/说服）、馒头哈佛故事课（信任/公共叙事）中与**转化向内容**相通的部分。立场：**先卖点后模板**——没 FABE，套路是空壳；**利他节奏**优先于硬广参数。

**公式与模板**：见 [references/playbook.md](references/playbook.md)。

---

## 适用场景

- 从 0 写种草/好物/测评/经验文（图文；短视频/直播脚本可同构）
- 定结构：不知用「教程解法 / 多品对比 / 个人经历」哪种
- 提炼卖点、标题、开头、配图清单
- 品牌约稿、知乎好物卡片、横向盘点 3 款以上
- 故事化带货：起承转合、粘性六原则、用户/价值观对齐（轻品牌向）
- 发稿前合规体检（商业/平台/广告法）

## 不适用场景

- 纯小说/盐选专栏 IP 创作（结构层可借 story-fundamentals；专栏变现细则非本 skill 主战场）
- 网文连载节奏、短剧分集卡点（见 web-novel-craft / short-drama-manhua）
- 法律咨询、医疗器械功效认定、平台规则终审（本 skill 给创作口径 + 红线，不替代法务）

## 先选结构，再动笔

| 读者状态 / 产品类型 | 首选模板 | 核心节奏 |
|---------------------|----------|----------|
| 有明确痛点，愿学方法 | **解决方案型** | 需求 → 方法（颗粒度）→ 产品作必要/增效因子 |
| 决策久、可囤货、易踩雷 | **横向对比型** | 分类 → 每款约 300 字 FABE+人群 → 卡片/图 |
| 需信任、情感温度 | **经历分享型** | 起承转合 + 虚假成功 |
| 极短种草、熟悉品类 | **三分法**（开头结果/主体卖点+经验/结尾引导） | 配产品图 + 效果对比图 |

**带货文总流程（先导片）**：① FABE 找卖点 → ② 套模板（上表或三分法）→ ③ 配美图（产品图 + 效果/场景）。

## 工作流 Checklist

### Phase 0：选品与卖点（必做）

- [ ] 选品：高需求高频 / 平台热议 / 关联自身身份与人设（缺一易无信任）
- [ ] FABE 清单：F 独特之处 · A 更强满足需求 · B 现实+心理利益 · E 权威或真实经历
- [ ] 金线：全文只推 1 条主记忆点（钻石案例：多特点=全记不住）

### Phase 1：定体裁与四段骨架

**解决方案型**

- [ ] 标题 ≤25 字：点困惑或「不能忍的难题」
- [ ] 开头 ≈200 字：困难场景 / 看文好处 / 我的结果（**先不点名产品**）
- [ ] 正文 ≈1000 字：方法够细（外人能照做）+ 卖点贴在方法上
- [ ] 结尾 ≤200 字：成果（感官+他人评价）+ 要点 + 鼓励尝试

**横向对比型**

- [ ] 标题点品类/价位/人群/品牌词（小号靠搜索）
- [ ] 开头四选一：身份 / 深度用户 / 调研苦劳 / 观点+选购标准
- [ ] ≥3 款：按价格|卖点|人群分类；每款 FABE+适用谁；官方好物卡片（禁直贴外链）
- [ ] 结尾：重申谁适合哪款 + 欢迎提问

**经历分享型**

- [ ] 起：受众熟悉场景 + **感官**冲突（忌空形容词）
- [ ] 承：自救尝试 + **虚假成功**（华容道式打脸）
- [ ] 转：FABE 与困难咬合，由守转攻
- [ ] 合：痛点/痒点/爽点 × 主观/客观/侧面

**三分法（短种草）**

- [ ] 开头：使用结果 → 主体：卖点嵌经验 → 结尾：互动/购买引导

### Phase 2：更好看（形神）

- [ ] 配图：产品/场景/过程效果 三选二；约稿常 ≥5 张/千字级
- [ ] 布局：短段、独立成段、倒金字塔；人设四源（专业/生活/兴趣/性格）
- [ ] 开头可套六套路：设问、欲扬先抑、矛盾、经历、故事、数字（目标：好奇+信任+淡化硬广）
- [ ] 选题荒：搜索词/画像/热搜/研报（见 playbook）

### Phase 3：故事化叠加（可选）

- [ ] 讲给谁：用户画像错则故事再好无效（苹果 1984 vs 日牌匠心）
- [ ] 价值观：让读者**自己推出**，勿空喊口号；代言人/叙事须**言行一致**
- [ ] 黏性 SUCCESs：简单、意外、具体、可信、情感、故事（带货与品牌短文案通用）
- [ ] 说服（博士课）：**情感先行，逻辑后置**；品牌故事可用五种正面模式（斩妖/白手/追寻/归来/重生）—详 playbook
- [ ] 公共叙事（馒头课，动员/品牌向）：我的故事 → 我们的故事 → 眼下的故事（Now 须给希望与行动）

### Phase 4：合规终检（发稿前必过）

- [ ] 无拉踩诋毁 →「无分好坏，只谈适合」摆事实
- [ ] 无过度承诺（升学/疗效/挽回感情）；个人经历≠普遍疗效
- [ ] 平台：医疗类好物限制、未成年代言禁令、三俗/对立/歧视
- [ ] 广告法：禁「国家级/最高/最佳」等；用第一梯队/榜单事实等替代
- [ ] 敏感词：非药械宣称治疗、溶脂、杀菌消炎等（见 playbook 表）

## 与 AI 协作

- 人提供：真实使用、FABE、合规边界、目标读者
- AI 适合：多标题/开头变体、颗粒度步骤扩写、对比表草稿、合规「捉虫」
- AI 不宜终审：疗效宣称、竞品态度、绝对化用语、虚构测评数据

写长篇故事向带货时，并行 `ai-writing-workflow` + 本 skill Phase 3。

## 输出格式（默认）

交付时按模板标注段落：

```text
【标题】
【开头】
【正文】（小标题可选）
【结尾】
【FABE 主卖点】（创作备忘，可不入稿）
【配图清单】类型 + 用途
【合规自检】通过项 / 已改写项
```
