# 男女频短剧路径与拉片参考

本文档自包含：办事路径对照、男频满级号/女频闪婚霸总拉片模型、打脸三型在男女频上的落地、改稿路径核对。场级八桥段与悬念见 [beats-hooks-scenes.md](./beats-hooks-scenes.md)。

---

## 使用说明

1. **男女频是投放与幻想路径问题**，不是文笔高下；改稿体检第 1 条即检查办事路径是否跑偏。
2. 拉片课立场：**否定爽点 = 离开付费赛道**；任务是同爽点拍得更不尬，而非装清高。
3. 写打脸/打斗前先定频道路径；再打段子型与加码方式（见下文「打脸三型」）。

## 一、办事路径对照（高频易错）

| 维度 | 男频 | 女频 |
|------|------|------|
| **办事** | **自己动手**变强 / 报仇 / 打脸 | **借男人之手、借势**；获爱、护短、资源倾斜 |
| **典型壳** | 满级号下山、战王、复仇量化升级 | 闪婚霸总、掉马甲、善良因果、职场互斗 |
| **拉片抓手** | 复仇期待 + 赐福双轨；前 20 集拉期待 | 女主画像 × 善良因果 × **观众开天眼**信息差 |
| **雷区** | 只剩杀戮、无「造物主」赐福 | 女主天天亲自武力揍人（易跑偏男频） |

**本质**：能力多来自「从天而降」；差别在挂在自己身上还是身边男性身上。五大爽点可叠加，但**投放要分清男女路径**。

**改稿路径例**：
- 女频打脸闺蜜/婆家 → 常靠霸总或「离婚后三哥宠上天」式借势，非女主亲自下场打斗。
- 男频同类事 → 主角亲自打脸、量化升级。
- **跑偏**：女频写成女主天天揍人 → 必须改回借势/情感线。

## 二、男频拉片：《凡人修仙记》模型

### 2.1 产品与心态

- 定位：典型**满级号下山**（都市修仙壳；战王/上帝模型近亲）。
- 同构提醒：无双/腾龙/紫气东来等**壳不同、模型同构**。

### 2.2 制作约束 → 嘴炮与解说

不能全实拍 →：**新反派/新危机 + 嘴炮/发波 + 配角解说**烘托。

### 2.3 满级号标准板块

仙界震慑开场（心结任务）→ 回人间被害回忆（离婚扫地出门）→ 护家人拆迁打脸收小弟 → 复仇期待+神医 → 救权贵结识上层 → **宴会工厂连环打脸** → 对手迭代至宗门 → 鉴宝/炼丹/扮演上帝 → 终局选拔清算。

**模型升级**：
- 旧：见神杀神；现：**救一半杀一半** → 爽感含扮演造物主。
- 开场须**心结未解**才有下山任务。

### 2.4 节拍与充值

- 前 **10–20 集**：拉满复仇期待，服务充值点。
- **量化体系**：武力、丹药、宗门——游戏感。
- **打脸分层**：**收小弟代打**，不全亲自打。
- **宴会场景工厂**：一场景可拍多集。

### 2.5 男频心理模型

被岳家瞧不起扫地出门 → 自己其实最强 → 救家人治病 → 座上宾 → 打脸轻视者 → 培养更强女配气前妻 → 鉴宝炼丹收徒（**造物主快感**）。

满级号下山 = **上帝/造物主模型**，不要只写「打脸」。

### 2.6 六维创新作业

| 维 | 常见问题 | 改进 |
|----|----------|------|
| 下山目标 | 心结不紧迫 | 可拆步骤 |
| 权力体系 | 门派名多、强弱难感 | 借神话/传统层级 |
| 危机阶梯 | 炼丹赛掉台阶 | 技巧戏≤1–2 集；危机上升 |
| 上帝爽感 | 只有炼丹鉴宝 | 止旱、改命运、点化路人 |
| 现实感 | 修仙皮缺人情 | 势利亲戚、旧同学羞辱源 |
| 大结构 | 终点直线、收尾拉胯 | 中段升级/改变终局目标 |

### 2.7 打脸三型（男频落地）

**共同机制**：我知我牛 → 敌方摩擦加码 → 揭晓释放；宜 **兑现 + 一加一** 防百集同打法。

| 子型 | 男频用法 |
|------|----------|
| **装逼打脸** | 仇敌/前妻家嘲讽赘婿、战废物 → 主角明示不信 → 宴会/鉴宝/武力一层层加码打脸 |
| **扮猪吃虎** | 满级号装废柴、装穷、装病 → 故意受辱再揭身份；适合前 10 集蓄期待 |
| **上帝视角** | 众人议论「神秘龙王/战王是谁」→ 主角在旁或已入场不显；小弟代打后真相落主角 |

**男频加码**：武力等级对比、道具/丹药阶位、量化「他竟是天尊」；**小弟先手、主角终局一击**分担场次。

**开局铁律**：离婚扫地出门；**灭一半收一半**（赐福、提修为、收马仔，勿纯杀戮）。

**终局**：前妻等仇人可**不杀、废掉、活着羞辱**。

## 三、女频拉片：《闪婚老公是亿万富翁》模型

### 3.1 类型公式

> 随便嫁一人 → 他竟是真命天子 + 最有钱有才霸道 + 渊源深（一夜情）+ **马甲藏不住**。

### 3.2 铁律：观众开天眼

- 角色可有信息差；**观众自始至终全知**。
- 可敢用大量不合理巧合。
- **信息差 + 善良因果**是主工具。

### 3.3 分段节奏（约每 10 集一块）

| 集段 | 主玩法 | 充值警示 |
|------|--------|----------|
| 1–10 | 双线拒婚、闪婚信息差、掉马甲喜剧 | 吊马甲危机循环 |
| 11–20 | 职场线、姐姐对手、勤俭人设 | ~19 勿重复「装穷找车」 |
| 21–30 | 奶奶双盲饭局、职场撒糖 | 卡点勿重复奶奶戏 |
| 31–40 | 儿子身份、继母攻软肋 | 男主护短打脸 |
| 41–50 | 设计图争夺、下药陷害 | 下药全剧约 3 次上限 |
| 51–60 | 父子伺候、一夜情真相给观众 | 危机勿一问即解 |
| 61–70 | 医院戏易拖 | 总 Boss 宜提前做小 Boss |
| 71–80+ | 学历攻击、终局加码 | **最后十集**财产/岗位/信物/监狱嘲讽层层加码 |

### 3.4 女主画像六元件

学历偏低 · 婚前性经历及软肋 · 家庭不幸福/被逼婚 · **善良**（获爱因果）· 有才华 · 勤俭不爱钱。

画像准 → 爽点自动准：钱给我、事事向着我、全家喜欢我、旧过往化解。

### 3.5 常用桥段

掉马甲 · 职场内斗 · 信息差上帝视角 · 假婚真爱 · 多重巧合 · 善良因果。

### 3.6 打脸三型（女频落地）

前期克制：**糖、掉马、职场小斗、暧昧**。

| 子型 | 女频用法 |
|------|----------|
| **装逼打脸** | 婆媳/职场贱人嘲讽女主穷、脏、没学历 → **男主/奶奶/势力**当众揭资源、身份、法律后果；女主少亲自武力 |
| **扮猪吃虎** | 女主装穷装乖过奶奶关；男主装外卖员装穷（观众知、角色不知）→ 婚礼/饭局集中掉马 |
| **上帝视角** | 观众知男主是 billionaire；反派还在骂「穷小子」→ 爽在**信息差看热闹** |

**最后十集**可放开：扇耳光、下跪、制裁；在大团圆上继续加码。

加强：藏身份要高明；对手虐心递进；少重复偷听/迷药/同功能角色。

### 3.7 女频拉片自检（7 条）

1. 女主画像六元件是否对准下沉女用户？  
2. 观众是否全程全知？  
3. 前 20/30 集充值点是否重复旧梗？  
4. 对手阶梯上升？总 Boss 是否过晚过弱？  
5. 迷药/偷听/同功能是否重复？  
6. 最后十集是否在大团圆上继续加码？  
7. 是在否定霸总/善良，还是把它们拍得更高级？

## 四、改稿与路径核对

- 改稿 **20 法则**第 1 条：男频/女频办事路径。  
- 第 2 条：八桥段是否用开（打脸/碾压/运气/地位/集体/因果/极限/哲思）。  
- 选题层：女频写成女主天天开打 → 明确错误，改借势/情感线。
