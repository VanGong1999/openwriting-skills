# Comedy Writing（喜剧写作）

本 skill 自包含编剧孵化营「喜剧作为元素」与短剧课「喜剧类型设计元素」共识：**当代商业叙事里喜剧 rarely 纯类型片，而是必学元素**；笑是一级需求。核心与爽/虐相反——**观众与戏保持距离**，靠优越感笑，而非入戏共情。

**技法总表与短剧对照**：见 [references/playbook.md](references/playbook.md)

---

## 适用场景

- 非纯喜剧片/剧中**嵌入**喜剧元素（药神式沉重主线 + 笑点段落）
- 短剧/网文：主线爽虐，用**一个喜剧配角**或桥段调节（女频霸总小跟班、老妈等）
- 设计**误会、信息差、callback** 驱动的笑料
- 区分「台词讲笑话」（玩赖）vs **基于人设困境的落地台词**
- 宣发：剪出一段够笑的戏作卖点

## 不适用场景

- 以**付费冲榜为主线的纯喜剧短剧**（行业体感充值偏弱，偏免费流——可作副线）
- 代替悲剧/虐恋主情绪
- 冒犯弱势群体、审查红线 comedy → 先看 `compliance-content`
- 脱口秀专场结构（影视剧本仅吸收情境法）

## 认知底座（动笔前 30 秒）

| 维度 | 喜剧 | 爽/虐 |
|------|------|-------|
| 观众位置 | 戏外俯视 | 代入主角 |
| 核心情绪 | 优越感、「关我屁事」 | 共情、酸爽落泪 |
| 本质机制 | 广义嘲笑 + **安全冒犯** | 命运与身份认同 |
| 人物公式 | **最大行为 → 最小结果** | 过激行为争取结果（仍属戏剧） |

**能量平衡**：影视连续砸角色会内疚；需笑哭交替、因果与度。脱口秀可持续砸自己；剧作砸的是角色/类型，更要平衡。

## Agent 工作流

### Phase 0：定喜剧载体

- [ ] 本片/本剧主类型是什么？喜剧占比：**点缀段落 / 固定喜剧配角 / 结构困境型**
- [ ] 目标观众：能否接受冒犯（老年受众对脱口秀式冒犯耐受更低）
- [ ] 是否与审查冲突：警/军/宗教/同性宣扬等硬红线不能当笑料靶子

### Phase 1：三方向择一或组合

**方向 A：喜剧人物（优先）**

| 类型 | 机制 | 写法要点 |
|------|------|----------|
| 小人物 | 俯视（残缺/傻/low/没见识） | 直接但注意善意；本山式进城错位 |
| 典型人物 | 社会共识「该踩」 | 校长、势利丈母娘、烂队梗；**禁踩无共识职业**（如消防员） |
| 荒诞人物 | 行为阈值 > 戏剧人物 | 用大装置煮泡面；猫和老鼠式绕远路 |

- [ ] 主角不能动？→ 配典型人物 + 荒诞配角（盗墓配胖子类）
- [ ] 愚者主角？→ 再缩小、再 low 一点

**方向 B：喜剧结构 = 困境**

- [ ] **倒霉**：屋漏偏逢连夜雨（先让观众愿看他倒霉的人设）
- [ ] **反差困境**：人放进**应付不了的环境**（ thief 藏宝于警察局）
- [ ] **铁律**：困境要大，**无关生死**（约会裤子裂了笑；摔破头不笑）

**方向 C：黑色主题（少用）**

- 龙虾式「单身有罪」等荒诞设定；日常商业片**不主张**靠讽刺立国，人物/困境为主

### Phase 2：八种呈现形式（落地到场次）

在剧本中刻意造境，使人设/困境有机会爆发：

1. **倒霉** — 想耍帅必扑街链式升级  
2. **误会** — 角色错，观众对（门禁喊「我爱你」）  
3. **巧合** — 必然抽中梗/必然逢凶化吉  
4. **隐私暴露** — 开裆、走错澡堂（守度）  
5. **信息差** — **观众信息 > 角色**；穿越/重生天然优势；反则笑点废  
6. **反转** — 最差者获胜（如花）  
7. **重复 / callback** — 排比拒绝 + 子承父业抽搐  
8. **反差** — 女汉子 × 弱鸡男

**台词**：基于已设人物/困境落地，**禁止**角色坐下来专讲冰箱大象笑话。  
**动作**：出洋相、张冠李戴；选演员相性（同一爬坑沈腾>Dignified 型）。  
**短剧加成**：误会 + 信息差开挂（重生预知）+ 现世报 + 讽刺不正之风（收礼等）

### Phase 3：与短剧商业节奏

- [ ] 重充值短剧：**主爽点单一明确**；喜剧作调味勿杂糅成「吃席」  
- [ ] 可加**一个**喜剧人物提升可亲度，不代替主线  
- [ ] 肢体笑：案头设计 + **表演临场**留白  
- [ ] 冒犯类（智商、特殊群体）→ 合规自检

### Phase 4：场次自检

- [ ] 本场观众是否仍保持优越感？是否突然强共情毁笑  
- [ ] 信息差方向对吗（观众天眼）  
- [ ] 困境是否过生死线  
- [ ] 是否只有抖机灵、无人设困境  
- [ ] 连续笑点是否需插入释放/善意动作（穿外套助人）  
- [ ] 敏感靶子 → `compliance-content` 清单
