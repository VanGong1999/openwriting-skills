# 新媒体爆款写作

## 适用边界

- **适用**：观点文、情感文、盘点文、带货软文、知乎回答/专栏图文、可传播的故事片段。
- **不适用**：长篇连载小说、短剧分镜脚本；仅可借用「起承转合」做短篇叙事，勿展开剧本格式。

## 底层原则（先过这一关）

1. **传播本质是情绪**，不是文采；高手差在**套路数量**，不是练笔时长。
2. **用户思维**：`自我表达 × 用户需求` 的交集——不迎合空洞、不写纯日记、不自嗨。
3. **选题约八成成败**；热点是冲 10w+ 的捷径；爆款多来自**组合已验证元素**，不是凭空捏造。
4. **人性十大爆款元素**（选题与标题的燃料）：
   - 三大感情：爱情、友情、亲情
   - 五种情绪：愤怒、怀旧、暖心、愧疚、孤独
   - 两大因素：地域、群体

## 标准流水线

按顺序执行，缺一步则补一步：

```
选题 → 标题（1秒点开）→ 开头（三句留人）→ 结构 → 结尾（点赞转发）→ 金句/故事（传播发酵）
```

**万能公式（速记）**：用户思维 + 热点 × 十大元素 + 模板库 + 情绪。

## 工作流 A：从 0 写爆文

1. **选题**：定目标档位（见下「选题三阶梯」），标出用到的十大元素 ≥1 个；可选热点。
2. **标题**：敏感词 + 套模板 → 产出 10–15 个 → 自测（自己想不想点、和用户有无关系）→ 留 5 个 → 有渠道则小范围投票/看数据定稿。
3. **开头**：任选 1 种开头模板，**前三句**必须完成：抓注意力 + 与读者建立关系 + 让人愿意往下划。
4. **结构**：四选一骨架填内容；段落宜短，一事一例。
5. **爆点**：文中至少 1–2 处金句；需要说服力时加「定冲突」小故事。
6. **结尾**：四选一，贯彻峰终定律（读者记住的是峰值与终点）。
7. **终检**：删长标题、删多爆点标题；开头三句试读；结尾是否有互动钩子。

## 工作流 B：改稿 / 诊断

对已有文稿输出简短诊断表：

| 环节 | 问题信号 | 改法指向 |
|------|----------|----------|
| 选题 | 只有自己关心 | 叠十大元素或四切入点（利益/原因/盘点/观念） |
| 标题 | 像摘要、过长、多点 | 只留一个爆点；套 8 标题模板 |
| 开头 | 铺垫太长 | 换模板，压缩到三句 |
| 结构 | 散、效率低 | 对齐四种结构之一 |
| 结尾 | 戛然而止 | 关联读者或排比升华 |
| 传播 | 没金句、没画面 | 金句 7 模板 / 故事 4+3+2 |

## 选题三阶梯（速查）

| 档位 | 目标 | 手法 |
|------|------|------|
| 一 | 快速 10w+ | 改编、盘点梳理、复制高赞评论角度、争议点切口 |
| 二 | 稳 10w+ | **热点 + 十大元素** |
| 三 | 100w+ | 换角色叙事、硬组合（非常规配对）、小见大 |

选题搜集可参考：热搜/排行榜/社群；深度源：垂直社区、旧杂志人事故事、垂直问答社区等。

**知乎向补充**：价值三层——解决问题、增长见识、精神共鸣；读者 **痛/痒/爽**；切入点 **利益、原因、盘点、观念**（与结构模板可对照，见 playbook）。

## 模板索引（细节见 playbook）

- **标题**：两步（敏感词→套模板）+ 8 模板 + SOP 四步；误区：过长、信息堆砌、等同正文摘要。
- **开头**：8 模板；**三句留不住则全文废**。
- **结构**：4 模板（观点+事例 / 大观点+小观点 / 观点+角度 / 观点+人物故事）。
- **结尾**：4 模板（总结 / 关联读者 / 名言解构 / 排比）。
- **金句**：课程 7 模板（1221、1213、搜词、猜字、具象、否定、扩字）；写作营 7 武器（对比、排比、追问、重复、否定、拆字、化用）可交叉使用。
- **故事**：4 步（一句、冲突、理由、组合）+ 3 步（背景、信息、情绪爆点）+ 2 招（乱序、场景演绎）；**冲突是灵魂**。
- **效率套路（图文）**：二选一、价值+方法、商城盘点、起承转合——按选题类型选用（见 playbook）。

## 对读者的价值清单（写前自问）

- 解决了什么具体问题？还是帮人「多见世面」？还是身份/困境/价值观共鸣？
- 与读者 **利益** 是否在第一屏可见？
- 垂直领域是否一致（利于推荐与信任）？

## 输出规范（代理撰写时）

1. 先给 **选题说明**（档位 + 元素 + 切入点）。
2. 给 **3–5 个标题**（注明所用模板）。
3. 给 **开头三句**（注明模板）。
4. 给 **结构大纲**（一级小标题即可）。
5. 给 **2 条备选金句** + **结尾 1 版**。
6. 全文语气：口语可读、短句、强情绪点；避免说教式长篇说理。
