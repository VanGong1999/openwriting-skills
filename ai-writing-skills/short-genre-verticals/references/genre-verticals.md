## 一、科幻

### 1.1 读者要什么

审美震撼来自：**好奇心、恐惧（似人非人/恐怖谷）、怀旧（历史科幻）**。母题含未知、第一次接触、家园、征服。思想实验（自由意志、观察者）是把科学谜题推到极端。

### 1.2 创作路径

| 步骤 | 内容 |
|------|------|
| 凝结核 | 念头 / 画面 / 情绪，任一定锚 |
| 储存知识 | 超链接式跳读，边缘知识垫真 |
| 构思 | 编到自己「很嗨」；历史科幻 = 真史事+人物+战场+有技术基础的虚构设定；技术惊险 = 生物学根源+玄扯但像真的来源+古今对照 |
| 朋克训练 | 把某技术/材料类别**极化**到自洽 |
| 知识观 | 「假装什么都懂」——细节举重若轻；不必纠结是否科幻作家身份 |
| 完稿 | 短篇尽量一个月内；完稿少无休止否定自我 |

### 1.3 感性科幻（双线合一）

| 误区 | 表现 |
|------|------|
| 纯硬核 | 长篇实验过程，外行脱节 |
| 科幻皮恋爱 | 背景可替换，无科技核 |

**故事盒（动笔前）**

- 科技盒：解什么科学/技术问题？创新方案？  
- 人物盒：情感困扰？关键转变动因？

**合一标准**：情感高潮 **导致** 技术问题被解决（例：父女和解 = 传参解方程救人）。

**科技写作**：行动跟着行动；技术仅在推动下一行动时**最简**插入。忌实验室参观长论。

**边界**：科幻 = 自洽 + 可沿当下科学外推；无解释的复活 = 奇幻。好故事优先于标签。

**训练**：科普 + 经典文学（强化人物）；十年式持续练；人物「住进心里」再写对话；**口是心非**两层（有意识/无意识）。

**反例**：以「人类」整体为主角的技术攻防战，缺代入。

## 二、历史 / 通史故事

### 2.1 五点小思考

1. **有底子**：人性矛盾、彷徨；真实原型事半功倍；一帆风顺弃写（例：海南岛战役势如破竹难成戏）  
2. **懂尊重**：别当读者傻；伏笔 1 秒可记；海明威动词  
3. **能克制**：苏联女兵初吻→安葬转折；不堆「供他」  
4. **会取舍**：马伯庸/张宗昌/山本五十六类——查证进不了正文就删  
5. **守底线**：打油诗非张宗昌所作仍要捅破；蒋介石之死典故须尊重考证  

### 2.2 结构与母题

- 三段位：流水账 → 亮点 → **埋钩子**  
- 母题：**复仇、寻宝**（可裹爱情）  
- 排版：2–4 行一段；数字小标题；段末钩  
- 叙事与人物不割裂；史书激荡年代多故事（近代、春秋等）  

### 2.3 新常态

无后台也有效分发；**Just do it**：先列人物/框架再写，脑中无稿。

## 三、悬疑 / 推理

### 3.1 类型观

本质 **设谜与解谜**；本格 = 证据够则必有解；本格反义常指 **社会派**。谱系宽：本格、社会派、新本格、叙述诡计、日常推理、硬汉派等。欧美黄金时代 + 日本本格为技法根。

### 3.2 配方与尺度

**99% 理性 + 1% 变态**。变态须在理性叙述中隐匿；立身谨重，文章可放荡。短篇（尤其知乎）万字内须让 1% 醒目，但勿只剩歇斯底里。

**放大**：善到极致、寂寞到极致；巴黎圣母院式极端配对。

### 3.3 三条路

1. 中国古典语境 + 本格硬技巧  
2. 社会派：坏人、制度、紫金陈式人像  
3. 主角**弱点**即魅力（比例配合 99%+1%）

### 3.4 技术概要

**密室**：上锁 / 看守 / 环境隔绝；解 = 机械 **或** 时间心理密室；禁地道烟囱。**谜底简单但揭晓前不能猜到**。

**诡计**：可能性犯罪、换药等；读《三口棺材》《诡计集成》；每读一本记一种——撞车靠文学与叙述拉距。

**叙述诡计**：多视角第一人称 + 漏写关键段；信息不对称；《情书》式藏初恋比平叙强百倍。

**坏人研究**：推卸责任 vs 让人爱上他的坏；神代式骗保；《绝叫》式逆袭。

**硬汉派**：烂仔英雄，缺点近观众，虚幻正义感驱动。

**心态**：被骂多或为火；抗骂训练。

**中国场**：本格弱于美日；恐怖、谍战强；用古典 + 社会派可差异化。

## 四、女性情感短篇

### 4.1 构思三事

1. **想读者**：七问筛素材；自我表达须与受众平衡  
2. **想范围**：名场面思维；一篇一种情绪  
3. **想视角**：彩礼双语境；第一人称亲但有互动，防轶事体  

### 4.2 题材与立场

- 诉求变迁：维持婚姻 → **选择权**  
- 切入点：普通外壳下集中痛；真实·提炼·糅合  
- 主题三角：自我认知 / 价值实现 / 人与环境  
- 反工具人：撕「美丽废物」标签；《我的姐姐》式牺牲重量  
- 困境：内化规训 vs 环境规训  

### 4.3 笔法

《鄙视》式：细节、欲言又止、心理层次；管状/散状视野差异可写进女性细节。

**脱离立场**：像看孩子般见优缺点；琼瑶紫菱/绿萍；曹建军 vs 扁平丈母娘。

### 4.4 沉浸三件套

常见场景爆发；深层人设非表面身份；情绪烈度略高于常人但贴合走向（《坡道上的家》）。

## 五、真实感 + 现实悬疑（点灯 + Nancy）

### 5.1 真实感双源

**逻辑**（事理 / 情理 / 文化）+ **情感**（够强则「不合理」也可成立）。

- 事理：因果链步步扣；脑洞设定内推演，无用情节删  
- 情理：无无缘爱恨；文化：古代多妻 vs 都市、傻白甜霸总过时  
- 间接经验 + 八角色视角检视  
- 共情：现实细节锚定；非脸谱；人之常情  

### 5.2 悬疑六误

1. 猎奇血腥主菜 → 人性社会细节  
2. 无内核 → 先表达欲  
3. 都知道的案情 → **换视角**  
4. 手法不会 → 裁判文书；三等有病<证据<人性  
5. 讲不好 → 第一人称选旁观者 + 跟进动机；切入点 = 第一次碰撞  
6. 反转堆砌 → **两个**：猜得+猜不得  

### 5.3 加分

情绪发泄点「可爱」角色；悬疑句瘦身留空白。

## 六、萌 · 燃 · 设定论

- **萌要素**：公共性 + 自动化（行为指令库）；可 AU  
- **人设** = 萌要素 + 人物逻辑；反差萌  
- **世界设定**独立审美（彩蛋游戏、无限流解规则）  
- **两原则**：连贯 + **典型性**（自创典型场景）  
- **案例心法**：道诡异仙（不可知恐惧内核）、来自深渊（诅咒制造探索/生活两难）、穿越推至可能性反面
