# 新媒体爆款写作 Playbook

> 本文件为自包含模板与 SOP 手册。代理需要展开细节时阅读本文件即可。

---

## 1. 人性十大爆款元素（选题/标题必查表）

| 类别 | 元素 | 常见叙事钩子 |
|------|------|----------------|
| 感情 | 爱情 | 分手、备胎、异地恋、择偶标准 |
| 感情 | 友情 | 绝交、借钱、背叛、渐行渐远 |
| 感情 | 亲情 | 父母、育儿、隔代、愧疚 |
| 情绪 | 愤怒 | 不公、维权、阶层、职场 |
| 情绪 | 怀旧 | 童年、老物件、旧时代 |
| 情绪 | 暖心 | 陌生人善意、小确幸 |
| 情绪 | 愧疚 | 来不及、子欲养而亲不待 |
| 情绪 | 孤独 | 单身、北漂、社恐 |
| 因素 | 地域 | 南北、小城/一线、乡土 |
| 因素 | 群体 | 90后、宝妈、打工人、体制内 |

**稳上 10w+ 公式**：`热点（可选）+ 上表 ≥1 项 + 明确读者人群`。

## 2. 选题三阶梯 + 搜集

### 2.1 三阶梯

| 阶梯 | 方法 |
|------|------|
| 快速 10w+ | ①改编爆款 ②盘点梳理 ③高赞评论视角 ④争议点角度 |
| 稳 10w+ | 热点 + 十大元素 |
| 100w+ | 换角色（他者视角）、硬组合（跨圈层配对）、小切口见大主题 |

### 2.2 八种搜集（迷蒙课）

- 常规：微博热搜、新榜排行、新媒体人社群、抖音热点。
- 补充：先知类资讯、垂直社区、旧杂志（人事、情感故事库）。

### 2.3 读者价值与切入点（知乎写作营）

**价值三层**

1. **解决问题**：步骤、方法、可操作建议。
2. **增长见识**：信息差、整合、降维输出（你的常识可能是别人的新大陆）。
3. **精神共鸣**：共同身份 + 共同困境 + 共同价值观。

**痛 / 痒 / 爽**

| 类型 | 含义 |
|------|------|
| 痛点 | 紧迫难题，需立刻缓解 |
| 爽点 | 非紧迫但见效明显 |
| 痒点 | 长期憧憬、理想生活 |

**四切入点**（可映射结构模板）

| 切入点 | 适合的创作模板 |
|--------|----------------|
| 利益 | 价值 + 方法 |
| 原因 / 观念 | 二选一 |
| 盘点 | 商城类 |
| 故事 | 起承转合 + 观点结构中的事例 |

## 3. 标题：两步法 + 八模板 + SOP

### 3.1 三大误区

- 过长（移动端展示不全）
- 多个信息点（应 **只聚焦一个爆点**）
- 写成正文摘要（失去悬念）

### 3.2 两步法

1. **找敏感词**：微信指数、对标大号标题高频词、目标人群嘴里的词。
2. **套模板**：从下表选 1 个主模板，可叠加数字或热词。

### 3.3 八标题模板

| # | 名称 | 句式要点 | 示例骨架 |
|---|------|----------|----------|
| 1 | 数字法 | 具体数字增强可信度 | 「3个…」「90%的人…」 |
| 2 | 对比法 | 一边…一边… | 反差身份、反差境遇 |
| 3 | 热词法 | 嵌当下热词 | 热点事件+态度 |
| 4 | 疑问法 | 反常识问句 | 「为什么越…越…？」 |
| 5 | 对话法 | 引号内一句刺话 | 「你说…我说…」 |
| 6 | 好奇法 | 关键信息留白 | 主语+反常结果，不解释尽 |
| 7 | 俗语法 | 顺口溜、押韵 | 短、好念、可传播 |
| 8 | 电影台词法 | 化用经典句 | 换词保留节奏 |

### 3.4 标题生产 SOP（四步）

1. 套模板 brainstorm **10–15** 个。
2. **自测**：自己想不想点？与目标用户有无关系？
3. 筛 **5** 个；有粉丝群/同事群则投票。
4. 发布后看打开率/分享率，沉淀进标题库（表格法、对标大号、畅销书目录）。

### 3.5 标题测试自问

- 是否 **1 秒内** 让人想点开？
- 是否 **一个爆点**？
- 情绪是否来自十大元素之一？

## 4. 开头：八模板与「三句法则」

**规则**：前三句必须完成 **吸睛 → 关联读者 → 推进阅读**。任一句拖沓则换模板。

| # | 模板 | 用法 |
|---|------|------|
| 1 | 问句式 | 连续/单问，戳痛点或反常识 |
| 2 | 对话式 | 场景对话，即时冲突 |
| 3 | 互动式 | 「你是不是也…」「请在心里选 A/B」 |
| 4 | 自我表达式 | 第一人称强烈态度（非流水账） |
| 5 | 题文呼应式 | 延伸标题悬念，不重复标题 |
| 6 | 名人名言式 | 引用后 **解构/反转**，非装饰 |
| 7 | 热点式 | 24–72 小时内热点 + 个人角度 |
| 8 | 粉丝投稿式 | 「昨天读者私信说…」制造真实感 |

## 5. 正文结构：四模板

| # | 结构 | 适用 |
|---|------|------|
| 1 | 观点 + N 事例 | 情感文、观点文 |
| 2 | 大观点 + N 小观点 | 清单、分点论述 |
| 3 | 观点 + N 角度 | 同一命题多侧面 |
| 4 | 观点 + 人物 N 故事 | 人物串联、群像 |

**写作节奏**：短段；一例一情；事例服务于段首观点句。

---

## 6. 结尾：四模板（峰终定律）

读者对体验的记忆 ≈ **高峰情绪 + 结束时刻**。结尾是离 **点赞、评论、转发** 最近的一屏。

| # | 模板 | 要点 |
|---|------|------|
| 1 | 总结型 | 回扣标题/观点，一句话钉死态度 |
| 2 | 关联读者型 | 「愿你…」「如果你也…」 |
| 3 | 名人名言式 | 再解构或推到读者身上 |
| 4 | 排比型 | 短句排比，情绪推到最高 |

## 7. 金句

### 7.1 迷蒙课七模板

| 模板 | 核心操作 |
|------|----------|
| 1221 | 两词位置对调 + 前后反差 |
| 1213 | 中间共同词 + 尾词相反或递进 |
| 搜词法 | 核心词查同音/近形词组合 |
| 猜字法 | 拆字赋义 |
| 具象法 | 抽象概念 → 可视画面 |
| 否定法 | 否定常识（半句或全句） |
| 扩字法 | 在句中插入字词改变指向 |

### 7.2 写作营七武器（可并用）

| 武器 | 结构 |
|------|------|
| 对比 | 上句观点，下句相反 |
| 排比 | 相似句式并列 |
| 追问 | 连续反问/设问 |
| 重复 | 上下句重复关键词 |
| 否定 | 不是…而是… |
| 拆字 | 拆词讲本质 |
| 化用 | 经典句换词保留骨相 |

**句法底线**：主谓宾齐全则通顺；加定状补则丰满（书面化、少口语碎语）。

## 8. 故事：4 + 3 + 2

### 8.1 四步（骨架）

1. **一句话**故事核。
2. **定冲突**（灵魂）：谁 vs 谁 / 想要什么 vs 阻碍什么。
3. **给理由**：动机可信。
4. **来组合**：嵌入结构中的事例段。

### 8.2 三步（丰满）

1. 交代背景（极简）。
2. 补充关键信息。
3. **情绪爆点**（愧疚、愤怒、暖心等对齐十大元素）。

### 8.3 两招（传播）

1. **打乱顺序**：倒叙、插叙，先给结果再揭因。
2. **场景演绎**：动词、细节、对话，可口述成画面。

## 9. 创作效率：四套路模板（知乎课）

| 模板 | 结构 |
|------|------|
| **二选一** | 开头 A/B 设问 → 正文论据（数据、案例、经历）→ 结尾重申并邀评 |
| **价值+方法** | 点价值（省时间/省钱/健康/愉悦）→ 步骤+原理 → 鼓励行动 |
| **商城盘点** | 标题宣告盘点 → 开头立资格 → 每项 100–300 字卖点（可提缺点）→ 结尾主推 |
| **起承转合** | 起=危机；承=应对与人格；转=关键行动；合=结果（短篇叙事用，非剧本） |

## 10. 质量终检清单

- [ ] 选题：十大元素 ≥1；读者利益或共鸣可见
- [ ] 标题：单爆点；8 模板之一；长度适配手机
- [ ] 开头：三句测试通过
- [ ] 结构：4 模板之一；无跑题段落
- [ ] 文中：≥1 金句；故事有冲突
- [ ] 结尾：峰终情绪 + 互动钩子
- [ ] 全文：情绪线清晰，非长篇小说式铺垫

---

## 11. 十条法则（速背）

1. 选题决定八成。
2. 热点是冲量捷径。
3. 爆款是组合出来的。
4. 标题只为 1 秒打开。
5. 开头三句定生死。
6. 结尾承点赞转发。
7. 冲突是故事灵魂。
8. 传播靠情绪。
9. 标题少即是多。
10. 底层：自我表达 × 用户需求。
