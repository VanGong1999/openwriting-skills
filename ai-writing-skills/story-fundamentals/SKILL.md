# Story Fundamentals（故事通用底座）

本 skill 提炼自查理「十五步写一个好故事」、编剧孵化营、北大博士 LOCK 心法，以及馒头商学院「公共叙事」中与**虚构叙事结构**相通的部分。立场一致：**从观众侧思考**——对抗、变化、共情是尺子；结构先于辞藻。

**深化公式与模板**：见 [references/playbook.md](references/playbook.md)。

---

## 适用场景

- 新故事从 0 到 1：一句话故事、核心创意、人物关系、大纲/节拍表
- 已有草稿「不好看」：按三标准与 15 步做结构体检
- 影视向梗概、提案、拉片前的框架对齐（孵化营口径）
- 需要把「意外 + 困境 + 目标进化」写清楚（LOCK / 博士课）
- 品牌、演讲、动员类内容里，需要**故事骨架**（非全文营销话术）时，可借用公共叙事三段论结构

## 不适用场景

- **短剧分集卡点、付费点、平台规则**：有专属短剧 skill，本 skill 只提供通用结构层
- **网文连载节奏、品类套路、日更产能**：有专属网文 skill
- 纯文学实验、作者电影自我表达优先（孵化营：先让观众认可，再谈作者性）
- 只要哈佛课的运营选题/传播/润色全流程（本 skill 仅吸收「公共叙事三段论」要点）
- 法律咨询、史实考据、科学论证——故事 skill 不替代事实核查

## 先判体裁，再应用

| 判断 | 接着做什么 |
|------|------------|
| 时长/载体：短片、院线、剧集、小说章节 | 选对应节拍密度（孵化营四幕节拍 vs 博士 15 节拍 vs 十五步阶段） |
| 类型片倾向 | 用孵化营「类型片共情点」校准，但不替代本 skill 的 15 步检查 |
| To B 定制 / 分账 | 孵化营：**市场是 To B**（完播率、拉新率、分账等为**经验口径**）；结构上仍用对抗+变化+共情 |
| 现实题材 vs 幻想 | 幻想更需要「环境+规则」；现实更需要「困境+体制」与目标递进 |
| 公共动员 / 品牌叙事 | 叠加 playbook 中的「公共叙事三段论」；英雄之路作人物弧线参考 |

**原则**：本 skill = **通用结构层**；行业玩法（短剧、网文变现路径等）在各自 skill 中叠加，不在这里展开。

## 工作流 Checklist

按顺序执行；可停在任意步产出中间物。

### Phase 0：尺子（30 秒）

- [ ] 能否用一句话说清：**谁在什么处境下仍要完成什么目标**？（孵化营一句话故事）
- [ ] 预判观众：对抗够不够、有没有持续**变化**、有没有**共情**入口（可怜/可信/可爱）
- [ ] 选题法则：**写什么比怎么写更重要**（孵化营总纲）

### Phase 1：种子（核心创意）

- [ ] CTFDP 五类中至少命中一类，商业向最好**复合两类**（如 F+D、C+T）
- [ ] 对照 playbook：C 弱者/强者/组合，T 诱人或要命，F 愿望/担忧/比喻，D 四类困境，P 悬念悬置
- [ ] 一句话验证：讲给几人听，是否产生「想知道后来如何」

### Phase 2：舞台与人（十五步 1–7）

- [ ] **环境与规则**：锁环境、定规则；忌双重设定、强设定过度、设定上过分创新
- [ ] **锁定主角**：有主动力、既特别又共情、底线忠诚、可拆分、**必须有缺陷**
- [ ] **激励事件**：戳破龟壳；主角常拒绝，二三次才上路
- [ ] **外部目标**：主动、可共情；**可能是错的**
- [ ] **骑士对手**：与目标利益对冲，**未必坏人**
- [ ] **配角**：伙伴/导师/爱情（+对手）；其余工具人；身份可转换

### Phase 3：引擎（十五步 8 +  LOCK 加压）

- [ ] **主力对抗**：环境 → 对手 → 自身，由小到大，贯穿全片
- [ ] **虐主自检**（博士课）：三角邪恶选择、怨憎会（反派捆绑）、怕什么来什么
- [ ] **撩观众**：认知差异保留节奏；先立预期再偏离；结论让观众自己得出
- [ ] AB 线（孵化营）：A=Want 事件线，B=Need 成长线，两条都重要

### Phase 4：转折与高潮（十五步 9–14 + 节拍）

- [ ] **故事拐点**：中间点，虚假胜利/失败；之后忌慢节奏
- [ ] **调整目标**：改/调/放大 → 最终目标，关乎缺陷与主题
- [ ] **确认对手**：实力相当、不低智商、有步骤；换人需伏笔
- [ ] **遭受重创**：至暗时刻、死亡气息
- [ ] **解决方案**：武力/智力/解读起始道具/大道至简；忌对手突然失智
- [ ] **最终决战**：主角亲自动手；时间锁则**最后一秒爆炸**；可再来一次意外
- [ ] 对照四幕节拍表是否缺：争执、B 故事、游戏中点、灵魂黑夜、解决悖论（见 playbook）

### Phase 5：收束（十五步 15）

- [ ] **回到原点**：呼应最初、实现主题、归来已不是少年
- [ ] 缺陷弧线闭环：激励→拐点→调整目标→决战，缺陷是否被触及或克服
- [ ] 15 步之后若写剧本：还需强化人设、增大对抗、视觉化情节、悬念与包袱（知识体系边界）

### Phase 6（可选）：公共叙事包装

- [ ] 动员场景：我的故事 → 我们的故事 → 眼下的故事（各答一问，见 playbook）
- [ ] 情绪是否足以推动行动（哈佛课：价值观需情绪中介）——**非虚构商务场景**专用，与虚构长片不必强行合一

## 输出模板

复制以下结构填写；根据任务删减小节。

```markdown
## 体裁与观众
- 载体/时长/类型：
- 主共情点（可怜/可信/可爱 + 类型片参考）：

## 一句话故事
一个「什么人」在「什么情况」下，仍然要「完成什么目标」。
- CTFDP（单选/复合）：
- 核心意外（博士：稳定被打破）：

## 环境与规则
- 大环境 / 小环境（肥皂泡）：
- 规则与禁忌：

## 人物
- 主角：缺陷 / 境遇 / 主动力 / 共情点
- 骑士对手 → 最终对手（进化）：
- 配角（伙伴/导师/爱情）：
- A 线 Want / B 线 Need：

## 目标链
- 外部目标（可能错误）：
- 拐点后调整目标（最终目标）：
- 案例参照：赚钱→不赚钱→赔钱（层次递进）

## 对抗与虐主
- 环境 / 对手 / 自身 三层：
- 三角冲突（价值/反面选项/代价）：
- 悬念层级（参与/未知/可能/压迫）：

## 结构节拍（勾选项）
- [ ] 激励事件  [ ] 争执  [ ] 故事中点（伪胜/伪败）
- [ ] 灵魂黑夜  [ ] 解决悖论  [ ] 决战  [ ] 结束画面呼应

## 结局
- 解决方案类型（武/智/起始道具/大道至简）：
- 回到原点与主题：

## 风险与下一步
- 15 步不能替代：视觉场面、台词、分场密度
- 待强化：
```

## 常见坑

### 结构与创意

| 坑 | 正解（课程口径） |
|----|------------------|
| 追「从没写过」的故事 | 99.9% 重复前人，换**元素**与复合 CTFDP（孵化营） |
| 双重设定、设定堆砌 | 第二步：锁环境+定规则，忌强设定过度 |
| 外部目标=最终主题 | 第五步目标可错，第十步才升华 |
| 对手=坏人 | 利益对冲；镜像主角另一面 |
| 拐点后拖沓 | 虚假胜/败后无慢节奏 |
| 反派降智赢 | 第十三步忌对手突然失智 |
| 剧本失败怪台词 | 博士课：**90% 是结构问题**（经验口径） |

### 人物与情绪

| 坑 | 正解 |
|----|------|
| 主角无缺缺陷 | 第三步必须有缺陷，且贯穿隐形主线 |
| 死亡崇拜、苍白苦难当主流 | 孵化营：亚文化，撑不起主流影视 |
| 急着揭示真相 | 撩观众：认知差异勿过早消除 |
| 只有道理没有戏 | 人物=动作集合；拿事儿说话，忌旁白推进（影视硬性要求） |

### 体裁误用

| 坑 | 正解 |
|----|------|
| 用公共叙事三段论写商业片分场 | 三段论用于动员/信任；长片用十五步+四幕节拍 |
| 把变现路径当结构标准 | 变现课表格是**经验口径**；结构仍用意外+节拍+场景冲突 |
| 短剧卡点当 Universal | 通用层不写平台规则；另开短剧 skill |

### 老师反复强调的一句话

> 对抗 + 变化 = 吸引；共情 = 留住。从观众侧出发，用 CTFDP 找种子，用 15 步搭框架——立住「源代码」，再往下写剧本。
