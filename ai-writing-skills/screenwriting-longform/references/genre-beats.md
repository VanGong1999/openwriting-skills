# 类型片与节拍细节

> 本包自包含：四幕节拍表、类型片十类、商业悬念与 28 条套路。与 [playbook.md](playbook.md)、[scene-dialogue-craft.md](scene-dialogue-craft.md) 配套使用。不讲短剧 20 节拍与充值逻辑。

---

## 使用说明

1. **学习时用分类，创作时关注个体**——类型是选择题工具，不是枷锁。
2. 一个故事可有**多个共情点**（如《泰坦尼克号》= 伙伴之情 + 鬼屋；《杀人回忆》= 侦探 + 伙伴之情）。
3. 商业片**信息节拍**约 **35–45** 个；与四幕节拍表「填空」配合（分场四步法见 [scene-dialogue-craft.md](scene-dialogue-craft.md)）。

---

## 一、结构：三幕 → 四幕

| 框架 | 内容 | 比例直觉 |
|------|------|----------|
| 三幕 | 建制 — 对抗 — 解决 | 约 1:2:1 |
| 四幕 | **建制 — 推进 — 转折 — 解决** | 对应起承转合 |

**剧本硬性要求：** 可视听化 · 按放映顺序 · 禁旁白独白大段闪回 · **拿事儿说话**（不描述、不概括，写看得见的事）。

**心理学逻辑（贯穿全片）：** 认知层（第一幕灌信息）→ 恍惚状态（游戏时光卸力）→ 情感层（第二幕）→ 激素层（第三幕战斗）。

---

## 二、四幕式节拍表（完整填空工具）

> 规定每一幕里必须发生哪些事；每一幕都当成**有头有尾的小故事**。100 分钟片，第一幕约 25 分钟；**主题**最好在第一幕前半段点出（有的教材要求五分钟内）。

### 第一幕·建制（提出问题，带观众进入世界）

| 节拍 | 写法要点 |
|------|----------|
| **开场画面** | 总体环境的一张画面；**第四幕结束画面要呼应它**（视而不同） |
| **世界** | 规则、人、现状；世界对主角的不友好用**事件**表达，勿说明（例：种族歧视世界 → 主角上来就挨揍） |
| **人物** | 技能（让他**搬点什么**，技巧：**救猫咪**——展示技能又讨喜）；缺失（龟壳）；现状/舒适区；龟壳（小环境与大环境的调和）；人物关系（后面要变） |
| **与我有关** | 引发共情，让观众信这个世界 |
| **激励事件** | 第一幕核心；别名：第一次意外、干扰/激励事件；大激励（爹死、船炸）或小激励（卖药挣钱）；本质是**意外**，激发走出舒适区 |
| **争执** | 拒绝召唤，至少**一个回合拉锯** |
| **目标/欲望** | 激励前已有，或激励后才产生 |
| **主题** | 必须有人用**台词**点出；含蓄不行；第一幕、最好前半段 |

**第一幕结尾状态：** 主角决定上路。

---

### 第二幕·推进（上路，认知→情感）

| 节拍 | 写法要点 |
|------|----------|
| **仪式感开场** | 对应第一幕开场；征途意象（武士骑马进夕阳） |
| **具体行动** | 怀揣目标动起来 |
| **伙伴** | 导师 / 爱情 / 友情；刺激成长，**B 故事**开端 |
| **关键道具** | 第二幕出现（桃乐丝红鞋、绿皮书幸运石）；**第四幕重新解读** |
| **游戏时光** | 快乐、卸力：第一幕认知疲劳后，切换到情感层；轻快内容+BGM+剪辑；符合观众想象（躲雨、抓蚂蚱）；别名：**拍海报的画面**；目标：让观众进入恍惚状态 |
| **训练/试炼** | 不能一直爽，气氛渐紧 |
| **接近目标 + 对抗升级** | 越接近，对抗越强 |
| **故事中点** | 第二幕结尾；**伪胜利**或**伪失败**（院线/一小时剧语境约 **55 分钟**） |

**第二幕结尾：** 伪胜 → 第三幕发现胜利是假的；伪败 → 第三幕发现还能调整。

---

### 第三幕·转折（搞错了，再来）

| 节拍 | 写法要点 |
|------|----------|
| **否决中点** | 上来第一件事：「虚的、伪的、搞错了，再来」 |
| **再来方式** | 调整方向 / 方法 / 对手；认清现实与真相 |
| **对抗升级** | 主角高歌猛进；对手养肥、逼近 |
| **大意外** | 二号意外 PLUS（第一幕是一号小意外） |
| **灵魂黑夜** | 主角失败；一无所有时刻；可伴随死亡气息（死人或广义死亡） |

---

### 第四幕·解决（蜕变与决战）

| 节拍 | 写法要点 |
|------|----------|
| **仪式感开场** | 全片第二个仪式感（第二幕已有一个） |
| **疗伤 + 大成长** | 舔伤、纠错；**蜕变/母胎重生**（成长 PLUS） |
| **解决悖论** | 凭什么这次能赢？三法见下表 |
| **决战** | 主角**亲手**解决；「对手/决战」灵活理解（比赛亦是决战） |
| **目标达成** | — |
| **结束画面** | 呼应开场；商业片常「视而不同」——回到原点，人已不是少年 |

**解决悖论三法：**

| 方法 | 含义 | 举例 |
|------|------|------|
| 重新解读道具 | 第二幕给了没看懂，现成新方法 | 《加勒比海盗》特纳金牌 |
| 孤注一掷 | 此前没豁出去，现在赌一把 | — |
| 自我牺牲 | 打不过则付代价 | 牺牲自己成全目标 |

**金牌道具闭环：** 开场埋下（如特纳脖上金牌）→ 第二幕自然存在 → 第四幕重新解读成解局关键。

---

### 四幕总览对照表

| 幕 | 关键节拍 | 核心动作 | 结尾状态 |
|----|----------|----------|----------|
| 建制 | 开场、世界、人物、激励、争执、目标、主题 | 提问、带入世界 | 决定上路 |
| 推进 | 仪式感、伙伴、道具、B 故事、游戏时光、试炼、接近目标 | 上路、成长、卸力 | 伪胜/伪败（故事中点） |
| 转折 | 否决中点、调整、真相、升级、大意外 | 搞错、再来 | 灵魂黑夜 |
| 解决 | 仪式感、疗伤、蜕变、悖论、决战 | 亲手解决 | 视而不同 |

### 节拍表使用姿势

1. **填空题练习**：严格按顺序元素写「人生前十故事」，先别跳出圈。
2. **灵活理解**：决战可以是比赛；游戏时光可以是「符合观众预期」的内容（不一定欢快）。
3. **建制埋因、转折爆果**：第一幕缺陷须在灵魂黑夜爆炸（例：《摇滚校园》假身份穿帮）。
4. **伪胜利三种处理**（例：找女儿）：被识破锁起来 / 女儿已死转报仇 / 女儿不走（斯德哥尔摩）→ 在对手身上见自己影子。

**案例速记：**

- **《加勒比海盗》**：龟壳=怕水的铁匠房；激励=伊丽莎白被抓；故事中点=找到她（伪胜）；大意外=杰克中枪；金牌重释解咒。
- **《摇滚校园》**：激励=摇滚歌手去当老师；灵魂黑夜=冒充穿帮；开场舞台=结束舞台。
- **《印度妈妈找女儿》**：主题台词=女性自强自爱；绕过动作实现欲望（救己女失败、救他人女成功）。

## 三、类型片：分类思维

**类型片 = 分类，本质是简化思维（高级认知），但有局限：**

1. 不可能绝对精准；一刀切必有灰色地带。
2. **学习用分类，创作看个体**——你手里只有一个作品。
3. 电影类型由**观众期待** + **制作方迎合**双向形成。
4. 学创作用**创作者侧**十个方向反推观众需求；施奈德十类型 = 以**主共情点**分类。
5. 东西方差异勿照搬（西部片 → 闯关东；个人英雄主义 vs 集体力量）。
6. 不要把分类用在活生生的人身上。

**创作者侧十个方向（四组）：** 困兽、出水之鱼、壮举、人物关系｜激励、环境、规则｜对手｜收益（目标）、解密。

**主共情点：** 技能、困境、关系、壮举、环境等可同时存在，但观众主要着力一点 = 主共情点。

## 四、类型片十类（纲领全文）

十个类型（顺序无冷热）：**金羊毛、伙伴之情、超级英雄、鬼屋、侦探、如愿以偿、麻烦家伙、变迁仪式、愚者成功、被制度化。**

### 金羊毛（Golden Fleece）

**定义：** 主角与小伙伴找「宝物」，常拿不到字面宝物，却得更重要的东西。

**主共情点：收益（目标）。** 目标 = 最大创意点与冲突点。

| 支点 | 为什么必须有 |
|------|--------------|
| **路径** | 目标悬在最后，路径明确才能撑满片长（大理、泰囧庙、OZ 国） |
| **团队** | 场景换、交流在；**团队 = 一人缺点拆解**（唐僧无聊、多萝西无聊是副作用） |
| **目标** | 本质导向 |

**催化剂人物（一人上路）：** 每站 NPC 必有一方成长，否则无效。

**范围：** 公路片、抢银行、盗墓（鬼吹灯）等；国产商业片约占 1/3～1/2。

---

### 伙伴之情（Buddy Love）

**定义：** 两主体相爱；**兄弟情写法与爱情片一模一样**（耽美即此类）。

**主共情点：人物关系。** 核心：**互补 + 沟壑**。

**爱情四阶段（必背）：**

| 阶段 | 含义 |
|------|------|
| 互助 | 互补，互相圆梦 |
| 共谋 | 合谋做坏事（翻墙私闯泳池：共谋+阶级对抗+「沾水」戏数据好） |
| 误会/背叛 | 撕裂；诀窍：**选择权不平衡**（一方只有一条路，另一方多条路）；第三者最简单 |
| 成长为对方 | 弧线交叉；换座戏代表身份交叉（《绿皮书》） |

纯爱情电影变少（生活压力），但《绿皮书》《触不可及》仍可做伙伴之情。

---

### 超级英雄（Superhero）

**四要素：** 能力 / 命门 / 对手 / 使命（拯救世界级）。

**主共情点：** 有能力的人拯救我们（危机感呼唤保护神）。

**渊源：** 坎贝尔《千面英雄》；趋势下行（不信神、东方集体主义）。

**神话改编铁律：必须有群众基础**（西游 > 封神；没基础 = 跟胡编没区别）。可现代化：强警察/特工/父亲，四要素齐即可。

---

### 鬼屋（Monster in the House）

**定义：** 有限空间内，神秘力量追捕残杀（不限于鬼：海啸、鲨鱼、恐龙）。

| 要素 | 要点 |
|------|------|
| 密闭空间 | 缩圈才恐怖 |
| 神秘力量 | 吓人、能实质伤害 |
| 原罪 | 主角群有罪，惩罚才成立 |
| 群像 | 社会比喻 + 要死人、看不出主角 |

**神秘力量须不可沟通、无规律**（金刚能沟通 = 伙伴之情；凯撒 = 强悍对手非鬼屋）。

怪兽规律：要大、基于现实惧怕（数据上蛇仍强）。

票房天花板约 2 亿（小众刚需）。

---

### 侦探（Detective / 解密）

**定义：** 抛谜题，主角带观众探究。**广义 = 所有解密类**（律政、记者、法医）。

**主共情点：解密（逻辑满足）。** 有门槛、偏小众（看不懂就不看）。

**三要素：** 秘密 / 探秘者（观众的眼睛）/ 探秘者自我牺牲（融入案情）。

**铁律：探秘者与观众信息高度对称**——藏线索最后抖 = 戏耍观众。

**不得已结构：** 律政打自己的案子；警察追连环杀手最后伤到亲人。

**商业补救：** 叠加一级需求（开篇惨烈案情等）。实战常「叫停」侦探立项（创作者爱写、观众少）。

---

### 如愿以偿（Wish Fulfillment）

**定义：** 得所欲，终回归现实知何珍贵。**所有金手指、穿越类。**

**主共情点：那个「愿」。**

| 要素 | 说明 |
|------|------|
| 愿望 | 穿越、能力、伙伴（毒液） |
| 咒语 | 规则与代价 |
| 教训 | 珍惜当下 |

**诀窍：** 终点前金手指**帮助**，终点后**阻碍**；第四幕**扔掉金手指**解危机。

---

### 麻烦家伙（Dude with a Problem）

**定义：** 无辜普通人卷入大麻烦、有生命危险。

**主共情点：无辜。** 与鬼屋区别：**不能做原罪**（否则「活该」断共情）。

**主题：** 平凡但不平庸——用平凡方法解决，非机械降神。

现代新兴类型（《鬼子来了》《疯狂的外星人》《波斯语课》）。

---

### 变迁仪式（Rites of Passage）

**定义：** 人生变迁下的过激选择；正确解法是**改变自己**，非改别人或环境。

**主共情点：** 青春期、失业、离婚、绝症、产后抑郁等**人人会经历的阶段**。

现代类型；**最易高逼格得奖**。

**辨析：** 《内布拉斯加》公路但不是金羊毛——观众不共情「中大奖」目标，共情「爸老糊涂我怎么办」。

---

### 愚者成功（Fool Triumphant）

**定义：** 表面愚笨者在「伟业」前竟成功。

**主共情点：戏谑成功**（主角低于观众 + 伟业高于观众 + 竟完成）。

常做喜剧，先喜后感人；勿流于荒诞。《阿甘正传》《功夫熊猫》《律政俏佳人》。

---

### 被制度化（Institutionalized）

**定义：** 体制内众人同选，主角偏不、对抗体制。

**支点：** 环境制度（现实依据或夸张）/ 人群同选 / 主角另选 / 结局牺牲（个体毁、制度毁或逃离）。

主角类型：新来的 / 边缘人 / 觉醒者。《飞越疯人院》《驯龙高手》《失控玩家》——沉重话题也可俏皮。

---

## 五、AB 线与人物弧光

- **A 线 Want**（外在欲望/事件线）+ **B 线 Need**（内在需求/成长线）；勿称主副线。
- **人物弧光：** 内在改变（正剧常写坚持，喜剧常写改变）。
- **催化剂主角：** 主角不变，改变周围人（《落叶归根》《阳光小美女》）——商用结构的另一种选择。

## 六、商业片：悬念与爽点

### 6.1 悬念四要素

参与性 · 未知性 · 可能性 · 压迫感。

悬念 = **悬而未决的念想**（俄罗斯套娃式层级疑问）。**反转 ≠ 悬念**（反转靠误导/隐藏，慎用）。

### 6.2 十五桥段型爽点（节选）

扮猪吃虎、士别三日、打脸梗、唾手可得、主角光环、神器认主、装备展示、兄弟反目挡刀、金手指、善待小人物、拒绝大人物等。

**原则：** **只加两个**（多了腻）；**能量守恒**（此处得利彼处付出）。

### 6.3 商业电影 28 个关键套路（全文）

#### 创意（5）

1. **创意只有重复，没有创新**——内核几千年讲完；创新在情节细节。
2. **设定越大越难持久**——强设定要低解释成本、做成生活比喻（《雪国列车》车厢=阶层）。
3. **投入与抽离**——爱作品 vs 修改时客观（恋爱脑护稿子要不得）。
4. **喜剧不是类型，是元素**——先讲好故事再往行为台词加喜感。
5. **不能双重神秘力量**——一套系统底线。

#### 故事（9）

6. **绕过动作实现欲望**——动作失败，欲望仍满足（偷饼失败得饼）。
7. **一头一尾最重要**——开头「带刀前行」；结尾让观众哭或笑。
8. **控制疑问**——解答立刻抛新问。
9. **重视故事中点**——伪胜/伪败，治头重脚轻。
10. **不怕再来意外**——结局后仍可意外。
11. **烈度可再强**——目标、关系、对手、意外多维加强（合理合情）。
12. **善用小伏笔**——配角俏皮惦记（药神黄毛不说话）。
13. **事不过三**——通常恰好三回合。
14. **时间压力**——最后一分钟营救本质。

#### 人物（11）

15. 主角主动，亲自解决。
16. 主角出场有设计感（别十个捕快一模一样）。
17. 成长/胜利伴随牺牲。
18. 忠诚于某物（人底线）；极端人设须先立孝父等。
19. 共情口诀：不同中找相同，相同中找不同。
20. 两次选择机会（上路前、灵魂黑夜后）外化成退缩。
21. 主角与对手一枝两花（同根不同选）。
22. 反派自圆其说（傻反派 = 傻主角）。
23. 伙伴大目标一致，小目标相克。
24. 人物关系向心力 + 离心力并存。
25. 人物反应别漏写（表演是反应的艺术）。

#### 主题价值（3）

26. 主题 ≠ 道理；价值观小于故事人物。
27. 主角小道理，对手大道理。
28. 能量守恒、平衡。

## 七、与短剧 skill 的边界

| 本 skill | short-drama-manhua |
|----------|-------------------|
| 四幕 + 35–45 信息拍 | 20 节拍 + 充值一加一 |
| 故事中点 55 分 | 拐点正中 + 每 10 集充值 |
| 台词少、坐谈≤3 场 | 态度+信息+潜台词更密 |
| 类型片十类主共情 | 八桥段 + 五大爽点 |

从短剧升格：重做一句话与四幕，勿保留短剧场密度与解压优先。总流程见 [playbook.md](playbook.md)。
