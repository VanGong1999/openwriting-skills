# Short Genre Verticals（短篇垂直题材）

本 skill 自包含知乎故事专题（科幻、历史、悬疑、萌燃、富兰克林法）、短篇小说女性情感与真实感专题，以及与人物相关的**延迟满足识人**在类型文中的轻量用法。**垂直类型技法 + 构思工作流**在此；通用故事节拍见 `story-fundamentals`，完整人设四法/弧光见 `character-craft`。

**分题材深度稿**：见 [references/genre-verticals.md](references/genre-verticals.md)  
**公式、清单、富兰克林步骤、女性/悬疑工作流**：见 [references/playbook.md](references/playbook.md)

---

## 适用场景

- 选定或打磨**科幻 / 历史 / 悬疑 / 女性情感 / 现实向悬疑**短篇梗概与正文
- 类型常见病：科幻「只有设定没人」、历史流水账/史料堆砌、悬疑只有变态没有理性、女性角色脸谱化、梗概很嗨正文很假
- 用**富兰克林四步法**临摹爆款短篇结构后换题材原创
- 用**设定内核**（萌/燃/世界观）启动玄幻、克苏鲁、穿越等网文向脑洞
- 写**压力下识人、CP 可信度、反派/伴侣选择**戏（轻量延迟满足，非全书识人课）

## 不适用场景

- 纯商业带货、广告法 → `commercial-content`
- 短剧分集付费点、审查细则全文 → `short-drama-manhua` + `compliance-content`
- 网文连载扫榜、日更卡点 → `web-novel-craft`
- 喜剧元素专精 → `comedy-writing`

## 先判垂直类型，再套工作流

| 类型信号 | 主路径 | 成败尺子 |
|----------|--------|----------|
| 科技/世界问题 + 人性 | 科幻「双线合一」 | 情感高潮是否等于技术高潮 |
| 真实史地 + 人物纠葛 | 历史「五点小思考」 | 有无矛盾挣扎、是否尊重真相 |
| 设谜解谜 + 社会人性 | 悬疑「三条路径」 | 谜底前读者是否猜不出 |
| 女性处境 + 选择权 | 女性情感 | 是否立体、非工具人 |
| 现实细节 + 刑侦感 | 现实悬疑 | 内核 > 猎奇；手法人性 > 有病 |
| 缺手感、需结构临摹 | 富兰克林法 | 能否丢开原文凭笔记重写 |

## Agent 工作流（按序）

### Phase 0：类型锚点（60 秒）

- [ ] 一句话：**本篇垂直类型的「不可替代点」是什么**（换背景就塌的核）
- [ ] 科幻：科技盒 + 人物盒各一句（见下）
- [ ] 历史/悬疑/女性：标最强**共鸣情感点**或**悬念提问**
- [ ] 需要临摹：是否已有对标范文（富兰克林 Phase 1）

### Phase 1：垂直类型专用骨架

**科幻**

- [ ] **凝结核**：念头 / 画面 / 情绪三选一，先钉中心尘埃
- [ ] **储存知识**：核心 + 边缘知识（超链接式跳转），细节托真实性
- [ ] **双线合一**：科技弧线（世界问题→曲折求解→意外高潮）+ 人物弧线（人心/关系→至暗时刻→情感解决）
- [ ] **动笔前故事盒**：科技核心（解什么、用什么创新方案）+ 人物核心（情感困扰、关键转变因何）
- [ ] **科技叙述**：仅在对主人公**下一行动关键**时以最简方式进入；忌站着聊技术
- [ ] 自洽：不违背当下科学框架的可推导假设（不必纠结硬软标签）
- [ ] 短篇周期：尽量一月内完稿；完稿自信改错别字，忌无限拖稿

**历史 / 纪实向故事**

- [ ] **有底子**：人物/事件具备矛盾冲突、彷徨挣扎；一帆风顺 → 创造或放弃
- [ ] **懂尊重**：少旁白解释、伏笔点到即止、海明威式动词 > 形容词堆砌
- [ ] **能克制**：情感由读者体会，忌「供他……」式强煽
- [ ] **会取舍**：史料为取信，塞不进正文的删（知识的诅咒）
- [ ] **守底线**：历史向尊重考证真相，哪怕结尾逊色
- [ ] **叙事段位**：埋钩子 > 找亮点 > 流水账；短段落 + 数字小标题 + 段末钩
- [ ] **母题工具**：复仇、寻宝（或叠加持久母题）作裹故事内核

**悬疑 / 推理向**

- [ ] **配方**：99% 理性 + 1% 变态（立身谨重，文章可「放大」）
- [ ] **路径三选一**：① 中国古典 + 硬核本格 ② 社会派（坏人写透）③ 主角**弱点**成魅力
- [ ] **硬核可学**：密室（机械/心理时间）、诡计（换药、可能性犯罪等）、叙述性诡计（信息不对称、漏写关键段）
- [ ] **禁土法密室**：地道/烟囱/挤缝等
- [ ] **功夫在室外**：诡计易撞车，叙事与人物拉开差距
- [ ] 知乎向短篇：万字内须让读者记住你的 1% 爆破点，但能力需可迁移到长篇

**女性情感 / 共鸣向短篇（构思层）**

- [ ] **想读者**：七问清单筛共鸣点（见 playbook）
- [ ] **想范围**：一篇打透**一种情绪** + 一两个名场面，忌框架过大
- [ ] **想视角**：谁站在何处看到什么（彩礼等同题异视角范例）
- [ ] **处境**：从「维持婚姻」到「要选择权」——矛盾从惯性与现实错位来
- [ ] **切入点**：真实 + 提炼 + 糅合；普通外表下的集中痛苦
- [ ] **立场**：客观包容共情；撕标签式「美丽废物/恋爱脑」工具人
- [ ] **细腻三要素**：细节、欲言又止式对话、心理层次（可男视角写女，但忌刻板）

**现实题材悬疑（盐选/短篇）**

- [ ] **忌猎奇血腥**作为主菜；敬畏生命，贴近细节与生活
- [ ] **先找内核**：想表达的社会/人性命题（有内核则小 bug 读者愿宽容）
- [ ] **动机—手法—结果**：藏其二、露其一，换视角即换悬念强度
- [ ] **手法三等**：下等有病结局 < 中等控证据 < 上等用人性（爱、恨、创伤）
- [ ] **视角**：与案无直接关联但有跟进动机；切入点 = 视角与剧情首次碰撞
- [ ] **反转**：通常两个——猜得到的 + 猜不到的
- [ ] **情绪发泄点**：塑造一个「可爱」角色供读者评述；悬疑句式瘦身、留白信息

**萌 / 燃 / 设定驱动（类型文通用）**

- [ ] **人设** = 萌要素（行为指令库）+ 人物逻辑；**世界设定**可与人物对称作第二原点
- [ ] **连贯性**：不 OOC、世界法则一致
- [ ] **典型性**：原创最能展露设定魅力的典型场景（傲娇告白等可仿，新意靠自创典型）
- [ ] **找内核**：设定对应何种欲望/焦虑（如克苏鲁＝对不可知之恐惧）
- [ ] 老设定：沿逻辑推到极限 → 反面变体（穿越＝可能性压垮确定性）

**富兰克林临摹（突破卡文时插入）**

- [ ] 找范例 → 主旨/素材/评价（+故事起承转合）→ **丢开原文**凭笔记重写 → 对比精炼/素材/价值
- [ ] 著作权：借鉴思想，表达原创；故事可换背景/人设仿结构

### Phase 2：真实感装订（跨界必做）

短篇读者易出戏，以下与类型叠加：

- [ ] **事理 / 情理 / 文化**三层逻辑闭环（脑洞除外设内自洽）
- [ ] **情感过硬**时理性可暂时失效（读者愿原谅少量 bug）
- [ ] **间接经验**：案件、职业、时代细节有据可查
- [ ] **人物八方向**检视（ police 式外貌…婚介式感情），选一两个关键细节露笔
- [ ] 主角行事**名正言顺**，忌无理由黑化心机女/反派（要写须交代）

### Phase 3：识人金线（人物戏交叉，轻量）

写关系抉择、职场识人、CP 可信、反派诱惑时：

- [ ] 延迟满足 = **AB 取舍**（非硬憋）：眼前满足 vs 更大收益
- [ ] **压力下见真人**：冷静系统易被压制 → 看应激习惯
- [ ] **分事儿看人**：同一人在工作/感情/对弱者耐心可不一致
- [ ] 亲密戏：舍得时间+情绪；大五宜人性/尽责性/开放度/情绪控制（两项低危、三项低勿深交）
- [ ] 言行：**知行合一**分层（知且行且迭代 > 知而不行 > 瞎忙 > 无知无行）
- [ ] 完整人设弧光、四法、延迟满足长练 → 并行 `character-craft`，此处不展开

### Phase 4：完稿自检（类型 + 真实）

- [ ] 科幻：情感高潮 = 技术高潮？是否人类个体主角（非「全人类」抽象）
- [ ] 历史：是否删了塞不进书的史料？有无为了一帆风顺硬写
- [ ] 悬疑：谜底前能猜出吗？是否只用「精神分裂」
- [ ] 女性向：是否还有一个可删的支线淹没名场面
- [ ] 富兰克林练习：是否误抄原文表述
- [ ] 合规意图：**正向价值、不猎奇擦边**；全文红线 → `compliance-content`

## 输出偏好（Agent 帮写/改稿时）

| 任务 | 输出结构 |
|------|----------|
| 科幻梗概 | 凝结核 + 双弧表格 + 高潮合一一句 |
| 历史选题 | 人物矛盾清单 + 埋钩子开头 3 句 |
| 悬疑大纲 | 路径 + 谜底前读者应信什么 + 叙述诡计缺口 |
| 女性短篇 | 共鸣点 + 名场面 2 个 + 视角一句 |
| 富兰克林 | 起承转合表 + 换设定仿写梗概 |
| 通稿体检 | 三逻辑表 + 类型专项 5 条 |
