# 长剧与视听剧本实操 Playbook

> 本包自包含：一句话与十五元素、四幕节拍、类型片速览、分场台词要点、广电实务与 **Pilot 试播集五步法**。细节展开见 [genre-beats.md](genre-beats.md)、[scene-dialogue-craft.md](scene-dialogue-craft.md)。执行时以具体片方/平台最新规范为准。

---

## 一、总纲与优先级（vs 短剧）

**编剧第一法则：写什么比怎么写更重要。**

**长叙事优先级：**

```text
故事完整性 · 节拍连贯 · 人物弧光/共情 > 单场爽点堆砌
```

短剧 Skill 中的「解压 > 审美 > 故事」**不适用于**本 Playbook。改编竖屏稿升格长剧时，须重建一句话故事与四幕节拍，而非保留充值节奏。

**服务对象：** 观众（共情、完播）；**市场是 To B**（定制/分账/拉新）。先把**商业片**写好，再谈作者电影。

**精彩三要素：** 变化 · 对抗（冲突）· 共情。

## 二、一句话故事与选题

### 2.1 模型

```text
一个「什么人」在「什么情况」下，仍然要「完成什么目标」
```

- 目标须**主动**（内驱力）
- 验证：口头 pitch，听众人是否产生「想知道后来」的冲动

### 2.2 十大设定（10 选 1～3，4 个为极限）

| 归属 | 类型 | 含义（略） |
|------|------|------------|
| 什么人 | 困兽 / 出水之鱼 / 壮举 / 人物关系 | 虎落平阳、假县长、不可能任务、相反人捆在一起 |
| 什么情况 | 激励 / 环境 / 规则 / 赌局 / 解密 / 对手 | 推出舒适区、困境空间、玩法规则、高风险目标、谜题、强大反派 |

### 2.3 目标六方向（6 选 1）

赢得 / 消灭 / 阻止·守护 / 逃离 / 送达·履约 / 救回·找回

### 2.4 新手误区（先扼杀）

- 平凡伟大作者电影路线（先让观众认可）
- 纯苦难/死亡气息撑主流
- 「别人没写过的故事」（换**元素**而非换故事体）

## 三、观众心理与十五元素

**幸福感需求链（强→弱）：** 性/暴力 → 喜剧 → 振奋 → 感动 → 猎奇 → 逻辑满足。

**故事 = 环境 + 人物 + 事件 + 主题**

**事件五要素：** 核心问题（钩子）/ 阻力（对手·环境·自我）/ 转折 / 代价 / 结果

**AB 故事：** A = Want（外在）；B = Need（内在成长）。勿称主副线。

**人物塑造：** 可怜 · 可信 · 可爱；对手宜做「镜像」；影视公司常见需求 = **主角弧光**（催化剂主角例外）。

**贯穿克制：** 能量守恒；爽点/元素**只加两个**；**先做对再做好**（一句话→节拍流畅→商业片）。

## 四、三幕 / 四幕节拍

| 范式 | 分段 | 比例直觉 |
|------|------|----------|
| 三幕 | 建制 — 对抗 — 解决 | 约 1:2:1 |
| 四幕 | 建制 — 推进 — 转折 — 解决 | 起承转合 |

### 四幕节拍表（核心工具）

| 幕 | 关键节拍 |
|----|----------|
| 第一幕·建制 | 开场画面 → 世界 → 人物（救猫咪）→ 激励事件 → 争执 → 目标 → 主题 |
| 第二幕·推进 | 仪式感 → 伙伴导师道具 → B 故事 → 游戏时光 → 试炼 → 接近目标 → **故事中点**（伪胜/伪败，约 55 分位） |
| 第三幕·转折 | 否决中点 → 调整 → 升级 → 大意外 → 灵魂黑夜 |
| 第四幕·解决 | 疗伤 → 蜕变 → 解决悖论 → 决战 → 目标达成 → 结束画面（呼应） |

**解决悖论三法：** 重释道具 / 孤注一掷 / 自我牺牲（金牌道具开场埋、末幕闭环）。

**拉片：** 信息节拍 / 信息熵；商业片约 **35–45** 个节拍。

## 六、分场与台词

### 6.1 剧本硬要求

可视听化 · 按放映顺序 · **禁大段闪回/旁白独白** · 用动作说话

### 6.2 分场四步法

```text
锁定任务 → 找对抗 → 用事件包裹 → 带来转变
```

单场须：交代信息 / 推进剧情 / 带来变化；**无变化可删**。

### 6.3 台词原则

- 台词**没有事件重要**
- 坐下谈话**别超三场**
- **忌用台词推进剧情**（大忌）
- 七注意：简洁、避 Q&A、潜台词、少代词、争论/错位/炸弹理论、个性化
- 金句优先人设型、情境型；慎用哲理型

## 七、电视剧模式与广电实务

**电视剧三种模式：** 经典叙事（单集信息熵/悬念）、群像叙事、章回体。

**市场行为：** To B；**不要先写全集去卖**。

**提案：** 命中率心理预期 1/10、1/60 量级；心法 = 共情。

**过审（广电向）：** 「1500 + 300」（梗概 + 思想内涵）；**尺度不是问题，价值才是**；价值 / 概率 / 共情专家。

**格式：** 无唯一国标，但需行业可读；一场戏时长直觉约 **1.5 分钟**。

**卡文检查：** 主题 / 核心对抗 / 主角成长 / 人物关系 / 攻击不足。

## 八、Pilot / Spec 与试播集五步法

（一小时试播集约 55 页；结构为 **规定性** 模板——贴近则 pilot 更扎实，非描述「所有在播剧都如此」。）

### 8.1 三个商业问题（推荐倾向）

| 抉择 | 推荐 | 核心理由（简） |
|------|------|----------------|
| Pilot vs Spec | **Pilot** | 不 pigeonhole、55 页好读、原创样本、可能开发 |
| Episodic vs Serial | **Episodic** | 好 pitch、可写非起源典型集、易 syndication |
| Cable vs Broadcast | **Cable**（可降级广播） | 更大胆难忘、买家多、写作自由 |

**聪明计划：** 大胆单元剧式付费有线 Pilot，内容能 **toned down for broadcast**。

**100 集逻辑：** 5 季 × 20 集 ≈ 联合播出目标；**人 + 概念**（人剧，非纯概念剧）。

### 8.2 五步法（Jeffrey Allen Schechter / 谢克特试播集工作流）

> 行业亦称 **Schechter 五步法**：Know your show → characters → structure → series pitch → episodic structure。下文按同序展开。

1. **Know your show** — 类型及其观众承诺；多为**程序剧**（每周病例/审判）；有线 vs 广播（大胆度）；单元剧 vs 连续剧；**100 集 = 5 季×20 集**（联合播出目标）；**人剧非概念剧**（把有趣的人嫁给有趣的概念）  
2. **Know your characters** — 主角须 **empathetic**；五法：强者、某方面最强、不应得的不幸、摸狗、古怪或酷；配角 **Unity of Opposites**：1 反派 + 1 英雄 + 3 对 6 人（Protector/Deflector、Thinker/Feeler、Believer/Doubter）；每种功能只保留一个；配角当各自故事里的英雄来塑  
3. **Know your structure** — 集 / 季 / 系列共用 **四原型**；每层约 1/4 时长对应 Orphan → Wanderer → Warrior → Martyr  
4. **Know your series pitch** — **TV Quick Pitch**（见下）；写作前先拆四原型  
5. **Know your episodic structure** — Teaser + 四幕页数（2–4 + 13×3 页量级）；**情节点** = 离散信息单元（非场景数）；A/B/C + **60/30/10**；**晚进早出**、每场景强按钮  

**四原型：** Orphan → Wanderer → Warrior → Martyr（对应核心问题 yes/no 的回答节奏）。

**英雄同理心五法：** 强者 / 某方面最强 / 不应得的不幸 / 摸狗 / 古怪或酷。

### 8.3 Episodic 试播情节点（中位参考）

| 段 | 原型 | 情节点数 | 要点 |
|----|------|----------|------|
| Teaser | Orphan | 1 | 引入 A question，强按钮 |
| Act 1 | Orphan | 8 | 核心问题清晰，地基最牢 |
| Act 2 | Wanderer | 5 | yes-no 交替，末点 false victory |
| Act 3 | Warrior | 6 | no 开头，B/C 解决，big yes 悬 A |
| Act 4 | Martyr | 3 | no → big no → final yes，重置系列 |

- A/B/C 故事 + **60/30/10** + D 元素（主题香料）  
- 情节点 = 信息单元，非场景数  
- 场景：**晚进早出**，每场景强按钮  
- 强度由低递增到 10  

**TV Quick Pitch 公式：**

```text
有缺陷的人（孤儿）+ 被过去困扰 → 卷入持续使命（流浪者）
→ 令人惊讶的转折（战士）→ 努力与牺牲解开过去（烈士）
```

**写作前检查清单（节选）：** 概念原创、研究同类剧、英雄与配角对立统一、系列/本季/pilot 核心问题、TV Quick Pitch、成功剧作 role model。

**大秘密：** 写成你认为的**最极端表达**（unproducible 的精神），再评估可制作性。

### 8.4 Hauge 故事定义（基底）

让**富有同情心**的角色，克服**一系列越来越难、看似无法逾越**的障碍，去实现**令人无法抗拒的渴望**。

## 九、与网文/短剧升格对照

| 从…升格 | 必做 |
|---------|------|
| 网文 | 压缩信息熵到视听场；删内心独白改动作与选择 |
| 短剧 | 重建 Want/Need 与四幕；弱化充值点密度，强化故事中点与灵魂黑夜 |
| 电影 | 一句话 + 15 拍/四幕；类型片主共情点先行 |
