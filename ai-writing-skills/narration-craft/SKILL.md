# 叙述技艺（narration-craft）

正文层「怎么写」：把脑内画面落成可读文字，稳住视角与代入，让场景切换自然、段落留印象。逐步 SOP、公式与自查清单见 [references/playbook.md](references/playbook.md)。

## 使用方式（Agent）

1. **先判定任务类型**：纯叙述技法 → 读本 skill；结构/爽点/循环/开篇/高潮 → 转 **web-novel-craft**。
2. **输出结构**：诊断（病因）→ 选用公式/SOP → 改写要点或示例句气质 → 自查清单。
3. **不编造**：平台规则、收入、未载明案例细节不得虚构；课内体验建议（如单段字数）标 **【经验口径】**；口误或待核处标 **【待核实】**。
4. **需要全文模板时**：读 `references/playbook.md` 对应节，勿在对话中复述整本 playbook。

## 适用 / 不适用

### 适用

| 场景 | 本 skill 入口 |
|------|----------------|
| 语言滞涩、段落臃肿 | 短段短句 + 动/静态顺序（playbook §2） |
| 有画面写不出、场景空 | 画面五招 + 代入感练法（§1、§7） |
| 视角乱跳、代词指代乱 | POV 决策树与同场切镜（§3） |
| 外貌五官堆砌、时机不对 | 氛围 + 记忆点 + 观察顺序（§4） |
| 换景生硬、只会省略号 | 转场六法轮换（§5） |
| 段落平淡无印象 | 电影叙事：氛围先行、记忆点、偷窥式（§6） |
| 单段剧情不够「好看」 | 读者预知 + 视角对比；明暗牌慎用（§8） |

### 不适用（分流）

| 需求 | 转向 |
|------|------|
| 大纲/细纲、九节点、卡文回层、开书全流程 | **web-novel-craft** |
| 爽点层次、三万字循环、扫榜跟风、书名简介开篇冲突 | **web-novel-craft** |
| 打斗前中后 SOP、感情线六步、对话四法专练 | **web-novel-craft**（打斗/感情/对话 reference） |
| 结构立意、剧本分场、短剧/manhua 节拍 | **story-fundamentals** / **short-drama-manhua** / **screenwriting-longform** |
| 纯 IP 宇宙、短视频画面制作流程 | 其他专项 skill |

> 叙述技艺服从「故事能写通」；**平淡剧情先补对比与信息**，不是堆描写技巧（playbook §8）。

## 工作流

### A. 改一段已有正文（默认）

```text
1. 读本段主视角是谁？是否多人「心想/听见」齐飞？
2. 读本段要留什么情绪/后果？缺则补代入（§7）
3. 动态动作用连续动词拆帧；静景/空镜定一条观察轴（远→近 或 上→下，一次一种）
4. 画面仍弱 → 套五招：以点盖面 | 镜头顺序 | 侧面避短 | 一两笔细节 | 感官点睛
5. 换场 → 从六法中选一种，忌全篇省略号
6. 收尾：playbook 末尾「叙述层总自查」勾选
```

### B. 从零写一场戏

```text
先决：读者是否对本情节有兴趣（戳软肋）——无兴趣则技巧无效（§7-0）
→ 氛围/环境能否先立情绪（§6）→ 再人物表演
→ 固定内视角写所见所闻所感 → 必要时一次镜头过渡到配角
→ 段长【经验口径】单段约 1–48 字、最多约 50 字；长句切开
```

### C. 设计「一段好看的剧情」（叙事层，非结构课）

```text
读者预知（信息前置，带期待）
+
本段核心对比视角的心理转变
→ 爽点/情绪发生
可选：明暗牌打信息差，但须预埋掉马甲后的下一钩子（§8）
```

### D. 练笔/拉升画面转化力

```text
拉片：空镜 → 声音/异动 → 视线移向人物
改编对照：按影视画面写文字 → 再对原著看差距（课内强烈建议）
仿写可选；囤理论书不能替代上述对照练
```

## 叙述层高频避坑

| 坑 | 做法 |
|----|------|
| 多人同段心理齐飞 | 固定主视角；配角要烘托再切，段落内稳定一人 |
| 第一/第三人称章内乱混 | 网文忌混用；番外可另用人称【课内口径】 |
| 五官外貌流水账 | 氛围 + 一个记忆点；按观察顺序、分舞台释放 |
| 脑中宏大写不出 | 先疑画面是否缺层次；以点盖面 + 镜头顺序 |
| 全篇「……」硬切 | 六法轮换 |
| 无效肖像（摸鼻、心颤堆砌） | 细节须带情绪或氛围，或服务伏笔 |
| 暗牌叠马甲无后续期待 | 掉马甲须接新钩子，勿当万金油 |
