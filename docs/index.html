Quick start

先装通用创作包

链到 Claude / Codex 的 skills 目录后，用 /skill-name 或 $skill-name 调用。

git clone https://github.com/VanGong1999/openwriting-skills.git
cd openwriting-skills

ROOT="$(pwd)/ai-writing-skills"
mkdir -p ~/.claude/skills ~/.agents/skills
# 按需 ln -sfn "$ROOT/<skill>" ~/.claude/skills/<skill>
