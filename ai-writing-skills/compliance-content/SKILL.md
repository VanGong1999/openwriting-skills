# Compliance Content（内容合规）

本 skill 合并短剧审查尺度、短剧最新注意事项中的政策体感、商业带货风险课、漫剧题材红线与 AI 写作常见拒稿点。**目的：认清边界、安全创作**；**不是**教用户试探红线、色情擦边、仇恨煽动或规避监管的数字伎俩。

**合并自检清单与替换话术**：见 [references/playbook.md](references/playbook.md)

---

## 适用场景

- 短剧 / 漫剧 / 网文剧本 **上线前自检**
- 知乎 fiction、女性情感、悬疑中的**尺度与价值观**
- 商业种草、好物、品牌软文 **三层风险**排查
- 选题阶段过滤**必下架题材**
- Agent 改稿：标红敏感段 + 给**合规改法**（删减、虚化、正向 framing）

## 不适用场景

- 法律咨询、行政处罚应对、具体判决引用
- 各平台 2025+ 细则的实时爬虫（清单为**创作口径 + 常见红线**，发稿前再对官方规则）
- 外国发行分级（本节以国内平台自审为主）

---

## 原则（必读）

1. **了解边界 ≠ 碰边界**：合规为了过审与账号寿命，非「刀口舔血」。  
2. **平台自审为主**：人审松紧不一，无永恒定论；偏保守更稳。  
3. **正向底色**：复仇/战神可写，主角仍宜善良正直、有追求；忌「社会逼良为娼」唯一叙事。  
4. **两性爽点**：靠暗示与氛围，不靠直白卖弄与裸露。  
5. **穿越架空**：真史真人真歌真企真 IP 蹭名 = 版权与审查双雷。  
6. **商业文**：保护的是**表达**，不保护思想；可借鉴结构，不可抄表述、不可绝对化鼓吹疗效。

## Agent 工作流：合并自检

### Phase 0：内容性质分流

- [ ] **虚构叙事**（短剧/小说/漫剧）→ 走 A 虚构清单  
- [ ] **商业转化**（种草/测评/带货）→ 走 B 商业清单  
- [ ] **二者混合**（故事带货）→ A + B 均扫

### Phase A：虚构与短剧

**A1 硬红线（出现即高风险）**

- [ ] 军队、政党、警察、宗教、**同性题材宣扬/涉及**（口径按平台从严）  
- [ ] 真人民币/国徽/国旗：**仅剧情合理必要**；办公室插旗等无必要勿设计  
- [ ] 公职人员作恶主线、赌博提倡、抢劫侵犯细节展示  
- [ ] 重生唱未购版权真歌、投资真实名人企业、拍真实电影、蹭热 IP 改一字  
- [ ] 具体省市区县、真实车牌机关门牌（宜虚化）  
- [ ] 漫剧：**出马仙**（相关剧目大规模下架风险）、**真鬼**、血腥暴力恐怖画面  
- [ ] 国民 IP/名著：**不魔改原剧情**；角色宜正面；金庸/迪士尼等侵权勿碰  
- [ ] 地域文化英雄（花木兰等）忌恶意魔改  

**A2 两性呈现**

- [ ] 禁直接卖弄风骚、赤裸挑逗、露大腿露沟（后期亦忌依赖模糊糊弄）  
- [ ] 禁触碰敏感部位、吻敏感部位（隔衣亦不行）  
- [ ] 强迫/交易/奴役/虐待/援交类：**不宜多、单次 ≤约 3 秒、点到为止**  
- [ ] 好作品用台词氛围撩拨，非裸露硬上  

**A3 语言与标识**

- [ ] 脏话：**哔音 + 字幕处理**；忌连珠炮  
- [ ] 仅偶发普通粗口  

**A4 价值观与政策体感**

- [ ] 不写「社会必然把好人逼成坏人」作为作品价值观  
- [ ] 政策收紧体感四块：**色情擦边**（最严）、封建迷信、炫富神豪、无底线暴力复仇  
- [ ] 付费短剧：**爽点单一明确**；杂糅悬疑喜剧科幻堆赛道易充值弱（非合规但影响过审叙事）  

**A5 悬疑/知乎 fiction 特条**

- [ ] 猎奇血腥不能主菜；忌「全员精神病」收尾  
- [ ] 软色情、挑拨男女/地域/阶层对立  
- [ ] 第一人称悬疑注意别靠无穷巧合（间接影响内容尺度观感）  

### Phase B：商业与带货

**B1 商业风险**

- [ ] 无捧一踩一、无诋毁竞品（改摆事实：适合谁不适合谁）  
- [ ] 无保证上岸/治愈/根治等过度承诺  
- [ ] 非医疗品不写治疗、抗炎、溶脂等疗效词；经历须声明**个人不等同普遍疗效**  

**B2 平台规则**

- [ ] 好物不带药械保健（知乎等规则）  
- [ ] 不用 10 周岁以下儿童代言；直播推荐不满 16 岁  
- [ ] 无软色情、李诞式「躺赢职场」、奥迪式物化、绝味式性暗示  

**B3 广告法**

- [ ] 无国家级/最高级/最佳等绝对化（用第一梯队、天花板、榜单事实）  
- [ ] 无国旗国歌军政机关形象推销  
- [ ] 核实资质；专业人用自己知识拒伪科学宣传  

### Phase C：AI 辅助稿附加

- [ ] 平台拒纯 AI 味稿：格式标点、逻辑、人设一致人工复核  
- [ ] 名著/凡人修仙传等：** AI 续营权利益**可能侵权；须人工大改  
- [ ] AI 不能替代合规判断；敏感段勿交给模型「想办法过审」  

### Phase D：修复策略（合规向）

| 问题 | 方向 |
|------|------|
| 历史真人朝代入 | 改架空国号地名、合成人物 |
| 警察破案线 | 改民间侦探/记者/律师视角，避公职破案 |
| 情欲戏 | 改权力/对话暗示，切镜头留白 |
| 鲜血仇杀连杀 | 减频次、象征化、正义动机与审判结局 |
| 拉踩竞品 | 改对比维度 + 人群适配 |
| 绝对化 claims | 改数据榜单 + 相对表述 |
| 真鬼恐怖 | 改心理恐惧/规则怪谈/人谋 |
| 笑点冒犯弱势 | 改自嘲或典型共识靶（仍审慎） |

## 输出偏好

- **审稿报告**：🔴 必改 / 🟠 建议改 / 🟢 可选；每条附**合规替代写法**一句  
- **选题否决**：若触犯 A1/B 硬项，直接建议换梗，不给擦边技巧  
- **商业文**：附三层对照表勾选结果
