## 0. 开书前决策树

```text
是否主攻番茄等免费广告流？
  是 → 走「狂更猫选题顺序」+ 文末番茄专章；日更锚 4000
  否 → 仍以扫榜/对标开篇定站气质（零基础班 06）；合同与榜类按目标站

是否零基础、尚未定赛道？

  是 → SOP-B 拆书落表 → SOP-C 四级纲或循环倒推
```

## 1. 扫榜与跟风

### SOP-A1 零基础班刷榜（全站通用）

```text
1. 选定目标平台
2. 只看自然榜（非强推堆量）
3. 表格记：类型、设定、卖点、节奏、人设、签约门槛对照
4. 分阶段找「自己能写的变种」
5. 读对标开篇十几～二十章对齐气质
```

### SOP-A2 狂更猫扫榜日常 **【番茄·免费流偏重】**

```text
每日：番茄推荐榜+人气榜；飞卢天榜+收藏（课内习惯）
翻前约 10 万字，记金手指与「解决问题的方式」（偷方式不背剧情）
开题材三问：能否说清爽点循环？中位数能恰饭？同人是否改够？
卡文：搜同型 20～50 本前三章；对照查漏补缺表；可跨类型借视角反应
```

### SOP-B 拆爆款四表（零基础班）

```text
按原文顺序读开篇
→ 填表：梗概 | 卖点 | 感情线 | 节奏
→ 问：它如何为平台赚钱？
→ 提炼可迁移机制（禁止只贴「有悬念」）
```

### SOP-B2 女频四要素 + 四换三（狂更猫）

```text
每本榜书四问：背景 / 女主人设 / 金手指 / 主线本质
→ 保留主线本质，换背景/人设/金手指（四换三）
→ 章节拆：梗概/节奏/五要素/人物/转场/钩子/爽点
```

### SOP-仿写边界 **【番茄·免费流】**

```text
易判像：切入点像、金手指类似、第一章结构相似 → 三项避开
简介可抄同类型结构，换名与金手指表述
卡文对标：打开即关，禁止边抄边发
```

### 正确选题顺序（狂更猫 · 免费流主推）

```text
扫榜 → 魔改书名 → 书名过关后写简介 → 围绕简介写开头 → 写到首秀
禁止：先写开头再补书名
```

## 2. 四级纲与故事工程

> 全文 SOP 本节为概述；九节点、细纲四法、三万倒推、搭台步骤展开见 [outlining.md](outlining.md)。

### 零基础班路径（通用长篇）

```text
灵感/核心梗
→ 微创新或反套路调整
→ 设定整理（人设+背景）
→ 草纲 → 总纲 → 大纲 → 细纲 → 正文
→ 卡文回层：大情节点→大纲；走场→细纲/代入
```

### 总纲四步

```text
1. 一句话主线
2. 独特性故事纲要
3. 人设表 + 背景设定（名词/地图/规则）
4. 分阶段剧情：地图法 / 等级法 / 进度法（可混）
   言情：感情四步；开局优先久别重逢等有前史
```

### 大纲推进

- 九故事节点（可只用 3–5 个）+ **冲突万能公式**（一个乱字 + 两个关口可用于开篇级）
- 细纲拉长四法：剧情拆解 | 逆推推导 | 戏剧冲突 | 产生对比
- 日码万字以上靠细纲（课内口径）

### 红娘子千字大纲（入门闭环）

四块必清：**故事 / 人物 / 冲突 / 立意**（自己懂且他人能懂）→ 分章细纲 → 按纲日更

### 写作课程2 结构补充

- 探索型：目标坚定 + 后纲自检（脱离主线？踩雷？坑填？）
- 逆推法：站在高潮回溯所需装备/人物/关系
- 珍珠串项链：独立事件串主线，阴阳珠子交错

### 稳书验证（狂更猫 SOP-32）

```text
书名+简介过关后：
主线：一句话
核心亮点：一句话（读者点进来的理由）
规划约四个剧情（约 12 万），每个都围绕核心
确认后再开写；写歪删回靠
铁律：主线 ≠ 核心亮点；升级常是来源不是爽点本身
与点进来理由无关的内容可删
```

### 第一个十万字倒推（狂更猫）

```text
定背景人设金手指主线 → 先定大结局 → 定 10 万中点
→ 倒推节点（主线∥感情线）→ 身世资源
→ 切成约 3 个大剧情填满 10 万
```

### 三万字循环（狂更猫）

```text
1. 能否循环、有无对标热度、难度适合否
2. 定第 1 个 3 万字终点（震惊/阶段性变强）
3. 倒推约 15 章章纲（章约 2000 字）
4. 中间章只推进不跑题
5. 第 2 循环 = 第 1 循环加强版
```

### 单剧情 11 要素（女频清单）

环境｜优势倚仗｜引入事件｜思考打算｜突发事件｜增加难度｜对手反应｜爽点（读者向后果）｜厉害之处｜震惊｜收获（须服务主线）

## 3. 书名、简介、开篇

> 冲突/悬念/设定开篇与五信息点、前五章避坑展开见 [openings-hooks.md](openings-hooks.md)。

### 书名

| 来源 | 公式 |
|------|------|
| 零基础班 | 新手直白有趣；万能：**身份 + 目标 + 反差** |
| 狂更猫 | **题材 + 金手指 + 热词**；四问：期待感？写得出？有矛盾？定位读者？ |

### 简介

**零基础班**：环境+人物+冲突（带悬念）；1～2 尖亮点；忌大纲流水账  
**狂更猫五段**：处境（可小抑）→ 金手指与效果（画饼）→ 成长路径 → 爽点预知 1～3 例 → 一句收束

### 开篇路线（零基础班）

```text
问读者想看什么 → 选路：冲突 / 悬念 / 设定（可叠）
冲突：「乱 + 两关口」，给主角不行动就崩的理由
设定：世界观 / 金手指 / 魅力热点
书名亮核心 → 简介亮冲突悬念 → 前三章兑现吸引力，章末瞬间悬念
```

### 男频万能稳妥开头五步 **【常用模板】**

```text
① 穿越醒来+世界观+危机/催系统+出系统（说明能干嘛）+章末读者预知
② 铺垫视角（震惊对象）→小目标+强调优势
③ 增加视角（直播等）
④ 欲扬先抑→装逼打脸（必须有对比）
⑤ 爽点扩散+收获盘点+下一目标服务大目标
```

### 第一章信息密度

- 男频约 2000 字内五信息点：世界背景 / 穿越重生 / 危机 / 优势+思考定目标 / 进入事件
- 女频五要素：女主与世界 / 金手指 / 现状（人物宜少）/ 思考与行动 / 有效突发事件接第二章

### 前五章骨架（狂更猫）

```text
Ch1: 世界观→身份→目标→展示→问题→金手指介入
Ch2–5: 人物动机→场景→目的不同拉矛盾→反派落到人性
基调：展示主角优势；章末须有读者预知（优势将如何作用）
```

### 女频前三章

```text
定保留主线 → 四换三 → 拆对标前三章「章功能」→ 按功能写自己情节
信息靠对话心理渗透，忌说明书；不会则 1 对标 + 5 参考缝合
```

### 写作课程2 黄金一章

- 读者耐心约五六百字；**类型 + 主角 + 矛盾点**
- 打脸需持续性与升级空间，勿一次打死渣男

## 4. 爽点、期待感、信息差

> 伏笔高潮、情绪引爆、爽点分层、瞬间悬念七法展开见 [climax-suspense-hooks.md](climax-suspense-hooks.md)。

### 定义（狂更猫）

- **爽点本质 = 对比**（不是单纯给好处）
- **期待感本质 = 读者预知**（兑现要超预期）
- **剧情**：先想最终装逼结算画面 → 倒推中间圆谎 → 过程用信息差拉期待

### 循环三要素

主角目标 + 金手指 + 核心（爽点来源）；主线 ≠ 核心

### 一个循环八步

```text
拉出目标 → 找逻辑 → 设阻碍 → 围绕核心制造爽点（有关系的对比）
→ 展示奖励要快 → 新阻碍/误会续到目标完成 → 结算 → 新目标
```

### 爽点加料 SOP

```text
定事件 → 金手指=读者预知1 → 叠加预知
→ 先定结算画面 → 倒推圆谎 → 信息差拉期待 → 兑现+超预期
```

### 爽点分层

读者预知到位 → 欲左先右 → 分层爆发别一次砸完 → 卡在期待高点

### 零基础班 + 写作课程2

- 马斯洛五层 → 约十二类爽点套路（零基础班）
- 三板斧：环境、感官（含心理博弈）、落差对比
- 七种爽感：成就、压抑宣泄、三观满足、超经验麻烦、信息差、灭小人、上位者凝视
- 一章 ≥ 2～3 个情绪引爆点

### 一段好看剧情（狂更猫）

读者预知（带期待）+ 视角对比（重点角色心理转变）

### 主视角推进链

所见 → 五感 → 思考目的 → 配合金手指造问题 → 再思考解决 → 短期目标服务长期目标  
心理活动 = 行为逻辑说明书（不可省思考定目标）

## 5. 人设与金手指

> 金手指四方面、微创新反套路、审设定三问展开见 [golden-finger-setting.md](golden-finger-setting.md)。

### 三维人设（零基础班）

```text
一维：开篇纸面速立（女频可强）
二维：事件与行为语言堆积（男频主战场）
三维：心魔/世界观等（可选）
团队：冲突/互补/镜像/反差
男频：主性格稳定，次性格可转变；区分成长 vs 转变
```

### 人设倒推（狂更猫）

定类型与结局 → 倒推关键节点 → 分叉选线 → 列节点能力性格 → 汇总人设 → 3+ 小剧情演出来

### 金手指（零基础班 SOP-24）

```text
从四方面想设 → 检查共性底线
→ 少而可延伸、弱开有成长
→ 与主题/背景碰撞矛盾 → 服务爽点且逻辑自洽
金手指 = 把不合理合理化
```

### 金手指（写作课程2 七特质）

唯一性、升级空间、有限制、隐匿、易懂、不要太多、不完全依赖

### 陌生化 / 微创新（零基础班）

反套路、穷举组合五元素（结构×情节×人设×背景×冲突）；新手主微创新勿神话开类型

## 6. 卡文、日常、感情线

> 本节为概述。**打斗**全文 SOP 见 [fight-scenes.md](fight-scenes.md)。**男频女频差异、日常目的、大女主无 CP** 见 [male-female-channel.md](male-female-channel.md)。**感情线六步、拉扯法则、对话四法与爱情循环** 见 [romance-dialogue.md](romance-dialogue.md)。

### 破卡文分型（零基础班）

大情节 | 衔接 | 描写 | 小情节走场 → 对应回纲/转场六法/代入走完场景

### 不卡文神器十条（狂更猫）

我是谁/在哪/什么情况 → 目标 → 困难优势金手指内心 → 进入世界举动 → 他人震惊 → 反转可选 → 装逼绕核心 → 舆论震惊 → 收获盘点 → 渲染/突发 → **拉出下一目标**  
卡在哪步只执行下一步。

### 搭台子

双方目标 → 时间 → 场景 → 演员进场 → 过渡 → 下一座台

### 感情线六步（零基础班）

相遇（优先前史）→ 好感 → 误会障碍 → 拉扯暧昧 → 内心突破 → 反转稳定

### 爱情套路（狂更猫）

感情好→往分开写；不好→往一起凑；误会解除必须升温；拉扯 = 一方十拿九稳时**另一方主动终止**（外力打断≠拉扯）

## 7. 番茄免费流实操 **【番茄·免费流】**

> 规则迭代快，以下为课内口述；发书以后台为准。

### 红线与更新

- 约日更 4000，禁扎更；断更约 7 天可能停流，捡回需连更约 14 天
- 身份证/手机/银行卡同人；严重抄袭、前三章高度同质、多平台同发、敏感热点开局风险
- 女频第一本建议锁 ≥20 万+书册，勿因首秀差轻易切书

### 节点（经验口径 · 待核实）

| 节点 | 课堂口述 |
|------|----------|
| 签约 | 约 2 万 |
| 验证 | 约 8 万相关节奏；热门题材勿四天囤满 8 万 |
| 首秀 | 常见约 10 万 |
| 书测/书册 | 约 20 万 |

### 发书到首秀

```text
封面+标签+简介卖点 → 发出
约 2 万签约；日更约 4K 不断更
盯追更比（宜 ≤3:1）与完读（大众约 ≥15% 为常见参考）
早发保跟读窗口；首秀后 1～2 天判断健康冲书测，爆炸可切（课内策略）
```

### 收入粗算（经验口径）

- 约 1 万读者/流量 ≈ 100 元（非官方）
- 睡后：约 60 万字完结且曾月稿 2 万+ 的质量叙事（34 课）
- 题材负责首秀量；实力负责单价与稳定性

## 8. 立意与 IP（写作课程2 · 长线）

- 核心句：先让人看懂，再让人看爽，最后让人记住（立意）
- 立意 = 成绩好 + 口碑好的共性；切入点：成长、时事、感悟、民族大义等
- IP ≠ IP 宇宙；好书常完结后放大改编
- 迷茫可多尝试，不能盲目跟风（与扫榜不矛盾：扫榜是验证市场，不是无思考粘贴）

## 10. 自查清单（写作中）

### 开头

- [ ] 前五章展示主角优势；金手指说明能干嘛
- [ ] 章末读者预知；思考定目标已写
- [ ] 女频：五要素、男主不宜过晚、忌信息后置

### 剧情

- [ ] 目标清晰、阻碍有、对比有关系
- [ ] 收获盘点、下一目标接大目标
- [ ] 稳书：本段是否服务核心亮点

### 爽点期待

- [ ] 对比写足；预知提前给（新人忌藏信息）
- [ ] 分层爆发；兑现超预期

### 零基础六标准（撰稿费导向）

冲突多、代入强、节奏快、有爽点、人设讨喜、设定新颖 —— 自评命中数，签约经验约 2–3 可签、4 近爆、6 大爆 **【经验口径】**
