# Writer Practice & Unblock Playbook（自包含速查）

> 蒸馏自：红娘子第 3–4 课、查理编剧孵化营第 26–27 课、狂更猫同人课、小说零基础写作班第 37 课及 SOP-22。不引用课程外路径。

## 1. 动笔前六步构思（有效训练法）

```mermaid
flowchart LR
  A[≥10创意] --> B[选定+原动力]
  B --> C[读者定位]
  C --> D[热点卖点]
  D --> E[故事框架]
  E --> F[目标字数]
  F --> G[讨喜人物]
  G --> H[开篇6000字钩子]
```

### 1.1 灵感与原动力

| 步骤 | 操作 |
|------|------|
| 发散 | 至少 **10 个创意** 写下来 |
| 筛选 | 最喜欢 / 最完整 / 最熟悉 |
| 追问 | 为什么选这个？另外九个为何不要？**什么打动我？** |
| 结论 | 打动感 = 内在原动力；无原动力易中途弃写 |

### 1.2 读者定位

- 动笔前明确：**这本写给哪类人**
- **写自己能驾驭的**：熟悉的生活/职业；不理解的高难度题材宜放弃硬写
- 案例逻辑：《都挺好》— 婚姻家庭、主体女性读者

### 1.3 热点（卖点）

两层：**题材共鸣**（戳心事）+ **赛道热闹**（看的人多不多）

| 更强共鸣例 | 较弱例 | 说明 |
|------------|--------|------|
| 失恋等大众经历 | 窄众经历（如部分金融陷阱） | 共鸣面决定传播 |
| 市场「热」品类 | 市场「冷」品类 | 冷门可写，接受面窄 |

### 1.4 框架

- 常来自新闻、影视、身边 → **真实作底，虚构作翅**
- 新人讨巧：初恋、校园、职场痕迹 → 升华，忌流水账日记
- 例：「被骗百万」作骨 → 叠人物、叠骗术类型 → 丰富后易带入

### 1.5 目标字数（控制力训练）

| 故事体量 | 字数感 |
|----------|--------|
| 简单一段经历 | 不必撑到百万字 |
| 多代家族史 | 需五六十万级以上空间 |

**练习**：强制「本故事 N 字内写完」反复练 → 想写多少能写多少。

### 1.6 人物

- 文笔情节好，主角讨人厌仍会弃书
- 公约数美德：善良、勇敢等；反派宜鲜明可憎
- 总裁文逻辑：类型读者偏好需在类型内满足，不必讨好所有人

### 1.7 开篇 6000 字训练

| 误区 | 现实 |
|------|------|
| 精彩在后面 | 开篇不钩 → 无人看后面 |
| 未成大神前故弄玄虚 | 危险 |

**练法**：

1. 专读他人书 **前 6000 字**，多本形成直觉  
2. 找模仿标杆，学到「愿看后面」再扩写  
3. 给信得过的读者：只听 **有没有兴趣看下去**  
4. 模仿合法：先仿后脱壳（行业常见路径）

**复习七问**：原动力？写给谁？热点？框架？字数？主角讨喜？开篇钩得住？

## 2. 素材库存

### 2.1 底层逻辑

| 误区 | 事实 |
|------|------|
| 没想象力天赋 | 多是**知识框架窄、信息少** |
| 凭空编造 | 必基于已有认知 |

小说要**代入** → 需要家长里短、社会细节、可感知对话。

### 2.2 渠道地图

```text
热搜/社会新闻 ──┐
天涯等论坛板块 ─┤
知乎第一人称 ───┼→ 艺术加工 → 小说/短文/观点
百度/贴吧/知道 ─┤
豆瓣小组 ───────┤
微博热点 ───────┘
```

### 2.3 各渠道动作

| 渠道 | 怎么做 | 收什么 |
|------|--------|--------|
| 热搜/新闻 | 百度/微博热搜等；多人搜 = 值得关注 | 改编潜力、社会情绪、戏剧性第一反应 |
| 天涯类论坛 | 按题材进板（情感/婆媳/亲子/30+婚恋等）；看精华与高回复 | 多层观点、吵架逻辑、**对话颗粒** |
| 知乎 | 搜体验类问句（同居、失恋、职场第一天…） | 第一人称细节、心理活动 |
| 百度 | 新闻+贴吧+知道跳转 | 话题放大成篇 |
| 豆瓣 | 前任、忘记前任等小组 | 他人如何写关系 |
| 微博 | 社会热点密集区 | 突发事件、情绪爆点 |

### 2.4 职业作者 vs 普通人看新闻

| 普通人 | 作者 |
|--------|------|
| 一晃而过 | 立刻想：能否成故事、谁共鸣 |

### 2.5 加工与合规

| 问题 | 原则 |
|------|------|
| 用真人真事 | 艺术加工：虚构、夸张、多人物组合 |
| 纪实癖 | 真名不换 → 隐私风险 |
| 比喻 | 素材要「洗切烹」，非生吞 |

### 2.6 观察者纪律

- 接收信息，**不急着道德审判**
- 人性灰色是资源；河流式积累 → 格局变宽
- 阅读面：言情 + 社会新闻 + 公共议题，避免单一输入
- **量变**：1 人一点 → 百人成线 → 千人成片

### 2.7 新闻 → 戏（示范逻辑）

事实骨架：困境下丈夫短信「我爱你」vs 妻子先想搜救位置——**两边第一反应不同** = 戏眼。  
筛选：**能打动我的，常也能打动多数人**。

### 2.8 工具（可选）

讯飞输入/语记、WPS、各类手机写作 App——应用市场试用手感即可，名称随迭代更换。

## 3. 卡文分型与 SOP-22

### 3.1 四型一览

| 类型 | 表现 | 本质 |
|------|------|------|
| 大情节 | 不知接下来写什么 | 后续发展无清晰思路 → **大纲/细纲** |
| 衔接 | 知下段，不会转 | 转场技巧 |
| 描写 | 细纲有，卡在句子上 | 表达库存不足 |
| 小情节走场 | 知目的，不知场景内容 | 需**代入走场** |

另：**桥段洁癖型**（知功能，嫌桥段俗）→ 归类为「先保节拍」，非「不知道写什么」。

### 3.2 SOP-22（一句话）

```text
分型：大情节 | 衔接 | 描写 | 小情节走场
大情节：回大纲/细纲 + 渴望—障碍—行动轮子 + 烂笔头自检
衔接：转场六法（结构性过渡：时间/地点/人物/情绪/主题/道具钩子）
描写：反向词典/写作助手 + 长期阅读
走场：沉浸代入，替角色把场景走完
```

### 3.3 三个万能公式（大情节）

**公式 1**：没有冲突 = 没有故事 → 还能搞什么事？

**公式 2**：渴望 + 障碍 = 冲突

| 戏剧性渴望 | 戏剧性障碍 |
|------------|------------|
| 当下遥不可及 | 不理会则在情感/身体/社会经济上遭**重创** |
| 与生死或「活不下去」级结果绑定 | 逼迫主角行动 |

**公式 3**：冲突 + 行动 + 结局 = 故事（轮子）

### 3.4 烂笔头自检表

写下答案，勿只在脑子里转：

| 对象 | 写清 | 强化 |
|------|------|------|
| 渴望 | 谁要什么？首次出现位置？ | 更强？更早？ |
| 障碍 | 是什么？首次位置？ | 更早更强？不理会是否仍无损？（若是则障碍弱） |
| 行动 | 用什么克服？位置？ | 更早、更坚定、更多？ |
| 结局 | 胜/败/局部胜？ | 场结局 vs 终局 |

### 3.5 小情节：作者代入 SOP

1. 写明本场景**功能**（例：让读者感到被忽视 → 理解性格转变）  
2. 自问：缺什么温暖才会转变？  
3. **成为主角**走完场景：感受、判断、行动  

### 3.6 描写卡文

- 长期：大量阅读同类好文，摘句式库存  
- 当下：写作助手、反向词典、同义替换（工具名随时代替换）

### 3.7 衔接：转场六法（补全）

任选组合，先联通再润色：

1. **时间跳切**：「三天后」  
2. **地点切镜**：新场景首句感官锚点  
3. **人物跟拍**：谁离场谁入画  
4. **情绪残响**：上一场景末句情绪接到下一场开头  
5. **道具/信息钩子**：未解问题带入下段  
6. **并行交叉**：A 线末句与 B 线首句对仗

## 4. 编剧五查 + 攻击矩阵（卡文/灵感枯竭）

> 与小说「轮子」互补：**剧本/强情节长篇**卡住时优先用。

### 4.1 根本原因

身陷迷局、自我催眠 → **看不清全局**；先跳出来。

### 4.2 五查顺序

| # | 检查 | 自问 |
|---|------|------|
| 1 | 主题 | 主题是什么？本场服务主题吗？跑偏/动摇？ |
| 2 | 核心对抗 | 谁在跟谁对抗？对抗是否停下来了？ |
| 3 | 主角成长 | 成长线在哪？滞后还是超前？该成长了吗？ |
| 4 | 人物关系 | 关系有无变化？单调则人多余 |
| 5 | **攻击不足** | 是不是**该写的压力没写**？（最常见） |

### 4.3 攻击性定义

故事中各力量对主角的**压力与打击**。规划宏大、落笔缩水 → 水。

### 4.4 攻击源 × 攻击目标

| 攻击源 ↓ / 目标 → | 主角本身 | 人物关系 | 行动目标 |
|-------------------|----------|----------|----------|
| 环境（自然） | 雨灾、严寒困人 | 灾难考验关系 | 阻挠行动 |
| 环境（社会） | **没钱**连环压 | 因钱撕裂关系 | 缺钱打不开局面 |
| 对手 | 揍、揭短、毁身份 | 挑拨离间 | 抢资源捣乱 |
| 自身 | 拖延误判 | 缺陷伤关系 | 自己掉链子 |

**用法**：卡文时连线，**缺啥补啥**。

**设定必「响」原则**：

- 怕蛇 → 蛇须出现  
- 假身份 → 须有人揭或险些揭  
- 好枪 → 须进水/被偷/失灵  
- 技能（厨子）→ 须有一次关键烹饪  
- 不会游泳 + 目标却是海上 → 要么改目标要么必落水  

### 4.5 桥段洁癖三原则

1. **流畅 > 精彩** — 俗桥段先写上  
2. 剧本是修改的艺术 — 后面再美  
3. 不可能每场都惊人  

**桌子比喻**：三条好腿 + 一条丑棍，桌子先立住。

### 4.6 卡文三条注意

1. 先保节拍（见上）  
2. 素材枯竭 → 继续调研、采访、看同类型  
3. **讲给人听**：捕捉倾听者反应，打破自闭循环

## 5. 拖延症

### 5.1 认知矫正

| 错误 | 真相 |
|------|------|
| 我是完美主义才不动 | 完美主义是边做边改；不动 = 拖延 |
| 我不懒，只是这事拖 | 此事就是你不愿付延迟成本的事 |
| 羞耻 | 人人都有；克服即优势 |

### 5.2 原理

对**延迟回报**缺乏信心 → 选眼前确定快感（短视频、游戏）。编剧链条极长 → 重灾区「十编九拖」。基因偏懒利于生存；**社会性**要求反动物性推进。

### 5.3 七法详表

| 方法 | 机制 | 实操 |
|------|------|------|
| 目标具体化 | 把远期变可见 | 订播出/完稿后的具体奖励物 |
| 计划拆分 | 降畏难 | 日 1–2h 推进一格；不必 16h 爆更 |
| 关闭干扰 | 减诱惑 | 写作期无手机；识别个人瘾项 |
| 十分钟法则 | 降启动 | 只写 10 分钟 |
| 先写最爱一场 | 降启动 | 从最有遐想戏入手 |
| 为了谁 | 外驱 | 对老师/家人/读者承诺 |
| 搭档 | 双边约束 | **双人组**最佳；三人以上易崩 |

### 5.4 拖延 vs 卡文

| | 拖延 | 卡文 |
|---|------|------|
| 状态 | 不想开始 | 想写但过不去 |
| 药 | 七法 | 分型 + 轮子/五查 |

## 6. 新手误区十条（展开）

### 6.1 搞服务，不搞艺术

文艺是交流方式；自夸艺术家易忘**服务观众**。伪高级「让人看不懂还给钱」对新人不存在。直播/拍戏都是服务喜欢你的人的不同形式。

### 6.2 才华

非入行前提；种类多（快反应 vs 慢雕琢）；**坚持即才华**。永远有人更强，不必焦虑门槛。

### 6.3 价值观

别刻意灌输；讲好故事价值观自生。**揭露现实**（发声、撕开事实）≠ 替观众下判断。

### 6.4 创作苦

「灵感爽」多是痛苦后的如释重负。编剧**延后满足**；反人性故苦，果子在未来。

### 6.5 规则

能破，**先熟后破**（熟而后生）。练车科目二与上路：先规则内化再忘掉规则。

### 6.6 赛道

公司选赛道 ≠ 个人创作者追热。**写擅长、所爱、有素材的**；成熟市场里各菜系都能活。

### 6.7 别急着红

买了剧本 ≠ 尾款 ≠ 开机 ≠ 过审 ≠ 播出。到账/认可前继续写。

### 6.8 别眼高手低

卖座「烂片」有别处长处；少判他人，先拍自己的。

### 6.9 名利

无错，但**能量守恒**：大名大利大代价。

### 6.10 得奖

主流奖新人暂勿幻想；小奖多商业行为。路线：**先商业卖座养创作**。

**浓缩心态**：少走弯路 → 把精力投到作品上。

## 7. 同人：互动中心与边界

### 7.1 定义

在已有 IP 世界观/角色上二创（动漫、影视、小说、游戏等）。

### 7.2 优劣

| 优势 | 代价 |
|------|------|
| 自带流量、省设定 | 挑读者（须看过原作） |
| 世界观成熟 | 易崩、金手指后流失 |
| 设定弱作者更稳 | 原作降温连带变凉 |
| 下限常高于乱原创 | **上限难大爆**；脑洞受限 |

「主线清晰」「更好水」**不是**优势。

### 7.3 核心：互动

> 主角做什么事，**最大化调动同人角色反应** = 互动。

- 中心不是单纯「弥补遗憾」  
- 情绪要多样（不只震惊）  
- 可无传统爽点，互动足亦可  

| 写法 | 读者 |
|------|------|
| 主角比悟空强百倍 | 不爽 |
| 开盲盒/书店让悟空变「朋克悟空」 | 爽在同人变化 |

主角 = **引发互动的装置**，非 solo 升级炫耀。

### 7.4 模板举例

| 模板 | 要点 |
|------|------|
| 书店/文抄公 | 谁读什么书情绪最大 → 心态变 → 奖励 |
| 盲盒店 | 谁来开、引起什么连锁反应；可扩天庭妖怪线 |
| 曝光/信息差 | 读者知主角牛、同人不知 → 等反应 |
| 心声/日记 | 扒光内心扔同人面前；**真实反差**非假高大 |

**高低对比**：扇玉帝耳光+震惊水字数 < 拖拉机/反差道具（仍需圆逻辑）

### 7.5 切入（课上经验口径）

- 海贼：顶上战争等大事件；盲盒/盘点为互动  
- 一人之下：罗天大醮等大场面；忌平淡老实升级暴打  
- 洪荒西游：**量劫/洪荒**向常优于重走取经；互动绕截教等  
- 武侠：风向随平台变，以能否上架为准  

### 7.6 互动设计 SOP

```text
1. 选热门 IP
2. 明确主角目标（变强/搞钱/收集…）
3. 设计砸情绪事件（道具/场合/反差）
4. 写足同人反应与连锁
5. 自检：删掉同人反应剧情还剩啥？几乎没剩 = 失败
6. 改命运须逻辑圆回主线；圆不上别救
```

**反差例**：孙悟空学阿威十八式 > 提前学七十二变无反差。

### 7.7 误区对照

| 误区 | 纠正 |
|------|------|
| 同人=弥补遗憾 | 中心是互动 |
| 主角平推最爽 | 爽在同人因你而变 |
| 只会震惊 | 要共情与多样情绪 |
| 不用结构 | 仍要目标、信息差、结构 |

### 7.8 边界【经验口径·非法律意见】

- 版权、签约、平台审核因时因地变；**上架可行性以平台实时规则为准**  
- 录音中「没版权硬写」仅为课堂态度记录，**不构成建议**  
- IP 热度、能否写金庸/古龙/雪中/Harry 等须自行核实

## 8. 联合决策树（卡文 + 拖延 + 没料）

```text
不动笔？
  └─ 用拖延七法；必要时六步重校准原动力

动笔但空？
  └─ 素材 SOP：逛论坛/热搜 + 观察者一周

有大纲仍卡大事件？
  └─ 细纲 + 轮子 + 烂笔头

知场景目的不会写？
  └─ 代入走场

知功能嫌桥段俗？
  └─ 先保节拍（五查/攻击表并行）

写同人读者流失？
  └─ 互动 SOP + 删反应测试

心态崩？
  └─ 误区十条对号入座，回到「服务读者」
```

## 9. 与结构 skill 的接口

| 本 playbook | 交给 story-fundamentals |
|-------------|-------------------------|
