# 短视频选题：3-2-4 与三角定位

## 「3-2-4」是什么

| 符号 | 含义 |
|------|------|
| **3** | **三角定位**：①自身（优势）→ ②用户（需求）→ ③平台（变现/赛道）——**顺序不能反**，勿先追热门搞笑赛道 |
| **2** | **双层满足**：①优势 **2–3 个叠加**（可反差）；②用户需求 **爽点 + 价值叠加**（爽点内又分激素级与人性级两层，**勿优先只做知识价值**） |
| **4** | **四步选题闭环**：定 ≥2 种变现 → 勾局部优势 → 锁定主需求（爽点+价值）→ 用平台变现反验证选题 |

> 选题终极句：**基于什么优势，给观众什么爽点/价值，在什么变现方式下可持续。**

## 适用边界

- **适用**：抖音等短视频账号定位、人设、选题策划、转型复盘（如保留用户需求换赛道）。
- **不适用**：小红书图文运营细则（见 `xiaohongshu-ops`）、剧本信息节拍拉片（见 `screenplay-analysis`）。

## 核心信念（必记）

- **选择大于努力**；赛道/达人不匹配要敢于推翻重来。
- **互联网只相信长板**；优势标准 = **百里挑一**（跟 100 个普通人比，不跟赛道王者比）。
- 找优势：**被外人夸过 5 次以上**的事；每人通常不止一个优势。
- **暴力 = 征服**（车/钱/装备/版图），不单是打架。
- **优越感**是人性级爽点之首：**姿态放低**，让观众觉得比你聪明。
- **价值是第三级、最后才考虑**；纯实用号天花板低于颜值/搞笑类（数量级差距）。

## 标准工作流

### 阶段 1：锚定平台（变现）

先定 **至少两种**变现方式（兼容），再选题。常见组合思路：直播带货（赛道型/自有产品）+ 短视频带货或接广；不必全员做直播。

九种方式速记：直播带货、打赏、付费直播、付费连麦、短视频带货、接广告、流量分成、平台任务、订阅/会员——前四种依赖直播，后五种否。

### 阶段 2：自身角（九类优势）

在 playbook 九类表上勾选；应用 **六条结论**：稀缺优先、2–3 叠加、反差、问他人去自恋、优势即 IP、**人人叠加创作能力**（会拍会写会剪）。

### 阶段 3：用户角（需求三级）

```
一级激素级：性（繁殖/魅力）、暴力（征服）、快乐
二级人性级：优越感、归属感、认同、情感治愈、秩序（逻辑）
三级价值：实用、效率（省时间）、欣赏
```

应用 **三条结论**：越靠前受众越广；爽点+价值叠加；**选定后主需求不换**（换赛道可以，别把铁粉需求翻转）。

### 阶段 4：合成选题陈述

输出模板（必填）：

```text
我的人设优势：[2-3 项，含稀缺/反差]
主要满足的爽点：[1-2 项，靠前优先]
叠加的价值：[0-1 项，服务变现]
变现方式：[≥2 种]
单条视频承诺：[30 秒内观众得到什么]
```

## 工作流 B：改号/转型诊断

1. 列出当前内容实际满足的 **需求**（不是表面赛道名）。
2. 若转型：学「汽车号→时尚号仍成功」——**用户需求未变**（一直提供「美」），只换表现形式/变现。
3. 若粉丝乱、掉粉：检查是否从优越感切到纯干货，或优势与人设割裂。

## 自检清单

- [ ] 是否先选了平台热门而非自身长板
- [ ] 优势是否 2–3 个叠加且有反差
- [ ] 是否只讲干货、无爽点钩子
- [ ] 变现是否至少两种、与内容不打架
- [ ] 主需求是否稳定可续更
