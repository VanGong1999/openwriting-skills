# 知乎盐选 / 短篇创作 Skill

## 何时使用

- 用户要写或改 **知乎盐选短篇**（第一人称居多，约 1 万字，付费试读 + 截断点）。
- 需要 **选题 → 大纲 → 成稿/改稿** 全流程，或拆解爆款、案件素材、女性情感、开篇导语。
- 用户明确要区分：**短篇盐选** vs **长篇网文** vs **带货/说服/营销故事**（后者用 `commercial-content`，本 skill 不展开）。

## 与长篇、带货的边界

| 维度 | 盐选短篇 | 长篇网文连载 | 故事带货/营销 |
| --- | --- | --- | --- |
| 体量 | 聚焦一件事，单线叙事 | 多线、世界观、细纲卷帙 | 话术、人设、转化 |
| 结构 | 起承转合 / 四句话故事；10 节左右分段 | 卷章、长线悬念 | 节拍服务于卖点 |
| 开篇 | 前 50 字/导语/前 800 字决定生死 | 可慢热铺垫 | 钩子服务于商品 |
| 变现 | 赞同、会员、截断付费 | 订阅、连载 | 直播、短视频 |

## 主流程：选题 → 大纲 → 成稿

按顺序执行；细节模板见 [references/playbook.md](references/playbook.md)。

```
选题（类型+素材+情绪） → 大纲（一句话/四句话/排序） → 成稿（口语化+节奏+截断） → 内测改稿
```

### 1. 选题

1. **定盐选大类**（数据向）：情感（古言/现言/世情）、脑洞（悬疑向/IP）、真实（职业/案件）；可拓展科幻（生活化情感）、悬疑推理（重逻辑、现实感）。——知乎 17 课
2. **爆款四要素自检**：话题性素材、出人意料设定、清晰主线、信息量爆炸开篇。——知乎 17 课
3. **案件/奇闻类**（若写真实向）：三维度（新知、情绪、讨论度）+ 资料一票否决（官媒 + 三视角以上）；填 **选题表**；不做「直写未定论热点」，做热点延伸。——知乎 18 课（张三千）
4. **构思三问**（有素材后）：想读者（共鸣清单）、想范围（名场面/只打透一种情绪）、想视角（盐选常用第一人称）。——知乎 19 课
5. **灵感三途径**：写自己、重新审视社会生活、找「梗」（可对照戏剧模式/虐甜梗表）。——知乎 18 课（Nancy）

### 2. 大纲

1. **一句话故事**：主角是谁、遇到什么事、做什么、结局如何。——知乎 21 课
2. **四句话故事（起承转合）**：起（扔进漩涡）→ 承（矛盾升级，勿重复起）→ 转（最高能）→ 合（圆满交代，短篇避免开放式烂尾）。——知乎 21 课
3. **单线叙事**：一条主线、一个内核、一种情绪；支线只包裹主线，禁止用新故事解释旧坑。——知乎 21 课
4. **案件类大纲四步**：写人/写事 → 定主打情绪 → 筛选素材 → **爆点前置**排序。——知乎 18 课
5. **情节服务主线**：按作者意图与大纲脑暴；可归类复仇/爱情/推理等自带爆点类型。——知乎 22 课
6. **情节公式**（深化因果）：情节＝（什么）＋ 为什么；避免「档案式罗列」。——知乎 06 极简情节公式
7. **可选兜底**：人物/背景/主线模板 + 波尔蒂 36 情境 / 两大底层套路（大卫/罗密欧）。——0 基础课 24–25 课
8. **五千字简纲**（影视向骨架，可迁移至知乎全文大纲）：故事线 → 罗列情节可能 → 人物戏剧任务 → 时间轴/节拍表；**困局须正面解开、梗概无省略号**。——北大 16 课

### 3. 成稿

1. **叙事**：口语化、沟通感（像回答问题）；高叙事效率；情绪贯穿且要「爆棚」（生理级反应）；手机阅读多分段。——知乎 18 课
2. **章节**：8–15 小节；**爆点开头 + 悬念结尾**；衔接承前启后/关联词。——知乎 18 课
3. **开篇**：删废话，2–3 个关键细节；尽快抛出欲望/困境；导语满足反常识/内涵深刻/情绪波动/悬念之一。——知乎 21 课；导语另可参考九层课约 100 字起承转合（见 playbook）。
4. **节奏**：300 字小矛盾、1000 字大矛盾（编辑向）；免费试读约 3000–5000 字要点前置、冰糖葫芦式矛盾点。——九层/竹节讲义
5. **截断点**：约 3000 字；大悬念套小悬念；爆点前置支撑试读。——知乎 18 课
6. **真实感**：事理/情理/文化逻辑；间接经验与职业细节。——知乎 23 课
7. **内测改稿**：受众 + 同级作者 + 前辈 → 修改 → 朗读 → 错别字。——知乎 18 课
8. **知乎文稿**：首人称优先、8000–15000 字；校对格式（分段、序号、专属对话符号、截断标记、敏感尺度）。——九层 短篇四大坑

## 辅助任务速查

| 任务 | 做法 |
| --- | --- |
| 拆爆款 | 会员榜单/万赞回答 → 六列表格细读 → 一句话主线提炼。——知乎 17 课 |
| 女性情感 | 切入点：真实+提炼+糅合；立场客观共情；细腻笔触三要素。——知乎 19 课 |
| 类型公式 | 虐/爽/甜、十个矛盾点、导语写清主线。——竹节爆款公式 + 九层钩子框架 |
| 卡文 | 回看大纲与作者意图；情节＝什么+为什么；从后往前推（0 基础课心法） |

## 输出约定（代用户创作时）

1. 先声明 **类型 + 一句话主线 + 主打情绪**。
2. 给出 **导语（约 100 字）** 与 **起承转合四句话**（或案件选题表字段）。
3. 标注建议 **截断点位置** 与 **小节划分**（约 10 段）。
4. 成稿阶段：第一人称、口语短段；不写长篇世界观铺陈、不写带货脚本。
5. 凡超出讲义处标注「创作发挥」，不冒充课程原文。
